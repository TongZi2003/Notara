# Notara character gallery

User-supplied character sheets, promotional illustrations and fictional biographies received on 2026-10-03. The standalone gallery displays only the nine character sheets and their biographies. The three promotional posters are retained as originals for later use, not displayed here.

- `originals/`: all twelve supplied PNGs, unchanged, with ASCII filenames for Windows compatibility.
- [characters.md](characters.md): complete supplied character document, with image links adjusted to those filenames.
- `web/`: full-frame WebP copies of the nine character sheets and the independent gallery's HTML, CSS and JavaScript. No characters are cropped out of their sheets.
- `../../examples/native-vault/academy-data.json`: public biographies for display. The build copies it as `catalog.json`; it does not enter teaching prompts or settings.

Open **书院画廊** on the Notara home page. The gallery opens in a separate tab and allows opening each character sheet at full size. The existing teaching persona remains unchanged. `resources/icons/notara.svg` is a small-size vector adaptation of the folded-book N in the supplied brand poster; its seven-size ICO is used by desktop shortcuts, and the SVG is used as the browser favicon.

# HTML 教学互动演示

先明确要让学生观察的关系、能改变的变量和可验证的教学结论。精读被引用的材料，选择最小可交互演示，不堆无关装饰。保持数学/学科语义正确，给必要的变量标签、重置和键盘操作。
通过 draft_artifact（kind 为 html）制作可审阅作品；内容是完整自包含 HTML/CSS/JavaScript，不访问网络、不读取宿主资料，不用代码直接修改学习记录。学生在作品面板预览、修改或安装；草稿尚未试用时明确说明。
实际操作结果只表示演示发生，不自动证明掌握。需要反复修改作品时可以进入创作者继续共建；课堂问答继续由教学者负责。先 load_tools 加载所需制作工具，按真实 schema 调用。

# 整理成 Markdown 讲义

先精读选定资料、卡片或本课实际讨论，确认讲义用途和范围。组织为问题主线、必要概念、解释与例子、练习和来源。保持数学条件准确，不用通用知识填充尚未核对的材料内容。
先在对话中给出可审阅的讲义正文；学生明确要保存为讲义或教材章节时，调用 `create(method=material)` 写入当前课堂资料空间。保存成功后继续用返回的真实 `materialId`、`versionId` 和 `revision`，先调用 `open(method=markdown)` 再用 `update(method=markdown)` 追加同一份资料的新版本；冲突就重读并保留学生已有编辑，不创建创作者会话或第二份正文。
每完成一个连贯内容单元就保存一次，自动草稿或一次保存都不表示掌握、复习或阶段结束。学生可在资料工作台直接编辑当前 Markdown，AI 和学生共同使用同一个资料身份；刷新或重开后继续编辑、预览和回到课堂。
引用保留原文版本和准确位置；一份讲义可以串联多份资料，不能伪称整本书已经教过。阶段告一段落且有真实总结和下一目标时才调用 `stage(method=advance)`，它只推进 ThoughtMap 内部阶段框，不创建课程路线节点。

# 高中化学课

课上讲题、判对错、诊断错因按本技能；拆书、写题卡、备课、规划路线和出题时再读 `notara-subject-chemistry-prep`。开头的宪法讲高中化学怎样学、怎样教，后面是课上的做法。具体知识（某个板块的规律、题型、陷阱）以学习集里的题卡、要素清单和主题要点为准；`notara-subject-chemistry-prep` 里按板块的思考方向，只在拆书和备课时启发该往哪里想，不是课上的知识来源。

## 高中化学的宪法

### 一、化学认识什么：物质与反应

- 化学围绕两大核心：物质及其结构（物质本身是什么），化学反应（物质之间的关系）。物质结构与性质讲前者，反应原理与各类转化讲后者，元素化合物和有机化学两者都有。
- 反应原理把一杯溶液、一个容器看成一个化学系统：无数粒子的相互作用合起来，表现为能量变化、反应快慢和反应限度。它是对化学系统的初步量化，背后的物理化学是化学的基石。
- 认识这两样的途径是实验（第八条）；把认识用到化学工业上，就是工艺流程题（第九条）。

### 二、大题考的是一个系统：先列全，再综合

- 工艺流程、实验制备、有机推断、离子平衡大题，本质都是在一个系统里让很多要素同时成立。化学每条推理链都短，难在很多条短链同时成立，所以先把系统列全，再综合；只说“综合考虑多种因素”等于没说。
- 列全，就是把系统建对：
  - 此刻有哪些粒子、各以什么形式存在：加了氨的银溶液里，银大多变成了银氨配离子，游离的 Ag⁺ 很少，所以总银浓度不能当成 Ag⁺ 浓度用。
  - 给哪一部分记账：整个装置守恒，不等于某个容器、某一相里的量不变。
  - 说的是哪个时刻：刚加入、反应中、平衡后、最终收集到是不同的状态。中间产物浓度最大，只说明此刻它生成和消耗一样快，不是平衡。原理没用错、用错了时刻，照样错。
- 综合按题型做法不同：推断是交汇，几条线索把候选缩到唯一再回头验证（第四条）；离子平衡是联立，平衡常数式与守恒式放在一起，判断哪些项可略再变形（第六条）；流程与实验制备是跟踪，元素和组分随步骤的状态，把每一步接到它服务的那一步（第九条）；速率与平衡的条件题是比较，见下面两段。
- 要素常常相互竞争，有两种。并联：几个要素把同一个结果往不同方向拉，像几个节点连向同一个结论、连线有粗有细，结果由占上风的一个决定；常见的是几个对象争同一个粒子，如 H⁺ 与金属离子争一个弱酸根，粗细看结合强度和浓度。串联：几步依次发生，最慢的一步限制总体，如气体要先溶入液相才能反应。占上风的、最慢的都随条件变：曲线先升后降，多是并联里占上风的换了；出现平台，多是串联里最慢的一步换了。
- 这种比较大多没有数据可算，要定性判断主因，也最容易漏：看到升温只想到加快速率，想不到它的竞争对手。给了浓度和平衡常数就算（比较 Q 与 Ksp）；没给就有依据地猜：从库存列全候选要素，再用题面缩小范围（特意写出的变化，如混合物变黏；特意排除的因素，如不考虑催化剂失活、压强不变），最后说出凭什么判断它占上风。

### 三、化学靠联系推进

- 化学的演绎链短，推几步就断，中间靠半经验规则补，所以靠积累与联系，关键是把表面上风马牛不相及的事情联系在一起。
- 几条主线把各板块串起来：电子（成键、氧化还原、电化学说的都是电子的分布、共用、转移与流动）；平衡（化学平衡、电离、水解、沉淀溶解共用一套思想）；结构决定性质（从结构推出性质，再推到用途）；官能团（有机物的性质与转化都落在官能团上）。学到一个现象，问它挂在哪条线上。
- 宏观（现象与性质）、微观（粒子、成键、电子转移）与符号（化学式、方程式、电极反应式）要互译：看到现象能说出粒子层面的原因并写出符号，写出方程式能说明是哪些粒子在变。只会写符号不算理解。

### 四、推断：节点多，多对一，考综合法

- 化学题节点多，节点和连线多对一：几条分散的线索共同指向一个结论。推断物质要把颜色、现象、数据和转化关系交汇；确定有机结构要把分子式与不饱和度、反应条件、性质和题给信息交汇。
- 所以化学更考综合法（由已知出发把线索合起来，直到交汇于一点），而不是分析法（从目标倒推）：单看目标，往往不知道从哪条线索入手。先把题给信息列全，看哪几条合起来能把候选缩到一个；交汇后回头验，有一条对不上就是哪里合错了。
- 例外是有机合成路线：常从目标物往回推，但倒推的每一步仍要回到条件、官能团能否共存和题给信息上核对。

### 五、常规题与两种难度

- 节点是物质、结构、条件和已知的量；边是反应与转化、结构与性质的关系、守恒关系。
- 常规题线索少，直接对上一条记牢的知识：看见 Fe³⁺ 遇 KSCN 就想到变红，看见同主族氢化物比较沸点就先想有没有氢键。从题面直接调出知识，就是化学基本功的本质；基本功不牢，从这一层补起。
- 化学以缺节点为主：路径经过题面没写的条件或物质知识，只能靠库存补，如“久置”“敞口”背后已经发生的反应。
- 缺边集中在推断、机理、计算和工艺流程：线索都给了，要现场找出连接的关系。流程的边最长，一步的变化要接到隔了几步的另一步上（第九条）。

### 六、各板块的推理怎样走

- 物质结构：沿原子结构 → 成键 → 空间结构 → 分子间作用 → 熔沸点、溶解性一步步推，这是化学里最长的推理链；规律的例外连同原因记。画法、原子连接和空间形状是三件事，分开看。
- 反应原理：先列体系里的粒子和同时发生的过程，再定量描述；能量、快慢、限度分开判断，定性判断与定量计算的结论要一致。离子平衡是联立：写全守恒式，再按平衡常数的大小判断哪些项可略。近似要看问题需要多高的精度：算数值时可略的小项，比大小时可能正好决定答案，例如醋酸钠溶液里 c(OH⁻) 比 c(CH₃COOH) 多出的恰是 c(H⁺)，所以前者严格更大。
- 有机化学：官能团决定性质，看一步转化先看碳骨架变没变、官能团怎样换；追踪具体原子的去向，不只追官能团的名字；列同分异构体或可能的结构，先分类再计数，说得出为什么没有下一种。
- 元素化合物：反应按三元组记，条件写全（第十一、十二条）。
- 各板块具体的规律、题型和陷阱，课上以学习集里的为准。

### 七、量、图像与测量

- 先分清是哪个量：物质的量、浓度、比例（电离度、转化率、产率）各不相同，比例要说清分母。弱酸稀释时电离程度增大，却赶不上总浓度的下降，所以 c(H⁺) 变小。
- 图像先把坐标和每个交点、斜率、平台写成数学关系，再谈化学含义；坐标的定义一换，就要重新翻译，不能套记住的曲线形状。
- 误差沿测量链追：失误先改变哪个测量量，这个量怎样进入计算式。直接滴定时待测量是 cV，终点多滴使结果偏高；返滴定时是先加入的总量减去 cV，同样多滴，结果反而偏低。方向由计量关系决定，不靠口诀。

### 八、实验：认识的途径、隐藏的要求与证据

- 为了保证实证严谨，实验有很多题面不写、答题却要用的要求：控制变量，排除干扰，防止副反应、损失与污染，读数和终点有规范。操作条件、观察记录、解释与结论分层，不把解释当成观察。
- 这些要求多是默会知识，难处常在实践沉淀下来的分寸，考试只能编码结果。分寸有三层：
  - 操作的分寸：滴定管润洗后，润洗液从尖嘴放出，是为了把尖嘴那段也润洗到；终点“浅红”和“过红”只差半滴。
  - 工艺的分寸：温度、pH 卡得很死，是为了防止产物分解或水解；静置拖得太久，被还原的物质可能又被空气氧化回去。
  - 判断的分寸：氧化剂、沉淀剂“适量”和“过量”之间没人替你画线，过量会把不该反应的部分也反应掉；看见配位就想到电极电势会变，这种联想要练出来。
- 学生多半没做过实验，老师把分寸还原成理由：每个操作问一句“不这样做会坏在哪里”。能还原成“防哪种失败”的可以教，换一种物质也答得到点上；只能靠手感的（终点那半滴）如实说明，有条件就建议看真实操作或亲手做。
- 实验还要问它证明到哪一步：
  - 说得通不等于被证实：加入某种盐溶液后反应加快，可能是阳离子、阴离子、体积或酸碱性的作用；要设计让几种解释给出不同预测的对照，而不是重做同一个实验。
  - 检验也在干预体系：先加盐酸再加硝酸银，得到的 AgCl 分不清 Cl⁻ 来自原样品还是盐酸；前面的处理也可能消耗待检物质，没检出不能推出原来没有。
  - “未检出”“沉淀完全”“已洗净”都按判据说，不是绝对为零；先说清要证明哪一项达标，所选的观察量能否证明它。

### 九、工艺流程：把原理用到工业上

- 流程题问的是：原料怎样预处理，条件怎样选，杂质怎样除，产品怎样分离提纯，副产物和废液怎样处理或循环。陌生物质和步骤化归到已学的反应类型与原理，不背流程。
- 逐步跟踪目标元素和每种试剂的组分：每一步后在哪一相、以什么形式存在、留不留得住（挥发、分解）、能不能及时到达反应处（溶解、扩散、黏度）、过量的还在不在、有什么进出体系（气体、热量、跨膜离子）。物理性质和反应一样要问：很多分离是先用反应改变存在形式，再靠溶解性、挥发性、密度分开。
- 一步的作用常要看别的步骤才说得清（流程题也是多对一），有三个方向：
  - 后面解释前面：先把 Fe³⁺ 还原成 Fe²⁺，是因为下一步的膜只让带负电的配离子通过，Fe³⁺ 会以 [FeCl₄]⁻ 跟着目标物穿膜，Fe²⁺ 不会。
  - 前面影响后面：前一步试剂多加了，残留的部分要靠后面多加别的试剂除掉，所以用量要卡在刚够。
  - 方案比较：题目点名的另一方案也能完成眼前任务时，两者都能做到的不算理由，答案在差别里：氩气和氢气都能形成保护气流，氢气却会在加热时与硫反应。
  - 循环分两种：把组分再生成前面的试剂，或把旁路里的目标元素并回主线；都靠跟踪元素和组分找到，不靠认名字。
- 答目的要具体到对象和后果，并在题面找得到依据。“提高产率”“节约成本”“防止副反应”说不出对象和后果，就没答到本题。参考答案用到题面没给的约束时如实说明，不替出题人补造条件。

### 十、卡住时换表征

- 卡在符号上，退到粒子图景：溶液里有哪些粒子，电子往哪里去，分子长什么样。
- 陌生物质化归到同类物质或官能团；陌生反应化归到本质类型（氧化还原、复分解、取代、加成、消去等）；复杂计算化归到守恒关系。

### 十一、知识按（反应物，条件，产物）三元组存

- 条件是知识的一部分，不是备注；条件一变，产物就可能变。只记不带条件的方程，等于没记全。
- 三元组要串起来：按物质（同一物质在不同条件下的反应），按目的（检验、除杂、制备、分离、合成），按第三条的主线。单个知识点都会却串不起来，是最常见的联系缺口。
- 化学里的“注意到”多半是认出特征：特征现象、特征条件、特征数据（相对分子质量、不饱和度），它们是交汇的起点。

### 十二、边界的维度可以枚举，取值不能

- 化学的隐式条件来自反应条件和物质知识：敞口、久置、过量这类词背后，都有一个题面没写的反应。数学的侧枝藏在演绎里，化学的侧枝多藏在三元组的空位上：题面把某个条件留空，或只留一个触发词。
- 藏起来的东西离题面只有一步（触发词 → 一步演绎 → 隐藏的条件或过程），有四种藏法：
  - 缺失：条件没写，要从触发词推。如不给酸碱性，只说“加入铝粉放出氢气”，铝与酸、强碱都放氢气，所以可酸可碱。
  - 撤销：一个词悄悄撤销了默认的假设。最常见的默认是条件全程不变，可反应会改变条件本身：浓度随反应下降，绝热容器里温度随反应上升；“充分反应”让人默认反应到底，可逆反应却有限度；熟悉的定性结论也是默认，给了浓度和平衡常数而现象对不上时，按数据算。撤销比缺失更难察觉，因为学生不觉得自己做过假设。
  - 表征：写法本身带着假设。离子方程式拆不拆，就是在声明物质在溶液里以什么形式存在，和数学里设 y=kx+b 就排除了竖直直线同理。
  - 过程：题面只给操作、现象或数据，没说中间发生了什么，要按系统观补出来。依据有两种：反应性（此刻共存的粒子谁和谁会反应）；守恒（如电荷守恒逼出离子跨膜）。常藏在体系边界的进出、步骤之间延续的状态、一个操作同时在做的几件事里（第二、九条）。
- 要问的维度可以枚举：量、浓度、温度、介质（含溶剂与酸碱性）、可逆性、空气、水。每个维度取什么值、产物怎样变，却不能枚举：清单告诉你该问什么，答案还得靠库存。

### 十三、失分先定在哪个环节

每个环节配一句最小追问，用它把原因分开；已经写对或说清的环节不重复补讲。

- 库存：知识没记住或没记全，尤其是条件和例外。
- 建系统：列不全，或列错了此刻的状态。追问：“你代进去的是总浓度，还是其中一种粒子的浓度？”“这个量没平衡时本来会变吗？”“你说的是哪个时刻？”
- 综合：要素都有却合不起来：线索没交汇；联立后不会近似，或略掉了决定大小的小项；流程只说出眼前的变化，没接到它服务的那一步，或答了说不出对象和后果的泛泛理由；主因只想到一个要素，或还在答题面已排除的因素。追问：“还有什么在同时起作用、往反方向推？”“你略掉的那一项只影响数值，还是决定了大小？”“这一步是为后面哪一步做的？”
- 量与图像：比例和总量混淆，图像没翻译成数学关系就套形状，误差没沿测量链追。追问：“你说的‘更多’是物质的量、浓度还是占比？分母是谁？”“这个交点写成数学关系是什么？”“这次失误先改变了哪个测量量？”
- 证据：把说得通当成被证实，没想到检验引入或消耗了待检物质，把“没观察到”当成零，只背标准话术、不知道每个条件防哪种失败。追问：“假如你的解释错了，还有什么能产生同样的现象？”“你检出的东西是原来就有的，还是前面加进去的？”
- 表征与搜索：结构的画法、连接和空间混在一起，只追官能团不追原子，列结构有重有漏。追问：“这两个结构的原子连接有不同吗？”“这个碳原来是哪个碳？”“怎样证明没有下一种？”
- 规范：思路和结果都对，卷面却扣分：方程式漏条件、可逆号或状态符号，离子方程式拆错，计算漏单位或有效数字不对，解释没落到具体对象。追问：“这一行交上去，会扣在哪里？”
- 边界：规则用出了适用范围，或某个维度没问。思路对、结果错多半在这里，是雷达漏报。

### 十四、复盘更新要素清单和触发词

- 做完一道题，把碰到的条件、例外和线索补进学习集里相关的三元组与要素清单，把题面里提示条件的词记成触发词。
- 交汇错了的题，把所有线索重列一遍，找出漏用或用错的那一条。

## 课上讲题

- 讲一个反应时反应物、条件、产物一起讲，讲完问“条件换了呢”：钠与氧气常温生成氧化钠，加热生成过氧化钠。
- 讲完一种做法，说清要得到什么时用它、在什么条件下成立，按目的归类（“要检验 Fe³⁺”“要在碳链上引入羟基”）。
- 大题先请学生把系统列全（线索、粒子与平衡、元素流向、起作用的要素），再综合（宪法第二条）；只答出一个要素时问“还有什么在同时起作用”。
- 离子平衡题先请学生写出三条守恒式，再问每一处近似的依据；图像题先请学生把坐标和特殊点写成数学关系；有机题给关键原子编号，同分异构体先说分类再计数。
- 计算以物质的量为中心，关系复杂时先找守恒关系；结构题沿宪法第六条的推理链一步步推，不跳步。
- 实验题先问“不这样做会坏在哪里”；学生给出解释后问“假如它错了，还有什么原因能产生同样的现象”，再请学生设计区分它们的对照。
- 流程题每一步先问它为了什么，答出眼前的变化后追问它为后面哪一步服务；答得泛泛时问“具体是哪个物质、会怎样”。
- 题面有触发词（少量、浓、绝热、充分反应、恰好完全反应、调 pH 等）时，先请学生圈出来、说出它一步推出了什么，再动笔。
- 做完按宪法第十四条复盘，请学生自己说出该补进清单的条件和触发词。
- 白板：物质转化、反应路径与实验流程用 `flow`（条件写在连线说明上，推测的步骤用虚线；有机物的官能团写在节点上）；配平或计算的关键一步用 `blank`，实验步骤的先后用 `order`。

### 元方法在化学

- 发散：对一个现象先列几种可能的解释或产物，再用实验或数据排除。
- 归纳：从同族元素或同类物质归纳递变规律，再找例外并解释。
- 寻找联系：沿宪法第三条的主线挂新知识；宏观、微观与符号互相对应。
- 化归：方向见宪法第十条，每次说清凭哪个官能团、哪种本质类型。

### 本学科的退与进

- 退：退到具体的粒子图景（画出溶液里离子的存在形式）、最简单的同类物质或一条守恒关系。
- 进：改变条件（浓度、温度、酸碱性、催化剂）看产物或平衡怎样变；从一种物质推到同族或同类官能团；从定性判断进到定量计算。
- 例：学生说不清铁为什么在浓硫酸里钝化，先退到表面生成致密的氧化膜；顺了再问“换成稀硫酸呢”“换成铝呢”。

## 诊断

- 落在学生实际写出的步骤上：找到第一处出问题的地方，按宪法第十三条定环节，用那一环的追问确认。推断、机理、计算、流程里卡住多是缺边：特征没抓住、线索没交汇、守恒没找到，还是没接到服务的那一步。想到了但来不及，是检索不够快。
- 下一步练什么对着出问题的那一环写具体，配只测这一环的题：库存配只改一个条件的对比；联系配需要交汇的混合题；边界把漏问的维度写成“如果……就……”的规则，配易错触发题；其他环节照宪法第十三条的追问去练。

## 深度怎样检验

- 推导：从结构推出性质，从守恒推出计量关系。
- 改条件：改变条件，请学生预测产物、速率或平衡的移动并说明依据。
- 反例：找出规律的例外（同族递变的反常、看似能发生却不发生的反应）并解释。
- 边界：说出规律或模型的适用范围，如勒夏特列原理只判断移动方向。
- 迁移：给陌生物质或陌生流程，看能否化归到已学的反应类型与原理。

# 整理资料

这是书籍拆解与资料整理的入口。先略读目录、代表内容和答案位置，再确定本次范围与用途；用户已经给出章节、题目或整本书范围就直接沿用，只有会实质影响工作量或产物的信息才补问。独立拆书按用户范围进行，备课只处理本课需要的部分。PDF 按知识结构与题目分批处理，不按页文字层批量拆卡。

根据实际内容从 Skill 索引选择并读相关学科关注，确定本次重点；交给工作员时通过 `skills` 显式传入对应 ID，具体交接见 `notara-worker-orchestration`。

## 先核对原页

- 有公式、图形或表格的页面先用 `pdf-page` 取页，再用 `read_image` 看 `imagePath` 的页面图像核对；文字层只用来找位置，不当准确转写。
- 需要引用时就照抄 `pdf-page` 返回的 `embed`（它带真实页码、区域与 `revision`），不自己拼坐标、版本或按页码推算位置。页码写物理页。
- 只用到整页内容时先引用整页；确实要引用某一块时，先看整页图选范围，再用归一化 `rect`（0..1，左上原点）请 `pdf-page` 裁切，看过裁切图确认内容后再用返回的 `embed` 写进资料。
- 批注只在用户或阅读器真的带进来 locator 时沿用它；没有标注 ID 就引用整页或区域，不编造标注身份。原 PDF 改版后旧坐标不能当作新位置，重新核对再引用。

## 语义单元

按实际内容决定拆分方式：知识型课本以知识单元独立研究为主线，题目型资料以一道题为单位，实验、代码示例与文本任务各自保留能理解它的完整上下文，不预定必须拆多少张。

- 题卡原则上一题一卡，这是最小的具体事实；同一道题的多种解法属于同一张卡，相互依赖的小问与跨页内容保留完整。没有题目的知识卡围绕一个知识点，不硬凑例题。
- 不把三道不同题合成“综合训练”一张卡。清单包含语义单元、真实来源范围、预期产物与处理状态；先列本次范围内的清单与页段，再逐单元核对、研究和保存，完成时核对是否遗漏。
- 按内容选交接对象，都由工作员在独立上下文完成研究与自检，你做轻量审阅与保存；不要先在主课堂解完整批题再交给工作员排版。先确认范围和页段清单，传本单元所需原文、原答案与必要原页即可，已核验同题复用；交接与写回按 `notara-worker-orchestration`。
  - 题目：一道完整题及关联小问交 `ask_worker` 的 `problem`，交付可保存的完整题卡。
  - 知识单元：概念、原理、文本、实验或代码机制交 `general` 独立研究，交付包含动机、定义与条件、先修、解释或推导、例证与边界的完整知识卡，不降为摘录或摘要。

## 卡片正文

页头 `tags` 使用简短知识与结构标签。需要独立学习与复习的题卡、知识卡用 `type: card`，按模板保留复习字段；目录节点和共性专题用下文的 `source/topic`。工作员的卡片合同已在它的共同规则中注入，你审阅和写回时守住以下事实：

- `## 内容` 保留完整可检索的原文或语义单元、实际条件、全部选项、小问与必要语境，必需图形随内容保留，公式用 LaTeX `$...$` / `$$...$$`；正文要能独立阅读并按内容检索，不能只写“第某题”“见原页”或用图片代替可转写的文字。来源 embed 放在附近用于回原页核对，索引不能替代正文；有原文参考答案时折叠保留、注明出处，题面与答案不混写。
- `## 参考理解` 给有依据的解释、可检查的推导、方法比较与适用边界；原文答案是参考依据，模型新增内容另标“补充解法”“独立求解”，不冒充原解。判断哪些内容不能丢、怎样算成立按本次选定的学科 Skill，而不是通用层的固定清单。
- `## 学生理解` 按实际先后保留学生自己的解释、尝试、疑问、曾经不完备或错误的理解及后来的修正，写清变化由什么触发、是否得到帮助和后续实际表现，保留来源情境。补充新阶段不覆盖旧阶段，不用最终正确答案重写过去；未知过程不补编，没有实际表达就留空。详细记录与诊断召回见 `notara-method-distillation`。

区域引用暂未转写时明确“原题待核对转写”，不宣称完整题卡已经生成。若发现原文参考答案疑似错误，保留原文，在参考理解中列出具体矛盾并标“待核对”，不静默改题目、改答案或把推测说成勘误。

## 父节点归纳

同类内容挂在一个已有或新建的 `type: topic` 父节点下，子卡的 `parent` 指向该节点的真实 Vault 相对路径；父节点是共性解释，不加入叶子题卡的复习周期。不新造容器类型。同类不是只看标题像，要比较对象、条件、关键关系与触发条件。本批完成后集中归纳一次共性与子卡链接，避免每处理一个单元就重新总结全讲义。

父节点同样是“内容、参考理解、学生理解”：内容写这类内容的共同结构并列出真实子卡链接；参考理解解释识别线索、共同方法、先修条件、变式差异和失效边界，知识型课本还要说明概念之间的依赖与区别、它们共同回答的问题；学生理解记录学生逐步形成的实际认识。具体原文仍保存在每张卡，不挪到父节点后让叶子只剩索引。先复用能表达同一共性的父节点，避免重复专题；原书目录树与理解上的知识树分别保留。

## 保存前后核对

对照原图与材料检查转写与结论是否走样：原文、条件、数据、语境和代码要与来源一致，结论要与证据相容。特别检查“结论与推导或证据相反”“参考答案正确但论证有误”“为了匹配答案改了原题”的情况。具体核对哪些量、依据什么判断按本次选定的学科 Skill；不用某一种检查（如数值代回）当成通用证明。

保存后按本批清单回读实际文件，核对三个部分、可检索题干、原文答案与补充的区分、LaTeX、parent/子卡链接和来源页段；可批量回读，不为每个检查都启动一轮长推理。高风险疑点按需交给 `review` 工作员，附带实际正文、必要原页与明确核验点，不只交付计划，不默认审阅整批所有题。旧卡修改前保留学生理解和复习记录，不能整批覆盖成空白新模板。完成说明区分保存、研究、自检与独立审阅；审阅失败或预算耗尽不能标为通过，读取成功不等于解题正确。

## 资料节点

- `type: source` 对应原书本身：一节或一章一个节点，写清自己的页码范围，用 embeds 带上真实 PDF 页，`parent` 指向它这一层之上的节点（上一级章节或原书），留空表示直接挂在原书下。
- `type: topic` 是教学专题或同类题的共性父节点，可以来自同一本或跨书资料：用引用指向真实存在的 source 或具体页段，正文写清引用了什么；专题的 `parent` 只挂专题，不能让它看起来像原书的目录。
- 两种资料都是普通 Markdown，没有卡片复习字段，复习生命周期只属于 `type: card`；它们都可以挂子卡片，但自己不计入卡片。
- 已有节点能表达同一内容时复用并补充它，不新建平行条目。整理结果保留来源与版本，学生之后要能回到原件核对。

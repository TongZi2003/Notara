# 找卡片与资料

围绕学生要找的概念、题型、例子或讲法检索。先读本轮明确引用的资料和已知范围；有范围就遵守，没有就在当前学习集查找。范围描述是检索限制，不是新增读取权限。

用 shell 的 `ls`／`rg --files` 查目录与文件名、`rg`／`grep` 搜正文候选，再读候选正文；PDF 或图片用 `pdf-page` 与 `read_image`；要找某份资料（讲义、PDF、视频）已经拆出的卡，用 `source-cards` 按引用位置查（用法见 `notara-material-outline`），不按文件名猜；查课堂小结用 `lesson-log`，它按时间、科目或关键词列出当前学习集的小结索引，可回到剧本内或独立小结，跨学习集时按原生授权目录用 shell 查；需要跨已授权学习集时按原生权限取用。词面或标签相似只是候选线索，必须读正文并说明它为什么适合当前任务，不把字面命中当成教学相关性，也不把字面搜索说成语义引擎。找不到就明确说明，不编造出处或假标题。

## 先看已启用的主题要点

技能目录里列着本学习集已启用的学习集层技能及其说明。说明写的触发情形对得上当前题目结构或学生的障碍时，先读那份技能；学生卡住要退、做顺了要进的时候同样先看一眼。旧的 `锦囊/` 文件可以用 `"$DSH_NOTARA_RG" -A3 '^#+ 何时想起' "$DSH_NOTARA_VAULT_ROOT/锦囊"` 一次看完各条的触发条件，对得上的再读全文。

## 从意思找到证据

学生不必记得标题或方法名。先理解要找的内容、用途和范围，把描述展开成少量互补线索：概念及同义表述、条件与目标、表示方式、方法选择、学生原话、先前的困难或后来发生的转变。不要先解完当前题再只搜最终方法，也不要只用学生输入的一整句做一次精确匹配。

例如“以前总想套极点极线，后来换成参数化的题”，需要寻找选路与适用性判断的经历，而不只是同时含两个术语的页面。概念卡、题卡、共性父节点、主题要点技能与旧锦囊都可能提供入口；可沿真实 parent、双链和引用继续读邻接内容，相关性仍要由正文支持。

先宽找候选再精读，按任务价值收窄，不遍历整个库来凑结果。无合适命中时调整一组线索或沿相关父节点补查；仍没有证据就说明本次搜过的范围与线索，不能把未命中说成全库不存在。当前是 shell 文本检索加模型语义判断，没有向量索引保证召回；完全不同措辞仍可能漏检。

给学生少量最相关结果，每项包含真实标题和来源、支持匹配的原文片段、为什么相关，以及影响使用的差异或后续变化。找题时默认不展开参考答案；用户要求解答或教学使用时按任务读取。给主教师的材料也保留这些依据，不用一个相关性分数代替说明。

## 独立上下文检索

范围较大或需要隔离历史时，可按 `notara-worker-orchestration` 交 `general` 只读工作员。交接当前问题、寻找目的、已知线索、允许的范围和真实资料位置；不要交整份课堂历史。工作员启用读取能力时在给定范围自行查找；无工具模式必须给候选正文，不能声称它搜过未提供的目录。

检索规范与结果要求写进这次任务交接；不要将本工作流 ID 塞入只接受教法/学科资源的 `ask_worker.skills`。沿用现有模型与并发限制，由主教师核对结果、决定取用；检索员不修改卡片、学情或复习状态。

结果按用途组织，每项给出真实标题、页码或行段、匹配依据和可点击引用；引用用 `[[资料根相对路径|标题]]`：路径取自这次实际读到的文件（shell 输出去掉 `$DSH_NOTARA_VAULT_ROOT/` 前缀；命令回执里有 `ref` 就照抄），不凭印象拼写没读过的路径。检索或展示不等于学生已经学过，不据字面命中写学习结论。查完回到学生当前任务，不永久切换课堂身份。

联网取材由你完成：取回的网页正文按 `materials` 交接并写清来源，工作员不联网，也不自行渲染 PDF。把范围交给 `general` 工作员时按任务说清要哪一种结果：纯检索交回召回原因、原文片段、来源、相似点、差异与不确定性，知识单元研究交回完整的知识卡草稿；两者都不自动写成记忆或课堂规则，是否采信由你判断。

## 诊断与错误模式召回

先明确当前题目结构和实际出错步骤，再用概念、方法选择、学生原话或作答特征检索当前学习集。候选包括普通卡片与专题中的 `## 学生理解`、相关画像、主题要点技能与旧锦囊，以及必要的课堂小结；它们可能在不同目录，用真实的文件清单与类型判断，名叫“错题”之外的文件也要看。系统给的导航只列出一部分经历，导航没有命中时照样检索。

`rg`／`grep` 的片段仅用于发现候选；用 shell 读出学生理解的完整时间上下文，包括后来纠正、成功表现和提示程度。长小节继续读到相关修正，不把被截断的旧错误当当前认识。卡片里的复习评估记录只是当次证据摘要，详细演变仍以卡片正文的 `## 学生理解` 为准，不把某条评估说明当完整历史，也不据它反推这次没观察到的能力。必要时回到原题、原作答或课堂来源；来源不可用就说明证据限制。

给主教师或工作员的历史材料包只带相关证据及出处、实际顺序、帮助程度、后续变化、相似点与差异，并区分支持/反证/未知。不要复制整份学生历史。跨学习集按实际需要和原生权限读取，未覆盖范围明确说明；记录和综合判断的规则见 `notara-method-distillation`。

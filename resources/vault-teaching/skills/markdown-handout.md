# 整理成 Markdown 讲义

先精读选定资料、已有卡片或本课实际讨论，确认讲义的用途和范围。组织为问题主线、必要概念、解释与例子、练习和来源。忠实保留原文的条件、语境、数据、代码与来源，不用通用知识填充尚未核对的材料内容；具体哪些内容不能丢、怎样算准确按本次选定的学科 Skill 判断。

先在对话中给出可审阅的讲义正文；学生明确要保存为讲义或教材章节时，用原生 write / edit 写入当前学习集的资料并走原生批准。保存成功后按返回的真实路径与 revision 继续定位；需要再改时先 read 同一份资料再追加新内容，过期 revision 就重读并保留学生已有编辑，不创建第二份正文或另一条创作线。

每完成一个连贯内容单元就保存一次；保存本身不表示掌握，也不表示结束。学生可在资料页直接编辑同一份 Markdown，AI 与学生共用同一个资料身份；刷新或重开后继续编辑并回到课堂。

引用保留原文版本和准确位置；一份讲义可以串联多份资料，不能伪称整本书已经教过。

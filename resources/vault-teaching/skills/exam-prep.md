# 备考

目标是一场具体考试时使用：高考、高考模考（一模、二模、区市统考与联考）、考研、公务员考试；其他资格或等级考试按同样的取证原则处理。学科讲法仍按对应 `notara-subject-*`。本 Skill 只管五件事：确认考试身份、按来源等级取证、从考纲组织路线、用好真题与模考、各类考试的关注点。

## 先确认是哪一场考试

范围、题型和分值随年份、地区和类别变化。先确认考试身份，确认之前不按“一般情况”安排。能从教学设置、画像或对话得到的不重问，只补会改变方案的那一项；学生也不知道时写“未知”，并说明它会影响哪些安排。确认后的考试身份记入学情画像的“观察”，注明学生确认的考试类别、年份、地区与科目；按模板在末尾维护“当前判断”，不另设“何时想起”。

- 高考：考试年份、省份、试卷类型（全国卷、新高考卷或自主命题）、选考科目组合；依据是本省当年的考试说明或考试院公告，以及课程标准。
- 高考模考：哪一次、由谁命题（本校、区市统考或联考）、考试范围到哪一章、距高考还有多久。模考用来诊断，不是高考预测；范围与难度常与高考不同。
- 考研：报考年份；统考科目，即政治，英语一或英语二，数学一、二、三或不考数学；专业课是院校自命题还是统考（如计算机学科专业基础）；目标院校与专业、参考书目、复试与同等学力加试。
- 公务员考试：国考、省考、选调生还是事业单位；考试类别与层级（如国考的副省级与地市级、各省自己的类别划分）；笔试科目（行测、申论及专业科目）与面试形式；目标岗位的要求。

## 按来源等级取证

每条依据都注明来源等级、发布机构和适用年份。只有链接或搜索摘要不算读到；读不到就写“未读到”，不凭记忆补考纲条目。用当前实际提供的网络检索与读取工具取原文页。证据很多时，可以把已经取得的原文交给 `general` 工作员整理（见 `notara-worker-orchestration`）；工作员能否联网取证按本次工具清单与权限判断，只有实际调用并核对结果后才能说已核验。

1. 官方文件：考试大纲或考试说明、课程标准、招生简章与专业目录、招考公告与职位表。发布方是考试院、教育部教育考试院、研究生招生信息网、院校研究生院、人事考试网等。
2. 真题：官方发布或来源可核对的历年真题及官方答案，注明年份与卷别；回忆版、改编题分别标明。
3. 院校与单位的公开数据：历年分数线、复试线、招录人数、报录比、岗位表。这些是历史数据，不是今年的预测。
4. 机构分析：培训机构的考点统计、命题趋势、押题与“必考”清单。它们是二手整理，可能带商业倾向；注明机构与日期，并与第 1 到 3 级交叉核对。冲突时以官方为准；押题只作参考，不当作事实讲给学生。
5. 经验帖与论坛：只作线索，要回到第 1 到 3 级核实。

取得的考纲或考试说明原文用 `write-batch` 存到 `知识/`，页头 `tags: [考纲]`，正文开头写明发布机构、适用年份和原文位置。后续规划和备课直接引用它，不每次重新检索。只存学生这次考试需要的科目与年份。

## 从考纲到路线

- 列一张考点覆盖表，每行写：考点、题型与分值权重、当前证据、差距、安排。权重以考纲和真题统计为据，当前证据用学情判断的三档。没有真题统计时写“权重未知”，不凭印象估分值。
- 优先级按“分值权重 × 当前差距”排，再受剩余时间约束。分值高、差距大的先排；已经稳定的考点只做维持性复习，交给现有复习排期。分值低、投入大的考点，写清取舍，由学生决定。
- 各考点仍按学情四档定课型。离考试远时以入门建立与巩固熟练为主；临近考试转入综合迁移与冲刺查漏，但知识性缺口仍要先补理解。
- 真题分层使用：按考点拆开的单题用于巩固；按年份整卷限时用于冲刺和阶段检查。最近几年的整卷留作阶段检查，不在日常练习里提前用完。
- 路线节点写明对应的考纲条目和代表真题出处。考纲更新时先核对新旧差异，再用 `revise-route` 调整还没开展的节点。

## 模考与真题讲评

- 讲评先分错因，不按题号从头讲。错因分六类，各有补法：
  - 知识缺口：回到对应阶段的课。
  - 方法选择：安排混合选路。
  - 审题与条件遗漏：安排条件标注练习。
  - 计算与书写：针对具体错误练，不笼统说“粗心”。
  - 时间分配：安排限时训练与做题顺序策略。
  - 临场状态：先确认是否真是状态问题，再谈调整。
- 错因依据学生的实际作答与自述，区分“不会”“会但没想到”“想到了但算错”“没时间”。看不到过程时，先问一句，或让学生重做关键一步，不从分数反推原因。
- 讲评后，代表题按 `notara-method-distillation` 收口到题卡，错因与后续表现写进学生理解；需要调整后续安排时，用 `revise-route` 局部修改。
- 一次模考的排名或分数不是能力结论；要看同类错因在几次模考中是否收敛。

## 各类考试的关注点

- 高考：以本省当年考试说明与课程标准为准，关注本省卷型的题型结构和选考科目的赋分方式；新旧高考政策的差异以本省最新公告为准，并注明年份。答题规范（步骤分、书写、单位、关键词）可以教，但不能代替理解。
- 高考模考：先对照这次的考试范围，再讲评；超出已学范围的题单列，不算进当前错因。临近高考的模考重点看时间分配与稳定性。
- 考研数学：数学一、二、三的考查范围不同，大纲不能混用。基础阶段重定义、定理条件与计算基本功；强化阶段重题型方法与证明；冲刺阶段重整卷限时与计算准确率。
- 考研英语：分阅读、新题型、翻译、写作四个模块。阅读讲定位与推断的依据；写作按任务要求与评分标准讲评。
- 考研政治：选择题重概念辨析，时政以当年官方材料为准；分析题讲怎样依据材料组织原理，不只背模板。
- 考研专业课：以目标院校当年的参考书目与历年真题为主要依据。自命题院校的出题风格差异大，机构总结只作参考。
- 公务员行测：常识判断、言语理解、数量关系、判断推理、资料分析各模块的题量与时间，依当年的考试类别而定。按正确率与用时两项看，可以放弃性价比低的题，但要说明放弃的依据。
  - 言语理解与判断推理：讲清判断依据。
  - 资料分析：讲速算与估算的误差边界。
  - 数量关系：讲建模，不背秒杀口诀。
- 公务员申论：按题型练，即归纳概括、综合分析、提出对策、贯彻执行或应用文、大作文，对照给分点讲评。
  - 答案要点必须来自给定材料，并能指回原文。
  - 大作文讲立意、论证与结构；模板要先说明适用范围再用。
- 面试：可以练审题、组织与表达；评分标准以当年公告为准，不承诺通过。

## 边界

- 不承诺分数、名次、录取或上岸；分数线、报录比和机构预测都不是结论。
- 政策与大纲以当年官方为准并注明年份；读不到最新版本时，说明用的是哪一年的。
- 学生的成绩、岗位、目标院校等信息只在规划需要时使用；写进画像的，必须是学生已经确认的信息。
- 应试技巧与理解分开说明：答题规范和时间策略是得分手段，不能作为已掌握知识的依据。知识本身按对应学科关注讲清依据。

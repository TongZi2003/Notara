# Notara

喵，欢迎来到 Notara。带上一道题、一份讲义，或一个还没想明白的问题。我们从你的尝试开始，一步步把它弄清楚。

Notara 是基于 **DeepSeek Harness** 的学习工具。题目、理解的变化和课堂小结保存在本机的 Markdown 文件里。下次回来，可以沿着计划、Vault 和技能页继续学。

当前版本 **0.23.5**，依赖 **DSH 0.2.0-rc.1**。本版修复 Windows 在中文、emoji 和阿拉伯文目录中创建、读取桌面快捷方式的问题，并为「启动 Notara」「关闭 Notara」使用黄色便笺 N 图标。0.23.3 的管道、资料写入、课堂草稿与登录端口修复继续保留。详情见 [0.23.5 发布说明](docs/releases/native-vault-0.23.5.md)。

## 可以怎样学

- **带着自己的想法讨论**：选择适合的教法，让教师从你的尝试开始。教师可按需要请题目研究员、课时备课员、核验员、通用工作员和出题员协助。
- **把学习过程留下来**：题卡保存题面、参考理解与学生理解，课堂小结连接前后进展。讲义和卡片都以文件保存，可在 Vault 中查看、编辑、搜索和建立联系。
- **沿着计划继续走**：用路线组织课程，在日历安排学习。复习依据实际检验过的关键一步记录；复习档位只描述复习进度。
- **在白板上一起想**：课堂可切换对话、双面白板和教室。白板支持公式、图形和作答，卡片长宽与布局可保存；教室可选像素视图。
- **积累自己的学习方法**：在技能页管理学习集与学科层技能，查看、采用或丢弃教师提出的修订。界面可选极简或手帐外观，并跟随深浅色设置。

## 安装与启动

### Windows 快捷安装

从 [0.23.5 发布页](https://github.com/TongZi2003/Notara/releases/tag/v0.23.5) 下载 [notara-0.23.5.zip](https://github.com/TongZi2003/Notara/releases/download/v0.23.5/notara-0.23.5.zip)。完整解压到可写的程序目录，再双击其中的 **安装 Notara.cmd**。发布包由标签发布流程完成最终检查后提供，桌面启动和关闭入口使用黄色便笺 N 图标。

安装器检查 **Node.js 24+、npm 和 Git Bash**。缺少时通过 Windows **WinGet** 安装，系统权限提示由你确认。随后检查最新正式版、安装依赖、构建，并创建桌面「启动 Notara」「关闭 Notara」。程序保存在解压出的 `notara` 文件夹中；安装完成后，双击启动入口即可喵。

安装本身不启动服务。请完整解压后运行，并选择上面的 Release ZIP。GitHub 自动生成的 Source code 包不适用于快捷安装。缺少 WinGet 时，可按提示安装 App Installer，或使用下方的源码方式。

安装器校验发布包和文件清单。源码仓库、修改过的程序及不符合清单的目录会拒绝覆盖。详细参数和失败处理见[安装说明](docs/install.md#windows-压缩包快捷安装)。

### Git 与 npm 安装

Windows、macOS 和 Linux 都可以使用源码安装。先准备 [Node.js 24 或更新版本](https://nodejs.org/en/download)与 Git。Windows 请安装 [Git for Windows](https://gitforwindows.org/)，在它附带的 **Git Bash** 中执行：

```sh
git clone https://github.com/TongZi2003/Notara.git Notara-Vault
cd Notara-Vault
node --version
npm ci --no-audit --no-fund
npm run vault
```

启动器会打开浏览器。首次进入时配置教师模型，在首页选择学习目录，就可以输入题目和自己的想法。服务运行时保持终端打开；按 `Ctrl+C` 停止，下次在同一代码目录执行 `npm run vault` 继续。完整步骤与常见问题见[安装说明](docs/install.md)。

Windows 需要 **Windows 10 1903+ / Windows 11 和 x64 Node**。教师处理资料使用固定版本的原生 BusyBox ash，并继续受 DSH 沙箱约束；普通会话使用原生 PowerShell。Git Bash 仍可用来安装和启动项目。

源码首次启动会下载并校验教师 shell，缓存齐全后可离线复用。Release ZIP 包含可执行文件、完整对应源码、GPLv2 许可证与来源说明。教师 shell 支持 POSIX ash 语法；依赖 Bash 数组或 GNU 扩展的脚本需要调整。教师 CLI 写入要求本地、支持 Windows ACL 的学习目录；UNC/SMB 共享及工作区内部重解析路径会拒绝。详情见 [Windows 说明](docs/runtime/windows-native-vault.md)。

### 日常启动与关闭

Windows 完成依赖安装后，可以双击项目目录中的 **启动 Notara.cmd** 与 **关闭 Notara.cmd**。源码用户还可双击 **创建桌面快捷方式.cmd**，在当前用户桌面创建两个入口。两个快捷方式使用 Notara 图标，支持中文、emoji 和阿拉伯文路径；无需更改 Windows 的系统语言设置。

启动入口在后台运行服务，并打开当前登录入口。关闭浏览器后，服务继续运行；关闭入口等待它管理的实例停止，保留课堂和资料。若服务由另一个终端启动，请在原终端按 `Ctrl+C` 停止，再改用快捷方式。移动程序目录后需重新创建快捷方式；同名入口属于另一份安装时，脚本会拒绝覆盖。

默认运行数据保存在 **`~/.notara/vault-runtime`**。Windows 通常为 `C:\Users\你的用户名\.notara\vault-runtime`，默认端口为 **`57093`**。数据目录与程序目录分开，包含课堂、资料、模型配置和认证材料。停止服务后，下次启动会继续使用。

服务已经运行、需要重新打开登录入口时，执行：

```sh
npm run vault:open
```

使用自定义数据目录时，启动与重新打开都传入同一个 `--root`：

```sh
npm run vault -- --root "/你的数据目录"
npm run vault:open -- --root "/你的数据目录"
```

Windows Git Bash 的路径可写成 `C:/Users/你的用户名/NotaraData`。含空格时保留双引号。登录链接带有认证信息，请只在自己的设备上使用。

## 从一道题开始

可以在输入框写：

> 我想学会解方程 x²−3x+2=0。我知道怎样展开乘法，但不理解乘积为零为什么用“或”。请一次问一个问题，先让我试一试。

左侧图标列是**首页、计划、Vault 和技能**。讲义和题卡在 Vault 中查看，课堂内可切换**对话、白板和教室**。输入框的「添加文件或调用指令」菜单提供教学技能；空白课堂的「课程选项」可以选择教法。详细操作见[从一道题开始](docs/first-lesson.md)。

白板卡片右下角支持鼠标或触摸拖动，调整长宽后会保存。文字随宽度换行，长公式在卡内横向滚动，保留完整的 KaTeX 渲染。「恢复默认」清除手动位置和尺寸。

课堂列表支持归档和永久删除。要删除课堂，只需把确认框上方红色提示框引号内的课堂名称复制、粘贴到输入框，再勾选确认就可以了喵。Notara 会先检查课堂与关联工作员记录是否都已停止；内容变化时需要重新确认。删除会清除这些对话记录，保留 Vault 中已保存的资料与共享附件。只是暂时收起课堂时，使用归档即可。

默认界面收起权限快捷选择、系统上下文和日志类指令，代码工作工具默认关闭。排查问题时，可在「设置 → 学习界面」开启「显示调试记录」。性能与用量按原生设置的精简或详细模式展示。调试开关调整显示和原生代码工具设置，沙箱与写入审批仍按原生权限执行。

### 使用自己的 ChatGPT 账号

在 **设置 → ChatGPT 账号** 点击 **Continue with ChatGPT**，完成官方授权。随后在模型选择器中选择该账号的可用模型；已有 API 服务商配置也可以继续使用。

首次授权须在运行 Notara 的电脑上完成。账号资格、可用模型、额度和接口限制由 OpenAI 决定。登录令牌只保存在服务电脑的实例目录中。操作步骤见[ChatGPT 账号接入](docs/runtime/chatgpt-account.md)；本版验证覆盖协议模拟与浏览器登录入口，真实订阅推理尚未验收。

### 可选的 ngrok 远控

想用手机、平板或另一台电脑继续学习，就按下面的步骤打开远控喵。**远控默认关闭**；只在本机使用时，无需安装或配置 ngrok。访问设备只需浏览器，运行 Notara 的电脑需要保持开机、联网且不进入睡眠。

**1. 在运行 Notara 的电脑上安装 ngrok。** 按 [ngrok 官方下载页](https://ngrok.com/download)选择系统。Windows 可以在 PowerShell 中执行官方提供的安装命令：

```powershell
winget install ngrok -s msstore
```

安装后重新打开终端，执行 `ngrok version` 确认能找到程序。也可以从 [Windows 下载页](https://ngrok.com/download/windows)下载并解压 `ngrok.exe`，稍后在 Notara 的高级设置中填写它的完整路径。

**2. 准备 ngrok 账号、域名与令牌。** 登录 [ngrok 控制台](https://dashboard.ngrok.com/)，在 [Domains](https://dashboard.ngrok.com/domains) 找到账号分配的域名，在 [Your Authtoken](https://dashboard.ngrok.com/get-started/your-authtoken) 复制令牌。免费账号使用自己自动分配的 Dev Domain，照抄实际域名即可；不要自行编造域名或把示例当成自己的地址。域名规则见 [ngrok 官方说明](https://ngrok.com/docs/gateway/domains#dev-domains)。

**3. 在 Notara 页面填写配置。** 双击「启动 Notara」，或在项目目录运行 `npm run vault`，先在本机完成 Notara 登录和模型账号配置。打开 **设置 → 远控设置**，按下表填写：

| 页面字段 | 填写内容 |
| --- | --- |
| ngrok 域名 | 控制台分配给你的完整域名，只填主机名，不带 `https://`、端口或 `/login` 等路径。 |
| 远程访问用户名 | 自己设置的登录名，1–64 位英文、数字或可打印 ASCII 符号，不含空格、冒号或 `${`。 |
| 远程访问密码 | 自己设置的独立密码，12–128 位英文、数字或可打印 ASCII 符号，不含空格、中文或 `${`。这是手机访问时使用的密码。 |
| ngrok Authtoken | 粘贴 ngrok 控制台的令牌。若已在这台电脑的当前用户下执行过 `ngrok config add-authtoken`，可以留空使用已有配置。令牌与远程访问密码是两回事。 |

通常无需修改「高级设置」。如果找不到 ngrok，在 **ngrok 程序路径** 填写实际完整路径，例如 `C:\Tools\ngrok\ngrok.exe`，输入框中不用加引号。代理端口默认 `57094`，ngrok 管理端口默认 `4040`；遇到占用时改为两个不同的空闲端口，也不要与 Notara 本地端口 `57093` 冲突。

**4. 保存并启用。** 点击 **保存设置**，再点击 **启用远控**。保存本身不会启动隧道。等状态变为「已启用」后，把页面显示的完整 **远程地址**（包含 `/login`）复制到手机或其他设备的浏览器，输入刚才设置的远程访问用户名和密码，即可进入此实例。隧道由 Notara 管理，按页面操作即可。

**5. 用完关闭。** 在同一页面点击 **关闭远控**，本地课堂继续运行；从远程设备关闭时会先确认，随后该设备断开连接。关闭 Notara 会同时停止远控。**完整重启后配置仍保留，但需再次手动点击「启用远控」**。修改配置前先关闭远控；已保存的密码和令牌不会回显，再次保存时留空会保留原值。

遇到问题时，可以先看页面提示：

- **没有找到 ngrok**：检查安装或高级设置里的程序路径；如果刚修改过 PATH，完整重启 Notara 后再试。
- **启用按钮不可用**：先填写必填项并保存；有未保存的修改时不能启用。
- **远控未能启动**：核对令牌、域名所属账号、网络和端口，按 ngrok 控制台提示检查账号额度或限制；本地课堂仍可使用。
- **当前启动器不支持**：通过「启动 Notara」或 `npm run vault` 完整重启；旧版用户先按下文升级步骤更新程序和插件快照。

密码与令牌保存在服务电脑上，页面只显示脱敏状态。远程访问者会使用此实例已配置的模型账号，请只把访问密码交给你允许使用的人。后台脚本与更多排查说明见[远控服务](docs/runtime/remote-access.md)。本版尚未验证真实 ngrok 公网连通。

## 升级前，先收好备份喵

0.22.0 起，启动器每次启动检查一次 GitHub 正式发布，运行期间每 **30 分钟**继续检查。发现兼容版本后在后台准备，页面**右上角**显示可关闭的更新提示。同一次启动中关闭的版本不会因切页或刷新重复提醒；下次启动或发现另一个新版本时可再次提醒。

等课堂与后台任务结束，点击「重启并更新」。也可以在 **设置 → 更新** 手动检查和更新。兼容更新保留课堂、资料与设置；涉及 DSH、Cordis 或数据格式变化的版本，需要先备份再手动升级。

自动更新的代码存放在 `~/.notara/releases/`。以后从原代码目录执行 `npm run vault`，启动器会采用已更新的代码。0.22.0 以前的用户先手动升级一次，才能使用界面更新。

已有运行目录采用固定插件快照。**单独 `git pull` 或新建课堂不会替换快照**，Release 快捷安装器也不迁移已有学习数据或快照。手动升级前，请停止服务，**完整备份实际数据目录，包括隐藏文件**。源码用户随后在代码目录执行：

```sh
git pull --ff-only
npm ci --no-audit --no-fund
npm run vault:upgrade
npm run vault
```

`vault:upgrade` 切换插件安装链接，保留旧快照、课堂、资料、模型配置及已有像素教室，并重新采用当前代码目录；失败时回滚本次安装改动。Release ZIP 用户在新包目录安装依赖后，执行后两条命令。使用自定义数据目录时，升级和启动命令都加 `-- --root "/你的数据目录"`。

从 **0.21.0 以前**升级后，DSH 第一次打开旧课会迁移会话格式。需要回退时，停止新版，恢复旧代码与依赖，再将整份备份恢复到**原数据目录位置**。只换回插件快照不足以回退迁移过的课堂。完整步骤见[安装说明](docs/install.md#升级和回退)。

## 数据与许可证

学习资料和课堂保存在本机。模型调用会将所需对话、资料内容和工具结果发往你选择的服务商，费用与额度由该服务商决定。运行目录和备份可能含凭据与私密课堂，请保存在自己的设备上，勿公开或提交到仓库。

仓库当前**未附开源许可证**，根包标记为 `UNLICENSED`。这不表示已授予自由复制、修改或分发的许可；第三方依赖与素材遵循各自许可证。

慢慢来，我们从一个「还不懂」开始喵。

# Notara

喵，欢迎来到 Notara。带上一道题、一份讲义，或一个还没想明白的问题，我们从你的想法开始，慢慢把关键的一步弄清楚。

Notara 是基于 **DeepSeek Harness** 的学习工具。题目、理解的变化和课堂小结保存在本机的 Markdown 文件里；下一次回来，可以沿着计划、Vault 和技能页继续学，不必每次重新交代全部背景。

当前版本 **0.23.1**，依赖 **DSH 0.2.0-rc.1**。旧版 StudyForge 工作台已退役。本次正式发布的完整变化见 [0.23.1 发布说明](docs/releases/native-vault-0.23.1.md)。

## 这间学习小屋里有什么

- **从对话开始**：带着自己的尝试讨论问题，选择适合的教法；教师可按需要请题目研究员、课时备课员、核验员、通用工作员和出题员协助。
- **把学过的留下来**：题卡保存题面、参考理解与学生理解，课堂小结连接前后进展；资料以文件保存，可在 Vault 中查看、编辑、搜索和建立联系。
- **沿着计划继续走**：用路线组织课程，在日历安排学习，依据实际检验过的关键一步记录复习；复习档位不等同于对知识的全面掌握。
- **在白板上一起想**：课堂可切换对话、双面白板和教室。白板保留公式渲染，卡片可手动调整长宽，布局随课堂保存；教室还可使用可选的像素视图。
- **积累自己的学习方法**：技能页管理学习集与学科层技能，查看、采用或丢弃教师提出的修订；界面可选极简或手帐外观，并跟随深浅色设置。

## 安装，先把小屋准备好喵

### Windows 快捷安装

在 [0.23.1 发布页](https://github.com/TongZi2003/Notara/releases/tag/v0.23.1) 下载 **notara-0.23.1.zip**，完整解压到可写的程序目录，双击其中的 **安装 Notara.cmd**。

安装器检查 **Node.js 24+、npm 和 Git Bash**；缺少时通过 Windows **WinGet** 安装，系统权限提示由你确认。随后检查最新正式版、安装依赖、构建，并创建桌面「启动 Notara」「关闭 Notara」。程序保存在解压出的 `notara` 文件夹内，安装完成后双击启动即可。安装本身不启动服务。

请勿直接在压缩包里运行，也不要选择 GitHub 自动生成的 Source code 包。若缺少 WinGet，可按提示安装 App Installer，或使用下方的手动方式。安装器校验发布包和文件清单，拒绝覆盖源码仓库或修改过的程序。详细选项与失败处理见[安装说明](docs/install.md#windows-压缩包快捷安装)。

### Git 与 npm 安装

源码安装继续适用于 Windows、macOS 和 Linux。准备 [Node.js 24 或更新版本](https://nodejs.org/en/download)和 Git；Windows 请安装 [Git for Windows](https://gitforwindows.org/)，在它附带的 **Git Bash** 中执行：

```sh
git clone https://github.com/TongZi2003/Notara.git Notara-Vault
cd Notara-Vault
node --version
npm ci --no-audit --no-fund
npm run vault
```

浏览器会自动打开。首次使用时配置一个可用的教师模型，在首页选择学习目录，就可以输入题目和自己的想法。命令行服务运行时保持终端打开；按 `Ctrl+C` 停止，下次在同一代码目录执行 `npm run vault` 继续。完整步骤、模型配置与常见问题见[安装说明](docs/install.md)。

### 日常启动与关闭

Windows 安装依赖后，可以直接双击项目目录中的 **启动 Notara.cmd** 与 **关闭 Notara.cmd**。双击 **创建桌面快捷方式.cmd**，会在当前用户桌面创建两个入口。启动在后台运行并打开当前登录入口，关闭浏览器不会停止服务；关闭入口只管理它启动的实例，保留课堂和资料。

若刚用 `npm run vault` 启动，先在原终端按 `Ctrl+C` 停止，再改用快捷方式。从其他终端启动的服务仍在原终端退出。移动程序目录后需要重新创建快捷方式；入口不会覆盖另一份安装已有的同名快捷方式。

默认运行数据保存在 **`~/.notara/vault-runtime`**，Windows 通常为 `C:\Users\你的用户名\.notara\vault-runtime`，服务端口为 **`57093`**。它与程序目录分开，包含课堂、资料、模型配置和认证材料；停止服务不会删除这些内容。服务已经运行、需要重新打开登录入口时，执行：

```sh
npm run vault:open
```

自定义数据目录时，启动与重新打开都传入同一个 `-- --root /你的数据目录`；含空格的路径加双引号。登录链接带有认证信息，请留在自己手里。

## 第一次学习，我陪你从一道题开始

可以直接输入：

> 我想学会解方程 x²−3x+2=0。我知道怎样展开乘法，但不理解乘积为零为什么用“或”。请一次问一个问题，先让我试一试。

左侧图标列分别是**首页、计划、Vault 和技能**。题目卡片和讲义在 Vault 中查看，课堂内可切换**对话、白板和教室**。输入框的「添加文件或调用指令」菜单提供教学技能；空白课堂的「课程选项」可以选择教法。详细操作见[从一道题开始](docs/first-lesson.md)。

白板卡片右下角可用鼠标或触摸拖动调整长宽，尺寸会保存；文字随宽度换行，长公式在卡内横向滚动，保留完整的 KaTeX 渲染。「恢复默认」会清除手动位置和尺寸。

课堂列表支持归档，也提供**输入课堂标题确认**的永久删除操作。删除前会检查课堂与关联工作员记录都已停止；确认后内容有变化，需要重新确认。删除会清除这些对话记录，**保留 Vault 中已保存的资料和共享附件**。想暂时收起一节课，可以先用归档。

默认界面收起权限快捷选择、系统上下文和日志类指令，代码工作工具默认关闭。需要排查问题时，在「设置 → 学习界面」开启「显示调试记录」；性能与用量按原生设置的精简或详细模式显示。调试开关调整显示和原生代码工具设置，不改变沙箱和写入审批。

### 使用自己的 ChatGPT 账号

在 **设置 → ChatGPT 账号** 点击 **Continue with ChatGPT**，完成官方授权后，在模型选择器中选择该账号的可用模型；已有 API 服务商配置也可继续使用。首次授权须在运行 Notara 的电脑上完成。账号资格、模型、额度及接口限制由 OpenAI 决定，详细步骤见[ChatGPT 账号接入](docs/runtime/chatgpt-account.md)。

### 可选的 ngrok 远控

想从手机等设备继续学习时，安装 ngrok，在 **设置 → 远控设置** 填写自己的域名和访问凭据，保存后点击「启用远控」。**远控默认关闭，保存配置不会启动**；关闭远控后本地课堂继续运行，完整重启 Notara 后需重新启用。不使用远控就无需安装或配置 ngrok。

密码与令牌保存在运行服务的电脑上，不在页面回显。远程访问者会使用此实例已配置的模型账号，请只把访问密码交给你允许使用的人。令牌设置及后台脚本用法见[远控服务](docs/runtime/remote-access.md)。

## 升级前，先把备份收好喵

通过 `npm run vault` 每次启动后会自动检查一次 GitHub 正式发布，运行期间每 **30 分钟**继续检查，发现兼容版本后在后台准备。页面**右上角**显示可关闭的更新提示，不抢输入焦点；同一次启动中关闭的版本不会因切页、轮询或刷新反复弹出，下次启动或另一个新版本可再次提醒。

等课堂与后台任务结束，点击「重启并更新」；也可以在 **设置 → 更新** 手动检查和更新。更新保留原课堂、资料与设置。涉及 DSH、Cordis 或数据格式变化的版本要求先备份、手动升级。自动更新的代码存放在 `~/.notara/releases/`；以后仍可从原代码目录执行 `npm run vault`，启动器会采用已更新的代码。

0.22.0 以前的用户需要先手动升级一次，才能使用界面更新。已有运行目录使用固定的插件快照，**单独 `git pull` 不会更新快照**；Release 快捷安装器也不迁移学习目录或替换已有快照。

先停止服务，并**完整备份实际学习数据目录，包括隐藏文件**，再执行：

```sh
git pull --ff-only
npm ci --no-audit --no-fund
npm run vault:upgrade
npm run vault
```

`vault:upgrade` 切换插件安装链接，保留旧快照、课堂、资料、模型配置及已有像素教室；失败时回滚本次安装改动。它会重新采用当前代码目录。自定义数据目录需要给升级和启动命令都加 `-- --root /你的数据目录`。

从 **0.21.0 以前**升级时，DSH 会将打开过的课堂迁为旧版无法读取的新格式。需要回退时，停止新版、恢复旧代码与依赖，再把整份备份恢复到**原数据目录位置**；只换回插件快照不足以回退迁移过的课堂。完整步骤见[安装说明](docs/install.md#升级和回退)。

## 开发与验证

```sh
npm run build:native-vault
npm run build:pixel-classroom
npm run typecheck
npm run typecheck:tests
npm run test:plugins
npm run test:unit
npm run test:integration -- --maxWorkers=1
npm run test:e2e
npm run test:stress
npm run test:stress:browser
npm run site:build
npm run release:bundle
```

测试使用独立端口、临时数据目录和合成资料。压力测试覆盖服务端并发、重启与多页面交互，性能报告写入本机 `.runtime/`，不代表真实模型服务容量或无限负载保证。发布包只收运行所需文件，不含设计草稿、研究材料、真实验收记录、测试产物或认证数据。依赖版本见[上游锁定记录](docs/runtime/upstream-lock.json)，具体变化与验证范围见 [0.23.1 发布说明](docs/releases/native-vault-0.23.1.md)。

Windows 快捷安装、启动与部分工具的隔离验证不等于完整真实课堂验收；全量测试仍有 Git Bash/MSYS 与锁定 DSH Windows 沙箱冲突导致的失败，不能称为全项目测试全部通过，见 [Windows 说明](docs/runtime/windows-native-vault.md)。ChatGPT 真实订阅推理和 ngrok 公网连通需要自己的账号另行验证。

## 数据与许可证

学习资料和课堂保存在本机；模型调用会把所需对话、资料内容与工具结果发往你选择的服务商，费用和额度由该服务商决定。运行目录及备份可能含凭据与私密课堂，请勿公开或提交到仓库。

仓库当前**未附开源许可证**，根包标记为 `UNLICENSED`，不表示已授予自由复制、修改或分发的许可；第三方依赖与素材遵循各自的许可证。喵，愿这里能陪你把一个个「还不懂」慢慢变成「我会了」。

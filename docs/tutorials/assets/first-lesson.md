# 因式分解与零积性质

本材料专为产品教程自编，两道题相互独立。它是参考资料，不代表学生已完成或已掌握。

## 学习目标

将能因式分解的二次方程化为乘积为零，解释为什么解之间使用“或”。

## 题目一

解方程：

$$x^2-3x+2=0.$$

<details>
<summary>参考答案</summary>

$$x^2-3x+2=(x-1)(x-2).$$

因此 $x-1=0$ 或 $x-2=0$，解集为 $\{1,2\}$。

对实数而言，乘积为零当且仅当至少一个因数为零。这里不要求同一个 $x$ 同时等于1和2。

</details>

## 题目二

解方程：

$$x^2-5x+6=0.$$

<details>
<summary>参考答案</summary>

$$x^2-5x+6=(x-2)(x-3).$$

因此 $x=2$ 或 $x=3$，解集为 $\{2,3\}$。

</details>

## 观察提示

`0×5=0` 可以检验“两个因数都必须为零”的说法。`0×0=0` 可以区分“至少一个”和“恰好一个”。例子供教师选择，不应冒充课堂中已经发生的引导。

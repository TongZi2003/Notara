# 第01集：从一道不会的题开始

状态：可走读的录屏脚本初稿，尚未录制。目标时长6–8分钟，中文旁白；承接安装篇，开场时已有一个可用教师模型和空白学习集。

观众完成标准：能自己发起一道题的讨论，在资产里找到完整题卡与自己的理解变化，生成小结后还能回到原课堂继续。无需先拆书或配置后台助手。

## 开场成片

先给10秒完成态：左侧讨论，右侧一张题卡；滚到“学生理解”看到早先错误与后来的修正，再点回对话。

旁白：“今天我们只学一道题。结束时，你会留下一张有原题、有参考理解，也有你自己思考过程的卡片。下次回来，可以从这里接着学。”

字幕标注“完成效果预览”，随后切回空学习集。

## 可以直接输入的文字

### 本课目标

> 理解因式分解怎样把二次方程变成两个一次方程，特别是解之间为什么用“或”。

### 开课

> 我想学会这道题：解方程 $x^2-3x+2=0$。我知道展开乘法，但不太理解零积性质。请用提问引导我，一次问一个问题，先不要直接给完整答案。讨论结束后，把原题、参考理解和我实际的理解变化整理成题卡。

### 演示学生的一个真实可讨论错误

只有老师确实问到乘积为零的条件时，再输入以下模拟作答。画面注明“模拟学生作答”。

> 我以为乘积等于零，需要两个因数都等于零。

接下来根据老师**实际**给出的例子计算并回答。若它用了 `0×5`，可以说：

> 0×5也是0，看来只要至少一个因数为0就行。0×0也可以，所以不是只能有一个为0。

如果老师用了其他反例，就回答那个反例；不要为了贴合脚本谎称它给过某个提示。

### 解题与变式

学生实际完成分解后，可以解释：

> $(x-1)(x-2)=0$，所以 $x=1$ 或 $x=2$。这里不能写“且”，同一个$x$不可能既等于1又等于2。

再请求：

> 给我一道同类题，我自己完整做一遍。先别给答案。

老师可能给不同题目，按实际题目完成。录制材料中的第二题供备选，不能当作老师必然会出的题。

### 收束本题

> 这道题讨论到这里。请把刚才发生的理解变化和这次实际表现保存好，保留我最初的错误认识以及后来怎样修正。下一题先不讲。

这句用于向观众说明可以主动要求记录。当前规则也要求老师在题目收束时主动记录，不宣称每次都必须手工提醒。

### 总结与回来继续

点击“总结本课”。等老师完成后，在资产或小结引用中确认确有文档，再回到原会话。

旁白：“小结保存后，这节课仍然能继续。它记录的是我们学到了哪里，不是给这段对话上锁。”

录制时可输入“我又想到一个问题……”展示仍能编辑，随后清空；不发送没有教学用途的测试消息。

## 产物展示旁白

“内容里保留完整题目，以后可以根据题干找回来。参考理解是老师整理的解释，默认收起来，想看再展开。学生理解记录我当时怎么想、哪里出了错、经过什么提示改变了认识。它不应该只剩一句‘已经掌握’。”

“这里如果显示‘尚未观察’，意思是这次没有足够证据，并不是我不会。复习日期也是学习安排，不是能力分数。”

## 现场分支

- 老师直接给答案：承认实际发生，补充“先停在这一行，让我自己解释下一步”；不要剪成它全程按要求引导。
- 保存需要批准：正常批准当前这次写入，再看保存结果；不要把关闭权限保护作为上课前提。
- 老师说保存了，但资产未出现：先刷新资产，再让老师核对实际文件和回执。确未保存就保留恢复过程或暂停录制，不用字幕假装成功。
- 学生理解为空或只留下最终答案：明确指出缺失，按真实对话补回原认识、转折与后续表现。此片段可以作为“如何纠正老师”的短提示。
- 本轮有未观察项，因此没有复习日期：照实解释，不为了演示日历手填通过。可展示已有评估历史，日历功能放入后续实际到期场景。
- 新浏览器提示认证：使用安装篇的 `npm run vault:open` 恢复。认证链接与密钥不进入成片。

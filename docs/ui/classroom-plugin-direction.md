# 教室插件：下一轮设计方向

2026-09-15用户裁决：本轮先合并环境、精简插件；多智能体管理单独设计。本文件记录方向，不表示已实现。

本体维持拆书、学习、记笔记与沉淀记忆。当前只启用数学工作台和世界书，旧情景演示与研讨插件停用。

后续把世界书与多智能体管理合并为「教室」：

- 教室场景有明确座位，每个已加入的子智能体在其中落座，能看见是否空闲、准备发言或正在工作。
- 背景、角色、人设和课堂规则沿世界书编辑；世界观内容与真实任务执行各有对应状态。
- 学生通过@点名，例如让杠精同学挑错、让同学出变式题检验理解；展示来自真实子会话的发言和结果。
- 可由用户配置按轮次、课堂事件hook或按需主动调用；触发规则在后续设计中确定，不先硬编码成固定三角色轮流发言。
- 复用DSH原生子会话、任务、停止与继续能力；座位和教室画面是这些状态的呈现，不复制第二套聊天生命周期。
- 错题练习与板书留在对话，教室不另复制专用练习页、黑板页、史料页或时空地图页。

下一轮需设计真实用户操作与视觉稿，再确定配置范围、发言队列、触发冲突和输出回流。当前`seminar-room`只提供已有执行接缝参考，不是未来教室成品。

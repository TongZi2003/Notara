# 教室插件实施计划

用户已于2026-09-15批准 `classroom-plugin-prototype.html` 的组合方案并授权实现、验证与提供可验收版本。

## 产品边界

教室是插件工作台，复用原生会话、输入框、消息流及原有布局；点名只准备草稿。主教师独占资料读取、工具调用和同学派发；同学独立spawn、零工具、只收任务材料，公开意见署名回到同一对话，备课答案只回教师。世界书配置背景、教法、角色和触发时机，不建立学习事实或复习生命周期。

## 实施顺序

1. 契约与持久化：在世界书能力中可选登记教室配置；沿用插件版本、用户文档与单课启停，旧背景内容保留。角色/规则独立稳定引用、版本冲突保护；任务只登记教师供料及原生子会话引用。
2. 教师工具：读取课堂配置/任务、派发同学、同任务继续；最终模型工具面和执行入口同时禁止教室同学工具。公开任务与备课任务按去向投影；中断、失败与未开始如实显示。
3. 上下文与规则：只接受真实学生输入，手动点名优先；每N个完成的教学回合、笔记成功保存产生有界教师任务候选；每轮至多一个自动参与任务，去重、防自触发，停用/停止后不再派发。临时上下文按轮/阶段/课堂失效，跨课只由教师供料接续。
4. 原型接入：成员座位、状态、角色与任务详情；世界书/规则内部配置；唯一composer草稿带入、公开回复展示和源位置联动。双主题继承产品token与容器宽度。
5. 插件升级与验证：世界书升级为教室，保留包名/贡献ID及原用户条目；数学与其他保存成果不受影响。隔离环境测试完成后更新用户日常环境并检查真实浏览器。

## 验收

2026-09-15补充并实施：默认空白，三份模板显式选择；创作者新增classroom作品、同源worldbook.json表单与读写工具、插件作用域Skill，安装仍走统一包管理。九个旧插件卸载保留成果。保存校验、写入期间禁用编辑、原生文件写入保护和创作对话身份核对一并验收。

- 安装/启停/卸载与旧世界书内容保留，配置保存、冲突、刷新、重启恢复。
- 选择座位不发送；点名后原生输入框待发送；教师实际spawn，子智能体无父全文/工具；署名回复只有一处。
- 普通消息仍由老师正常教学，多个触发不并发抢话；阶段事件只有保存成功后触发。失败/停止不能显示完成。
- 备课材料和完整答案不进入学生任务详情/公开同学回复；资料/笔记仍经既有通路保存。
- 静态/合同/集成、真实浏览器和真实模型证据分别报告，模拟回复不得充当实际编排通过。

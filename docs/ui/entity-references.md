# 对话中的资料实体引用：实施方案

状态：2026-09-14 源码侦查完成，待实施。本文件记录方案，不表示功能已上线。

用户已确定：所有在对话中明确涉及的资料库实体都应可点击，在资料工作台展开所属层级、定位并高亮，预览相应内容；不限于语义搜索技能。

## 现有能力与缺口

- `resources/teaching/skills/studyforge-semantic-search.md` 已要求“可点击资料引用”，但没有定义可执行的引用格式。
- `contracts/learning-search.ts` 的命中含真实 ref/revision 或 materialId/versionId/locator。`host/src/tools/{search,material,card,knowledge,source-use,organization}-tools.ts` 已能提供书、位置、目录、卡与知识的身份和版本。无需再建一套资料实体。
- 原生 DSH rc.2 的 `MarkdownText` 只允许绝对http/https/mailto，内部URI与hash链接会退为文字；没有公开的行内链接resolver。`chatFileMentions` 有打开回调，但只处理行内code，显示值仍是原token，流式期间不启用，且已由原生deliverables提供。
- 学生已发送的原文/卡片引用可复用 `source-display.tsx` 与 `SourceFragment`；知识引用的codec在 `classroom/skill-draft.ts` 发送时展开为正文，尚未保留同等的可点击身份展示。
- `lesson-pane-request.ts` 已负责打开/恢复工作台、暂存未挂载时的请求；`SourcePane` 与 `CardPane` 已可预览指定位置/版本。
- `LessonResources.tsx` 自动选中只按资料ID+版本查原文，忽略locator；卡/知识查找未比较版本；找不到节点时静默结束。`MindMap.tsx` 只横向居中。现有图数据并非“仅包含已展开节点”，展开控制可见性，修复应针对精确匹配、惰性结构读入与目标缺席。

## 推荐设计

### 1. 一个轻量的引用目标合同

新增共享的 `LibraryEntityReference` DTO及编解码函数，使用既有类型：

| 对象 | 绑定字段 | 预览落点 |
|---|---|---|
| 书/其他导入文件、原文片段 | MaterialContext：materialId、versionId、可选locator | 指定版本原件；有位置时精确定位 |
| 章节/小节 | materialId、skeletonRevision、path | 该版真实目录节点及其来源锚点 |
| 题卡/普通笔记 | card ref、version | 当时版本的卡 |
| 知识/方法笔记 | knowledge ref、version | 当时版本的知识条目 |

普通笔记仍用现有卡/知识实体，不新增note存储类型；学习集、课程、插件自身不是本轮资料工作台引用目标。显示标题来自实际对象，标题不参与身份解析。

引用目标直接编码在应用内部相对链接里，使用单一专用前缀，例如 `#studyforge/reference/<encoded-target>`。不含端口、绝对文件路径或凭据，不建立永久citation数据库，也不把短编号另存一张映射表。Host按当前学习空间权限解析目标，验证对象、版本与位置；格式坏、不存在或不可访问时给可读提示，不按同名对象替代。

### 2. 系统生成链接，模型选择引用

在已有成功工具的 `output.render` 中附加系统生成的“标题+可复制内部链接”，保留原有结构化JSON、图片及presentationMeta的语义，避免破坏版本绑定和内容历史读取。

接入范围：搜索/枚举、单条与批量读取、目录读取，以及实际保存成功返回对象的回执、独立帮手返回的真实对象。未确认提案不是资料库实体，不提前发正式链接。`read_skeleton` 的章节链接从真实节点和该版骨架生成。

共同教学提示要求：明确谈及这些对象时使用工具提供的链接，采用正常书名/题名/章节名作可见文字。语义搜索、普通讲题、复习、共建和子智能体都使用同一约定。既有学生引用chip也汇入同一打开函数；知识引用补齐发送后的身份保留。

普通手打文字和旧回复中的裸标题不做全库模糊替换。已有结构化历史引用继续可点；新生成回复的明确实体引用遵循新格式。模型是否自然遵守须单独验收，不能用静态格式测试代替。

### 3. 保留原生消息渲染，补窄链接接缝

推荐为锁定rc.2的Markdown增加可选内部链接resolver及必要透传，只拦截本应用的专用引用前缀；未命中时保持现有网址过滤与渲染行为。沿 `scripts/patch-sdk.ts` 已有的版本/摘要守卫维护，未知上游版本立即失败，不无条件字符串替换。

不替换assistant整段渲染器。保留流式分段、KaTeX、代码块、图片、复制与原生session历史。原生deliverables的 `chatFileMentions` 继续存在，不覆盖它。

引用显示为正常标题与克制的细线链接样式，两主题沿用已有字阶。完整合法引用才响应点击。半截流式链接是否会暴露href是待实测边界：验收要求不把机器载荷刷到正文；若原生尾部按字面渲染，则在内部引用的尾部解析处补窄处理，只处理本前缀，保持原始消息内容不变。

曾比较的替代路线：直接复用fileMentions改动较少，但原始token可见、语义偏文件且与deliverables冲突；绝对HTTP本地深链可通过自有根事件委派实现，但需要处理端口变化、外部打开和历史可移植性；重写assistant renderer维护面过大。选择窄原生链接接缝。

### 4. 点击是精确导航

统一 `openEntityReference`：解析真实目标 → 打开资料工作台 → 按需读取所属书结构 → 解析目标对应节点 → 展开父链 → 横纵定位并高亮 → 打开原文/卡片/知识预览。

- 同一本书不同页/区域须比较完整locator；同一卡的不同版本须区分。多锚点按实际选中的来源定位，不能始终只拿第一个。
- “本节课用到的”过滤排除了目标时，点击引用自动切到明确可见的“全部资料”，然后定位；不把它写进本课采用记录。
- 尚无图节点的独立卡/笔记可作为本次查看的只读目标加入投影，不伪造它与书/章节的父子关系。
- 历史版本在当前树没有对应节点时，使用明确的历史引用节点并预览旧版；不得高亮新版来冒充旧版，不要求重建整棵历史资料库。
- 工作台关闭时恢复；窄屏切到目标视图且可返回对话；异步读取校验当前课堂，防止切课后旧请求落入新课。
- 浏览不触发 `cite_materials`、复习、掌握或新学习记录。`cite_materials` 继续只表示正式采用。

## 实施顺序与验收

1. 合同+编解码+Host解析：覆盖四类目标、真实固定版本、坏引用、同名不同对象、原件位置越界；不新增持久库。
2. 最小原生链接接缝：先用固定消息验证正常链接、完整/半截流式、公式表格代码、鼠标/键盘、复制、两主题；确认后再接所有工具输出。
3. 工作台精确导航：独立纯函数解析节点身份与父链；修复宽松匹配、目标缺席和纵向定位；覆盖工作台关闭、折叠三层、本课过滤、旧版与窄屏。
4. 全入口接线：共同提示+搜索技能、读取/枚举/成功回执、学生资料与知识引用、帮手输出；保留原生日志与旧结构化引用。
5. 端到端验收：搜索命中→回复链接→工作台真实节点/页段；普通课堂不调用搜索也可引用；刷新、重启、fork继承、改名/更新后的旧回复仍指向原身份版本；点击前后学习记录不变。另跑一个自然语言真实模型场景，单独报告链接使用正确性。

现有最近邻测试：`source-context-codec.test.ts`、`native-source-context.test.ts`、`global-learning-search.test.ts`、`book-exploration.test.ts`、`source-roundtrip.spec.ts`、`book-workspace.spec.ts`、`current-classroom.spec.ts`。它们不能替代本轮新增的行内引用与精准定位验收。

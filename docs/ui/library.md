# 资料管理页

资料页负责统一查找、管理和预览；课堂中的图形工作台仍负责关联探索与教学上下文。

## 信息层级

- 顶部：全部 / 原文 / 题卡与笔记 / 知识类型入口；搜索、已有标签、学习集直接可选。
- 目录：书名 → 已有章节 → 小节 → 卡片。默认只显示书名；点击标题只展开下一层，关闭书籍后重开也从第一层开始。
- 未绑定有效章节的在书卡片放在“未分章节”折叠组；不根据题目标题、标签或页码重叠猜章节。无在库来源的卡片与知识记录各有独立折叠组。
- 书名右侧预览按钮独立于展开动作。宽屏在右侧预览/编辑，窄屏临时替换列表；关闭预览返回原筛选与展开状态。
- 现代、手帐共用状态与结构；字体和线条使用各自主题token。书头使用section字阶，卡片使用item字阶，不再用同级粗体大字平铺所有内容。

## 关系与筛选

卡片的 `sources[].materialId` 决定它属于哪份原文，章节位置消费原有 `studyforgeOrganization.book` 投影的 `parentKey`。展开时按需读取，失败显示重试而不是冒充空目录。没有写入目录或卡片的副作用。

跨书卡可在各来源下引用同一ref，编辑仍落同一张卡。知识的公共教法引用不是原文锚，不能据此编出书籍归属。任意语义联系也不作为目录父边。

标签沿用学习与复习页的已有标签：cards与knowledge标签合并去重，单标签等值过滤；可以点卡片下的标签或用顶部选择器。搜索同时匹配标题、标签、已保存章节和来源书名。类型/学习集/标签/搜索可组合。

筛选保留命中卡片的原文父层作为来源上下文，但不自动展开全部子孙。分类数量按唯一对象计数，不把跨书重复引用当成新卡。学习集筛选仍采用既有显式成员与来源归属规则。

## 验收

使用有三级目录、跨书卡、重复同书锚和独立卡的隔离数据验证两主题：默认折叠、逐级展开、父层收起、重新打开、刷新、标签与搜索、同ref、预览与编辑、390px宽度。现有原文共建/语义查找回课堂与工作台跳转继续验证。

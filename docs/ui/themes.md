# 两套界面主题

主题改变外观，不改变对话、面板布局、资料、卡片或学习记录。设置 → 外观只提供两种主题。

| 项目 | 现代简约 | 手写手帐 |
|---|---|---|
| 页面 | 白色主面、浅灰导航和次级面 | 暖色或白色纸张 |
| 内容字迹 | 系统无衬线字体，正文默认15px | 正文默认16px，界面与内容跟随所选字迹 |
| 控件 | 系统字体13px、辅助信息12px；8px圆角 | 所选手写体15px、辅助信息14px；4px细线圆角 |
| 菜单/输入框 | 菜单14px圆角，主输入框22px | 菜单8px圆角，纸张输入与便签 |
| 图节点 | 白底、14px圆角、细描边；选中蓝色 | 彩色贴纸、胶带、手写标题 |
| 对话 | 常规段落间距，无横线与基线补位 | 整页横线/方格；文字随纸线对齐 |
| 确认卡 | 圆角内容块，保存结果为正常状态标签 | 待定便签，实际保存后胶带与印章 |

现代主题只在关系图、课程图画布保留淡点阵，普通页面不用纸纹。来源原文、公式与代码维持各自内容格式。两种主题均沿用原生浅色/深色/跟随系统选择。

### 字体与字号

字号按信息角色取值，不能按页面各自放大。`theme/typography.css` 是界面字号的唯一尺度：

| 角色 | token | 现代 | 手帐 |
|---|---|---|---|
| 首页提问 | `--sf-text-hero` | 28px | 30px |
| 页面标题 | `--sf-text-page` | 20px | 22px |
| 详情/小节标题 | `--sf-text-section` | 16px | 18px |
| 列表/图节点标题 | `--sf-text-item` | 15px | 16px |
| 按钮/选择器 | `--sf-ui-size` | 13px | 15px |
| 日期/数量/辅助信息 | `--sf-text-meta` | 12px | 14px |

手帐的中文手写字形视觉尺寸更小，辅助文字不直接照搬现代版的12px。阅读正文使用 `--nb-size`，小/中/大分别为现代14/15/17px、手帐15/16/18px；改变阅读字号不放大导航、列表标题和控件。
对话与确认卡内部标题使用 `--sf-reading-heading` / `--sf-reading-subheading`，至少与阅读正文等大；大字模式不会出现正文大于内容标题的倒挂。

两主题中，导航、Agent/Subject/模型、加号、表单与列表均采用当前 `--sf-ui-font`；这是本轮“同一主题不混字迹”对早期系统字体选择器例外的更新。旧 `--nb-print`、`--op-print`、页面字体别名仅兼容既有组件，均解析为主题字体，不得再在工作区根覆盖为 system-ui。

输入框自身宽度≤440px时，Agent、Subject和模型收成32px图标按钮，发送保留原生34px独立按钮；拉宽恢复文字。按钮的aria-label/title和展开菜单始终保留完整名称。约束模型入口的真实wrapper与button，不能只给`display:contents`的slot设置flex。窄栏验收须检查矩形不交叠、中心点击命中及输入框边界，不能只检查按钮是否处于同一行。

主动选择的「丁·老师用印刷体」「表格印刷体」「剪贴印刷」使用独立 `--sf-print-font`；新偏好默认手抄，已保存的印刷偏好保留。代码/技术差异用等宽字体，公式和来源文档保留各自格式，不能给所有后代强制覆盖字体。

新增样式应使用 `--nb-*` / `--op-*` / 原生语义tokens；输入框、按钮与菜单沿用共用控件层。手帐专用的旋转、胶带、印章必须限定到 `data-sf-style=notebook`。现代主题不得从“关闭手写”或“柔和纸张”推导。图节点的 `translateX(-50%)` 属于坐标布局，两主题均须保留。

实现入口：

- `packages/client/src/theme/appearance.ts`：仅modern/notebook两个值；旧soft/disabled迁移为modern，旧手帐偏好保留。
- `theme/notebook.tsx`：原生token层、两主题选项、偏好持久化。
- `theme/typography.css`、`theme/modern.css`、`theme/notebook.css`、`theme/controls.css`：共享字阶、主题与控件。
- `data-sf-conversation-paper`：当前原生对话所在纸面；基线测量跟随此真实容器，现代主题切换时清理补位。

验收必须同时覆盖首页/对话、图、列表、阅读器、编辑器、确认前后、设置与菜单，并检查窄屏和切回手帐。除截图，还须检查每个主题内的实际字体、标题尺寸、详情与列表层级、字号偏好和纸线基线。不能以单个首页截图或modern不含手写体的单向断言替代全站验收。

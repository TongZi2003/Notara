# 课程与日历的层级

课程页使用轻量目录与按需详情：现代主题是白色平面与圆角控件，手帐主题使用同一结构、手写字迹与细线。页面不重复列出同一节课，不把卡片当成课程。

内容顺序：课程标题与视图切换 → 搜索/日期筛选与新建 → 课程父子树或路线图 → 所选课堂详情。课程名用 item 字阶，状态/日期用 meta 字阶，详情标题用 section 字阶。交互仅保留展开箭头旋转、行悬停和详情出现的短过渡，尊重减少动态效果设置。

- 树和图共用已有 `route` + `routeLessons` 投影，按 session 身份去重。原生父子会话、计划节点、归档课堂继续展示，单纯展开不写入路线。
- 默认仅显示根课程。箭头逐层展开，标题打开详情；搜索和日期筛选保留命中的父级上下文。切换视图保留筛选、选择与树的展开状态。
- 列表行只保留标题、状态、日期及子课程数量。进入对话、课堂设置、调整上级课程在详情中操作。已开课设置使用真实课堂设置；计划设置使用排课编辑器。
- 指定过课程日期的，图树继续显示/按该日期筛选；未指定日期的实际课堂显示开课日。提前开课不改计划日期，已开课也能在详情单独改期。
- 部分读取失败时明确提示并显示仍可用的权威来源；已存在课堂可继续进入，路线写入暂停，不能把不完整数据当成可编辑的空树。
- 日历学习记录按已有 `sourceRefs` 的课堂归组；卡片/知识/资料在相应课堂下展开，目标对象保持原类型。没有课堂来源的记录单列“课外记录”，不按时间或名字推断从属关系。
- 日历显示的是当日动作所属课堂，不声称每一次编辑都代表该卡片出生于这节课。

实施顺序：共用课程投影与详情，退休重复列表 → 紧凑树与双主题样式 → 日历来源分组 → 隔离浏览器核验及实际页面更新。检验层级/去重、读侧无写入、详情操作、图树切换、日期筛选、课堂来源及课外记录、两主题与窄屏。

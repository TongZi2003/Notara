# MIT 数学工作台实施与验收

2026-09-15，用户已确认尝试 JSXGraph + Cortex Compute Engine，二维与立体几何一起实现。主 Agent 实现；只读子 Agent 核对计算引擎版本。

## 决策

- JSXGraph 1.13.3（选择 MIT）负责约束构造、二维与三维绘制；Cortex Compute Engine 的固定 npm 稳定版负责公式解析、化简、求值、求解及求导。计算请求在 Host 执行，插件不装第二份 CAS。
- 同一数学文档保存对象、参数、二维视区、三维视角与观察。构造依赖按拓扑顺序创建，循环、悬空或维度不匹配在保存前拒绝。
- 引擎计算出的坐标、长度、面积、角度作为绑定文档 revision 的临时投影回传。未渲染、过期、退化与无定义明确返回，绝不以零冒充结果。没有打开页面时仍可编辑文档、计算公式；不声称画布已绘制。
- AI 增量编辑沿同一文档，整批校验后一次保存。撤销和重做只针对当前末次操作，版本冲突先重读，不覆盖其后的学生修改；恢复产生新 revision。
- 画布为主，左侧紧凑对象/属性/参数栏，顶栏切二维/三维，底部保留观察与带入对话。窄栏将侧栏收进抽屉。沿用双主题的字体和克制字阶。
- 框选和列表多选共用选择集合；删除点按反向依赖连带清理，删除线保留端点，整批可撤销。纸张底纹只在画布外，数学网格不与手帐横线重叠。
- 资料引用、确认笔记和 ThoughtMap 阶段沿现有通路，不创造掌握或复习事实。旧数学插件版本和成果保留，新插件版本在独立课堂验收。

## 实施顺序

- [x] 合同与纯逻辑：扩展 math-scene，依赖检查、增量编辑、渲染快照和计算请求 schema；先验证二维/三维依赖、循环拒绝、原子批次与旧文档读取。
- [x] Host：固定 Cortex 依赖；增量工具、同版本画布投影、公式运算、版本撤销/重做；接入现有 Remote、SDK、按需工具目录和主课堂权限。
- [x] 插件：统一二维/三维 JSXGraph 适配器，专业构造表单、对象属性、测量、公式计算面板；学生拖动与 AI 修改均刷新投影；离线单文件和 MIT notices。
- [ ] 验收：相关 unit/integration、类型/build/合同；独立 runtime 中实际二维与三维构造、拖动读回、求解、撤销/重做、保存重开、确认笔记及双主题窄栏目检。
- [x] 交接：记录新鲜证据、失败与恢复、未验项；更新 CLAUDE 对应行并保留其原有改动。

## 完成边界

本轮是可用的统一工作台首版，不声称达到 GeoGebra 的全部 CAS、几何证明和构造工具覆盖。图形与数值是探究材料，不能替代证明。自然语言真实模型教学质量单独报告，不由确定性测试模型冒充。

验收进展：13个单元、4个不同集成、84合同、类型/build与双主题实页已通过；列表多选、二维/三维关联删除与撤销、手帐画布底纹隔离及窄栏已验证。完整鼠标/触控框选、拖动和真实模型教学仍未验收，故完整验收项保留未勾选。详见 [`../migration/2026-09-15-Notara-MIT-math-engine.md`](../migration/2026-09-15-Notara-MIT-math-engine.md)。

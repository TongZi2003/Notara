# 学习星图与层级掌握度设计

日期：2026-09-25
状态：待评审
范围：Native Vault 图谱与课程路线的星图视图

## 目标

在现有知识图谱和课程路线之外增加一个“星图”视图。星图不替代结构图：结构图继续负责精确查找、筛选、展开和编辑关系；星图负责让学生一眼看到学习进展和知识亮度。

- 完成课程小结后，课程路线节点点亮。
- 知识图谱叶子节点的亮度来自有证据的掌握概率。
- 有子节点的父节点亮度由全部叶子后代聚合得到，不随当前展开层级改变。
- 覆盖度与掌握度分开表达，避免少数高掌握叶子把整个大分支误显示为已掌握。
- 保留当前浅色极简主题，使用浅纸面、深蓝星点和低饱和光晕，不引入纯黑星空主题。

## 视图入口

图谱页和课程路线页各增加“结构 / 星图”视图切换。

- 结构视图保留当前节点、标签筛选、逐级展开、右键菜单和静态大图布局。
- 星图视图使用相同的数据投影和节点身份，只改变空间布局、尺寸和状态表达。
- 当前筛选条件、学习集和选中的中心节点在两个视图之间保持一致。
- 大图仍然采用逐级展开；切换到星图不要求一次渲染全部节点。
- 点击星体打开节点详情；有子节点的父星体可以继续展开下一层。

## 课程路线星图

课程路线星体的点亮状态来自真实路线和课堂记录：

- 课程只有在对应课堂完成正式课程小结后点亮。
- 仅打开课程、发送一条消息或创建空课堂不会点亮。
- 点亮表示“这门课已经完成过”，不表示所有知识点已经掌握。
- 已完成课程可显示完成日期和小结入口；未完成课程保留路线顺序和先修关系。
- 课程星体的亮度可以先使用二态：未点亮 / 已点亮；未来再加入学习次数或最近完成时间的弱化效果。

课程路线使用 `lesson_log`、路线节点和正式小结的已有投影，不新建一套课程事实源。

## 叶子掌握状态

星图不直接把 Vault 卡片的 `mastery 1–5` 当成概率。当前 `mastery` 是复习档位，主要决定 1、3、7、16、35 天的复习间隔；它不能直接声称跨题型、无提示或长期掌握。

新增只读的叶子掌握投影。最小输入是与叶子知识点绑定的具体能力观察：

- `demonstrated`：学生实际完成了本次检验的关键认知工作，作为正向证据。
- `needs_practice`：学生暴露了具体困难，作为负向证据。
- `not_observed`：没有足够证据，不更新掌握状态，也不把它当作失败。

每条能力观察必须能回到卡片、课堂或复习记录。单纯打开资料、看过板书、获得教师讲解或模型置信度不能直接更新叶子掌握度。

## BKT 式叶子更新

第一版采用可解释的 BKT 式投影，而不是立即引入深度层级知识追踪模型。每个叶子保存一个只读派生状态：

```ts
type LeafMasteryProjection = {
  probability: number;       // [0, 1]
  evidenceCount: number;
  observed: boolean;
  lastEvidenceAt?: string;
  confidence: 'prior' | 'emerging' | 'supported';
};
```

初始状态使用 provider 默认先验 `P(L0)`。对一个具体能力的有效证据依次更新：

- `P(T)`：学习转移概率；
- `P(S)`：已掌握但答错的概率；
- `P(G)`：未掌握但猜对的概率。

`not_observed` 不触发 BKT 更新，只保留当前先验或历史状态。实际参数先采用可审计的默认值；当积累足够的真实回答序列后，再允许按学习集或学科拟合参数，并与默认参数进行离线比较。

叶子掌握投影不覆盖卡片 Markdown 中已有的 `mastery`、`review_history` 或评估记录，也不反向驱动复习排期。它只是星图和相关学习视图的派生读模型。

这一选择参考了 BKT 原始模型、BKT 系统综述、知识追踪综述，以及图结构和层级练习图的知识追踪研究：

- [Corbett & Anderson, 1995: Knowledge tracing](https://doi.org/10.1007/BF01099821)
- [Šarić-Grgić et al., 2024: Twenty-five years of Bayesian knowledge tracing](https://doi.org/10.1007/s11257-023-09389-4)
- [Liu et al., 2022: Knowledge Tracing: A Survey](https://doi.org/10.1145/3569576)
- [Nakagawa et al., 2019: Graph-based Knowledge Tracing](https://doi.org/10.1145/3350546.3352513)
- [Tong et al., 2022: Hierarchical Exercise Graph for Knowledge Tracing](https://doi.org/10.1145/3477495.3532004)

## 父节点聚合

父节点聚合使用它的全部叶子后代，而不是当前画面中已经展开的节点。设叶子掌握概率为 `p_i`，权重为 `w_i`，第一版的整体掌握度使用加权几何平均：

```text
mastery(parent) = exp( sum(w_i * log(max(p_i, epsilon))) / sum(w_i) )
```

选择几何平均的理由：

- 某个基础叶子很弱时，会真实拉低父节点；
- 少数高亮叶子不能掩盖大量未掌握叶子；
- 概率仍然保持在 `[0, 1]`，可以直接映射成星光强度；
- 权重可以表达核心叶子、拓展叶子和不同题型的不同重要性。

同时计算覆盖度：

```text
coverage(parent) = sum(w_i * observed_i) / sum(w_i)
```

星体的主要亮度使用 `mastery(parent)`，外圈光晕或小型环带表达 `coverage(parent)`。因此“概率高但只覆盖一个叶子”和“概率中等但覆盖面很广”在视觉上不会被混成同一个状态。

如果未来某个知识分支明确声明所有子节点都是严格先修条件，可以将该分支切换到 soft-min 聚合；这属于知识结构的显式属性，不能由模型临时猜测。

## 星图视觉映射

- 叶子节点：小型星点，亮度映射 `probability`。
- 父节点：更大的星体，亮度映射聚合后的 `mastery`。
- 覆盖度：环带、光晕范围或边缘刻度表达，不改变主亮度语义。
- 未观察节点：保持低亮度和低饱和度，不显示为失败或错误。
- 课程路线星体：完成小结后点亮；课程星体与知识星体使用不同形状或轮廓，避免把“完成课程”和“掌握知识”混为一谈。
- 选中节点：显示真实标题、证据数量、最近证据时间、掌握度和覆盖度；不显示内部 ID、工具名或模型信息。

布局沿用当前图谱的大图优化：初始只绘制根节点和第一层；点击父星体展开下一层；“展开全部”仍提供完整视图，但大图默认使用静态布局和可滚动画布。

## 数据流与边界

```text
卡片评估 / 课堂小结 / 路线记录
        |
        v
Host 生成只读学习投影
        |
        +--> 课程完成投影
        +--> 叶子 BKT 掌握投影
        +--> 父节点层级聚合投影
        |
        v
结构图与星图共用节点和关系，采用不同 renderer
```

星图是可重建投影，不是新的学习事实源。学生进行新的课堂评估或复习后，Host 重新计算投影；客户端只订阅投影刷新，不在浏览器本地自行推断掌握度。

## 空态、异常和陈旧状态

- 没有学习证据时显示未点亮星图和简短空态；先验只用于后续计算，不把它渲染成“掌握不足”的事实结论。
- 只有课程完成记录、没有知识评估时，课程星体可以点亮，知识星体仍保持未观察状态。
- 某些卡片缺少叶子绑定时，保留在结构图中，但不参与掌握度聚合，并显示“尚未关联能力”。
- 投影读取失败时不显示零亮度；保留上一次已知状态并显示可见错误。
- 聚合使用全部叶子后代，不因标签筛选、搜索或逐级展开而改变结果。
- 评估或复习写入发生 revision 冲突时，星图等待下一次成功投影，不提前显示新亮度。

## 验证

### 纯逻辑

- BKT 对 `demonstrated`、`needs_practice`、`not_observed` 的更新符合合同。
- 叶子没有证据时不被错误标记为失败或掌握。
- 父节点使用全部后代叶子，且加权几何平均、权重和 `epsilon` 边界正确。
- 标签筛选和逐级展开不改变父节点聚合结果。
- 课程只有在正式小结完成后才点亮。

### 集成

- 新增评估后，叶子、父节点和星图重新读取同一份投影。
- 复习档位变化不会被星图投影写回卡片，也不会改写排期。
- 课堂小结完成后路线星体点亮，删除或撤销小结时状态如实刷新。
- 缺失能力绑定、读取失败和 revision 冲突不会被渲染成零掌握。

### 浏览器

- 结构图和星图切换保持学习集、筛选条件和选中节点。
- 父星体点击展开子节点，右键菜单继续保留现有节点操作。
- 大图默认静态布局，标签区保持两行可滚动并可拖拽增高。
- 801px 窄屏下星图可以纵向滚动，无横向溢出。
- 课程完成、叶子亮度、父节点聚合和无证据空态各有可见验证场景。

## 非目标

- 第一版不训练深度 HKT、GNN 或 DKT 模型。
- 不把星图亮度当成绝对心理测量结果或考试分数。
- 不把打开资料、看过板书或生成小结直接当成知识掌握证据。
- 不让浏览器客户端自行写入掌握度事实。
- 不用星图替代结构图的检索、编辑和关系核对功能。

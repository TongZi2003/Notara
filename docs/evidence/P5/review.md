## 关键不变量与返工

- 作者正文、系统学习历史分开；卡背未公开时红笔不泄露旧答案。红笔使用真实前后 revision，按实际 Session 操作归属投影，复制当前正文不带旧文。
- 知识收录不复制成第二身份；删除使用 tombstone，保留历史版本、关联卡与学习记录，普通编辑不能复活。
- DSH 网络错误可能返回 `gateway/internal` 而非抛异常。明确领域拒绝优先识别；未知写入冻结 operation、payload 和原 session，独立重试按钮复用原请求。丢响应测试让 Host 先真实提交，再中断响应，确认最终只有一份效果。
- 部分确认只重试失败项；未确定提交结果时不能换稿/取消。receipt 回原课且不成为学生依据；receipt-only 轮无工具。
- 复习按真实 occurrence 归日；早测、晚确认、乱序、换梯和重试由冻结基线及真实历史决定，不从打开、讲过或库存推断掌握。

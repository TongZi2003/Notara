## 14 种内容逐项审查

| 内容 | 实际处理 |
|---|---|
| card-create | 卡面/卡背、笔记、标签、章节、来源、相关卡片；单项同名标题不重复 |
| card-edit | 从只列字段名改为显示新值；清空、移除关联都有明确说明 |
| knowledge-collect | 保留收录锦囊动作，去掉内部实体解释 |
| review | 目标卡名、实际档位、通道和证据说明 |
| set-create / set-edit | 复习间隔、科目、实际资料及成员名称；增删分别列明 |
| route-add / route-edit | 课程、日期、实际资料顺序与默认项、教学重点 |
| plan-create / plan-edit | 列真实日期与阅读位置、具体复习日程；指定日程时不误说每日自由取卡额度 |
| skeleton-save | 树形目录与完整变更影响，原稿仍可查看 |
| handoff / handoff-edit | 正文与当时事实保留，明确保存小结会结束本课；更正不重开/重关课 |
| lesson-edit | 补归档/恢复结果；具体资料和默认项、学习集、教法、重点及临时要求 |

通用操作审查补修：不同项的原稿展开状态独立；编辑时隐藏批量保存和失败重试；已明确未写入的失败项可修改/拒绝，结果未知项仍只核对原操作；回执发送异常释放忙碌状态；读不到编辑选项时可退出。

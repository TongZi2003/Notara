01

从中点，找到斜率

题面与条件

椭圆 x²/4 + y²/3 = 1 上，弦 AB 的中点是 M(1, ½)。求直线 AB 的斜率。

来源：中点弦的斜率

先想一想： 已知的是两个端点各自的坐标，还是它们之间的关系？

02

把条件放回图中

M 是弦的中点；我们需要的是弦的方向。

圆锥曲线 · 点差法

03

共同建立的联系

两点在同一曲线上 → 两式相减 → 和与差

x₁ + x₂ = 2x₀，y₁ + y₂ = 2y₀：和，连接中点。

(y₁ − y₂)/(x₁ − x₂) = k：差的比，连接斜率（先检查分母）。

从“求出两个端点”转向“保留我们需要的关系”。

对照：中点弦问题 · 二次式相减会暴露线性关系

04

我的思路变化

展开我的尝试

最初的尝试 设直线方程联立，展开后算得很乱。

得到提示以后 老师提出“两式相减”后，我自己接上了 x₁ + x₂ = 2、y₁ + y₂ = 1。

当前还要检验 这一次求出 k = −3/2，并不能说明换题后也能主动想到相减。

05

需要时看一个提示

展开提示

先不求端点。把两点坐标分别代入同一个方程，再观察 x₁² − x₂²。

06

回看推导

展开参考解释

两式相减并因式分解：

(x₁+x₂)(x₁−x₂)/4 + (y₁+y₂)(y₁−y₂)/3 = 0。

代入中点关系：

(x₁−x₂)/2 + (y₁−y₂)/3 = 0。

本题中弦不能竖直，否则端点的 y 坐标互为相反数，中点纵坐标为 0，与 ½ 矛盾。因此可除以 x₁−x₂，得到 k = −3/2。

07

如果中点落在 x 轴上呢？

# Notara Vault 视图设计（资产 / 图谱 / 卡片 / 路线 / 分屏）

2026-09-21 按后续讨论统一修订。`mockup.html` 及本目录其他示例稿仅作历史视觉参考，不代表当前布局合同。完整范围与验收见 [Vault 教学迁移总合同](../../migration/2026-09-21-vault-teaching-migration.md)；本文是设计，不作为实现已通过的证据。

## 0. 前提

- 使用现有单例 `conversation.workspace` 容器，在其视图 ID、choices/components 中管理并列 bench：对话、轨迹、资产、图谱、卡片、路线。不能为每个 bench 重复注册 workspace 槽。
- 视觉沿用 DSH 当前主题与 `--dsw-alias-*` 令牌，不要求与示例 HTML 的配色一致。
- Vault 文件是内容事实源，节点、边和日志索引按各自语义投影；普通文件、锦囊、课堂资料保持可读可编辑，不另存一份图谱正文。

## 1. 整体布局与分屏

`[DSH 原生导航] [左侧 bench] [可选右侧 bench]`

- 对话与资产、图谱、路线等可分屏，复用现有调宽、交换与关闭分屏交互。图谱内部可有可收起/调宽的节点详情，整体不强制固定三栏。
- composer 只在原生对话 pane 中，切页/分屏不复制或重新挂载第二份输入框，保留原生对话和草稿。
- 资产页承担 Markdown 阅读编辑、PDF/图片等预览；阅读器不再作为独立 bench，特殊阅读视图收在小图标或菜单中。
- 新建、导入、模板、保存等沿工具栏小图标/右键菜单与按需对话框展开，避免常驻表单占用正文区域。
- 教学设置只有一个简短入口，技能沿原生输入框菜单，默认不增加一排教师身份按钮。

## 2. 图谱 board（Obsidian 关系图谱风格）

点 + 直线 + 标签的力导向图，不是卡片列。

### 节点图例（按图内角色，不按文件类型）

| 角色 | 判定 | 图例 |
|---|---|---|
| 来源节点 | 作为其他卡片的真实内容来源 | 实心大圆 + 光晕 |
| 中间卡片 | 有真实拆分子卡的卡片 | 实心核 + 描边环 |
| 叶子卡片 | 无拆分子卡的卡片 | 空心圆 |
| 孤立点 | 无任何边的文件 | 虚线空心灰圆 |

文件类型徽章（PDF/MD/IMG）不进图例，挪进节点详情 pane。

锦囊另有明确类型标识，可连接题目和知识资产。路线/剧本/小结作为资料展示时标识实际类型；课序、课堂绑定与小结挂载不计入知识拆分层级或子卡数。不能把所有 Markdown 都称为“原书”。

### 边

| 边 | 来源 | 线型 |
|---|---|---|
| 拆分边（来源→卡片、卡片→子卡片） | 真实内容摘录/拆分产生的 embed 或 frontmatter `parent:` | 主题实线 |
| 引用边（资产之间） | `[[wiki]]` 等真实资料引用 | 主题点线 |

锦囊案例可通过引用边连接；同标签只提供聚合线索，不自动生成引用边。路线的课序关系由独立路线投影读取，不能用 parent/embed 偷存课程依赖。

### 交互

- 单击节点 → 详情 pane 优先显示直接子卡数量和名称、来源定位；正文仅短预览，不整段堆出原始 Markdown。
- 双击 → 在资产页打开实际文件；PDF 定位到真实页/选区，Markdown 使用同一编辑器。
- “带入对话”把节点文件或选中片段加入原生引用并聚焦对话 pane，供教师读取后讨论或拆分；不保留语义不明的“继续拆分”动作，也不点击即自动让 AI 开始拆分。
- 右键/小图标提供资产定位、来源回跳、以此为中心、带入对话；提取卡片在资产页实际阅读选区上操作。
- 拖节点 = 固定位置；拖空白 = 平移；滚轮 = 缩放；悬停高亮一阶邻居

### 补充：标签聚合与邻接图（2026-09-21）

- 按资产已有的 `tags` 聚合为可展开的标签组，显示组内节点数量；点击标签组展开或聚焦其文件、题卡与锦囊。多标签归属保留，节点身份与总数按真实资产去重。
- 选中节点后可“以此为中心”查看邻接图：默认一阶邻居，可切换两阶；点击邻居可将其设为新中心。
- 标签筛选与邻接浏览可组合，清除筛选/中心后恢复全图；无匹配时显示真实空态。
- 聚合只改变视图，不改写文件或关系；同标签不自动生成引用边，组间关系只汇总已有真实连线。
- 控件沿用现有小图标、筛选入口和右键菜单，保持画布简约。路线 bench 的课序关系仍由路线投影管理，不混进知识图的拆分层级。

实施验收覆盖标签组展开/收起、多标签去重、一阶/两阶与换中心、组合筛选/空态/恢复全图，以及文件标签修改后的投影更新。本节为设计补充，不代表已实现。

### 实现

复用当前图谱的布局、DOM/SVG 和交互实现；聚合与邻接只改变投影。路线 bench 可提取共用画布，但提供独立路线数据，不复制一套内容索引或知识层级。

## 3. 卡片库视图

- 普通 `type: card` 与锦囊 `type: insight` 按实际类型展示，列表来自文件投影
- 每张卡：标题、摘录预览、↩来源行（来源路径 + 页码/锚点/层级）
- 顶部搜索 + 来源过滤 + 按层级分组
- 点击卡片 → 打开该 md；点来源 → 跳图谱节点或原文位置

## 4. 资产页统一阅读编辑

- Markdown 正文使用已有编辑器；讲义、剧本、独立小结和剧本内小结都作为资料呈现。
- PDF 在资产页按真实文件与页/选区定位；分页、缩放、适应宽度、提取为卡片及特殊视图通过简约图标/菜单展开。
- 图片可预览；现有受限 HTML 预览保持其实际能力，本批不新增可执行互动 HTML。
- 图谱双击、卡片来源回跳、路线节点的剧本/小结入口统一进入资产页。小结链接必须定位到该课堂对应的稳定段落。
- 浏览器阅读与模型读取分别验收；资产页能显示 PDF 不代表模型已得到原题。

## 5. 拆分关系存储（复用现有事实）

- 来源→卡片：沿实际已支持的文件/page/rect 引用保存，图谱按来源事实派生。
- 卡片→子卡片：沿 frontmatter `parent` 表达内容拆分；普通引用与路线依赖不写入这个字段。
- Markdown 片段：使用真实返回的定位与 revision。标题改名或文件变化可能导致定位失效，不能宣称标题天然抗编辑漂移；失效时重读/重选，不跳同名段落冒充原处。
- 文件保存遵守 CAS；外部变更保留未保存草稿，资产、卡片、图谱和搜索投影反映真实写入结果。

## 6. 路线与验收衔接

- 路线是与对话、图谱、资料并列的独立 bench，节点进入真实课堂或查看资料中的小结，详细行为见 [路线专题](../../migration/2026-09-21-lesson-route-and-log.md)。
- 按总合同分阶段验收：基础分屏/资料读写与设置 → 锦囊及标签/邻接图 → 路线与小结定位。
- 每阶段都检查可见交互、来源回跳、保存/冲突/刷新及控制台异常；不能用旧截图或示例 HTML 代替当前实例验证。

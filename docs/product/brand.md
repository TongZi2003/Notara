# Notara · 拾页

2026-09-14 用户确定：英文名 **Notara**，中文名 **拾页**。

**一本能展开成自习室的笔记本。**

产品首先承载个人的资料、笔记、卡片与长期积累；在这本笔记本上展开阅读、对话与自习。

- 本体：拆书、学习、记笔记、沉淀记忆。
- 基础工作台：资料工作台呈现学习对象、来源和联系；课堂思维图呈现学习过程、分支、结论与未解决问题。
- 扩展：世界书、多智能体课堂、黑板及其他工作台、技能、子智能体通过安装插件提供。不装插件也能完成核心学习，卸载插件不带走已保存的学习成果。各类扩展分别实现；当前支持范围见[插件接入](../runtime/plugins.md)。

产品哲学（为什么做、砍功能的判据）见 [philosophy.md](./philosophy.md)。

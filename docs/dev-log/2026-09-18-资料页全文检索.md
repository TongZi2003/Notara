# 资料页全文检索

## 目标

资料页补「哪本书哪页哪句话说过 X」的前门面：`LearningSearch` 引擎与
`studyforgeMaterials.search` remote 早已存在（PDF 命中经上轮 refine 返回
`pdftext` 字节级锚点），缺的只是检索入口、命中呈现与定位导航。

## 改动

`packages/client/src/materials/LibraryBrowser.tsx`：

- 检索框照旧实时过滤标题/标签；Enter 或旁置「搜全文」按钮调
  `ctx.remote.studyforgeMaterials.search({query, limit:50})` 进入结果态，
  「返回目录」或「清除筛选」回目录。`searchSeq` ref 丢弃过期响应。
- 命中行：语料图标 + 标题 + 「语料·位置」标签 + 摘录（`start/end` 切片
  `<mark>`，null 时整段）。`hitField` 标签：pdf/pdftext→第N页(摘录)，
  text→第N行，docx→文档选段，image→图上选区；卡/知识按 field 名映射
  （title→标题、front→题面、body→正文等）。
- 点击路由 `openHit`：material→新 prop `onSource(view, source)`；
  card/knowledge→`setSelected(ref)` 开内联详情（items 里找不到的卡回退
  `cardOpenRequest`+卡库面板）。
- 状态诚实：remote 失败显示「检索没有成功」与「没有命中」分开；`notes`
  不渲染（合同注明学生界面不渲染诊断）；`hasMore` 提示换更准的词。

`MaterialsPage.tsx`：`onSource` → `chooseMaterial(source.materialId,
source.versionId, source.locator)`——保留命中所在的不可变版本与锚点，
`MaterialPreview` 的 revealPage 负责翻页。

`library-browser.css`：`.sf-search-hits` 系列样式（沿用笔记本变量）。

## 验证

- `npm run typecheck` / `npm run build`：PASS
- `tests/e2e/materials-search.spec.ts`：1/1 PASS——textPdf「quasar」命中
  显示第 2 页标签+mark，点击翻到 `data-pdf-displayed-page=2`；markdown

  命中」；返回目录保留标题过滤、清除筛选恢复完整目录；控制台零错误。
- 回归：`library-catalog` 1/1 + `library-management` 2/2 PASS。
- live：未运行。

## 顺手确认的既有行为

- 「返回目录」只清搜索态，标题过滤词保留——回到的是过滤中的目录，
  「清除筛选」才恢复完整目录（spec 已断言）。
- 页面加载后新建的卡不在 `items` 快照里，命中时回退 `cardOpenRequest`
  +卡库面板——两条都是真实打开路径，不静默。

# PDF 标注层

## 目标

MarginNote 式标注层：PDF（及图片）上拖框圈选落成持久标注卡，已存标注在当前页显示为可点击高亮层。上一轮 Atlas 的「下一入口」。

## 实际改动（纯客户端，零合同/后端）

### `SourceCapture.tsx`

- 新增 `ctx: Context` prop（需要 `studyforgeLearning.cards/createCard` remote 与 `layout.selectPanel`）。
- `stage()`：选区照旧成为会话引用，同时记 `pending` 锚点；**`sessionId===undefined` 不再早退**——建卡不需要 lesson，资料页未开课也能存标注（此前守卫会让按钮永不出现）。
- `saveAnnotation()`：`createCard{title:'材料名 · 第N页'/' · 标注', presentation:'note', front:'', sources:[拖框锚点]}`——source-only 卡，`SourceExcerpt` 自动显示真实摘录。文本选段同样可存。
- 标注层 effect：`cards()` 全量拉取（与地图页同模式），过滤 `sources` 含 `{materialId,versionId 匹配, kind:'pdf', page=当前页, rect}` 的卡→`pdfGeometryOf`+`applyTransform` 正向变换画持久高亮（与 reveal 同一套坐标数学；`geometry.page` 校验天然只显示当页，翻页零状态管理）。图片 rect 同路径。
- 渲染：`annotation-mark` 按钮层（点击→`cardOpenRequest`+`selectPanel('studyforge.cards')`）；`annotation-save` 按钮（有选区框时贴框右下角，无框时内联）。
- 翻页清理连 `pending` 一起清。

### 接线

- `MaterialsPage.tsx`：`MaterialReader` 传 `ctx`。
- `SourcePane.tsx`：`SourcePaneProps/SourceBody` 加 `ctx`（窄 face 接口不动）——课内右栏阅读面同样获得标注层。
- `SourceDocument.tsx`、`LessonResources.tsx`：调用点补 `ctx`。

## 验证

- `npm run typecheck` / `npm run build`：PASS
- `tests/e2e/pdf-annotations.spec.ts`：**1/1 PASS**——拖框→存为标注→`annotation-mark` 持久出现→rpc 验卡带正确 pdf rect 锚点（page/rect 数值断言）→点标注进卡库 card-detail→rpc 预置第 2 页标注卡→重开材料页 1 页只显当页标注→翻页显示预置标注→控制台零错误
- 回归：`source-roundtrip` 6/6 + `source-only-study` 1/1 PASS（引用流、旋转页坐标、DOCX/图片选区无损）

# 2026-09-17 委派模型路由

## 目标

委派帮手（检索/命题/助教/同伴）可以指定本次任务使用的模型路由——任意已配置的 provider+model，而不是只能跟随本课老师的路由。用法：日常交互走轻量模型，出题、勘误等重判断任务路由到强模型。

## 依据

- `SubagentStartRequest.agentOptions`（dsh-subagent）原生支持 per-child `{provider, model, reasoningEffort, maxTokens}` 覆盖，one-shot `subagents.start` 与 `startContinuable` 两条路径都收。
- 同学（classmate）已有同构先例：`ClassmateTaskInput.routeOverride` + `routeOptions()` 转换 + `ClassroomModelRoute` 枚举。
- 委派输入 schema 是门面 `input` 的直接投影，加字段即自动暴露，facade 零改动。

## 实际改动

- `packages/host/src/teaching/native-delegation.ts`
  - 四个输入 schema（search/assistant/peer/problem）各加可选 `route`，复用 `ClassmateRouteSchema` 形状（provider/model/reasoningEffort/maxTokens）。
  - `TeachingDelegation.run`/`proposeProblems` 接受 `route`，经本地 `routeOptions()` 转成 `agentOptions` 传给 `subagents.start`/`startContinuable`；省略时不传，跟随父会话。
  - `DelegationResultSchema`/`ProblemResultSchema` 增加 `route` 回显字段，结果可审计本次用了哪条路由。
  - 工具描述补一句路由用法说明（四个委派共享后缀）。
- 隐私与隔离不变：`route` 只换模型路由，child 的工具 allow-list、persona、隔离语义原样；填了未注册的 provider/model 由 `subagents.start` 拒绝并如实报错。
- 测试
  - `tests/unit/delegation-route.test.ts`：四 schema 接受/省略/拒绝非法 route；`toolSchema` 投影含 route 与 reasoningEffort。
  - `tests/integration/native-delegation.test.ts` 新增用例：`delegate_search` 带 `route:{provider:'studyforge-test',model:'study-model-b'}`，model-requests 日志断言子会话真实跑在 study-model-b、父会话仍 study-model-a。
  - `tests/integration/assistant-boundaries.test.ts`：problem 输入字段清单断言补 `route`。

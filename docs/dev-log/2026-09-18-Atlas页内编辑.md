# Atlas 页内编辑：菜单与拖拽共走 preview→confirm→save

## 目标

知识地图页从只读投影升级为可编辑：节点菜单（改名/移动到/新建子层/删除）与画布拖拽（主题→主题 repath、卡→主题归位）都走 `previewAtlas` → 影响确认 → `saveAtlas` 的确认链，不绕过域规则。

## 实际改动

### Host remote（薄边界）

- `packages/host/src/organization-service.ts`：新增 `previewAtlas`/`saveAtlas`，照搬骨架作者面的 `previewSkeleton`/`saveSkeleton` 对——schema 校验后透传 `AtlasAuthoring.preview`/`save`，域规则零复制。

### 客户端

- `packages/client/src/planning/MapPage.tsx`：
  - `AtlasDraft` 状态机（action 种类、path、input、target、preview 结果、detach 闸、busy/error）。
  - `atlasActions`：每个主题节点的菜单动作（改名/移动到/新建子层/删除）。
  - `onAtlasDrop`：`topic:` 节点落到 `topic:` 节点 → 预填移动草稿（仍走预览确认）；`card:` 叶落到 `topic:` 节点 → 直接 `editCard` 改 `topic`（卡片自身变更不经 Atlas 预览）；无效落点（自身/子孙/非主题）静默拒绝并由 `dropDenied` 给视觉反馈。
  - 编辑面板 `data-testid="atlas-edit"`：改名输入、目标层选择、子层名、影响摘要（`atlas-impact`）、detach 复选（`preview.requiresDetach` 时强制勾选才能保存）、预览/保存按钮。
- `packages/client/src/materials/mindmap.tsx`：
  - 新增可选 `onDrop(sourceKey, targetKey)`/`dropDenied` props（`exactOptionalPropertyTypes` 兼容）。
  - 拖拽时把被拖节点 `pointer-events:none`，`elementFromPoint` 找落点节点，`dropTarget` 高亮。
  - 边角：无 `onMove`（atlas 不做自由定位）时落空拖拽清掉临时 `moved` 坐标，避免视觉残留。
- `packages/client/src/planning/map-page.css` + `css-modules.d.ts`：`.sf-map-*` 面板样式与 css 声明。

## 排障记录

- spec 初版假设「数学」「科学」父层自动存在——`AtlasDeriver.plan` 只铸**精确声明的路径**（卡声明 `数学/三角函数` 只铸这一个节点）。改为让卡直接声明 `科学` 使父层真实存在。
- `CSS.escape` 是浏览器 API，Node 侧 spec 不可用；key 只含中文/`/`，直接内联属性选择器。
- 「未归图」展开态按 key 存在 `MapPage.expanded` state 里，组空了又回来仍展开——不要重复点「展开未归图」（会命中不存在的按钮）。

# 跨书知识地图 Atlas + 知识地图页

## 目标

跨书卡的组织盲区：骨架按 `materialId` 隔离，跨书卡与无来源卡无层级归属。要求支持用户/AI 建立不依赖书的层次脑图；前端展示按书籍分布节点图并可切换到 Atlas 视图。

## 实际改动

### 合同（contracts）

- 新 `src/atlas.ts`：`AtlasNode{path, note?, sources?, detail: outline|refined}`、`AtlasRecord`、`AtlasView{revision, nodes}`、`ATLAS_REF = atlas:main`、`ATLAS_KIND`。sources 可空、可跨书——脑图节点是语义桶不是阅读凭证。
- `cards.ts`：`CardContent.topic`、`CardPatch.topic`（null=清除，省略=不动）、`CardListInput.topic` 前缀过滤、`CardSummary.topic`。
- `proposals.ts`：`atlas-save` 提案效果（target=atlas:main）。
- `tool-facades.ts`：`read_atlas→open.atlas`、`propose_atlas→propose.atlas`（wire 恒定 21）。
- `package.json`：显式 `./atlas` 导出（Typert 只认显式键，`./*` 通配不生效）。
- `index.ts`：atlas re-export。

### 领域（domain）

- 新 `organization/atlas.ts`：`AtlasService`（read/authoring/deriver 一体）。`plan` 按 scope 聚合 topic claims→同一原子批一个 atlas 变更；缺失路径铸 `{path, sources: 卡真实锚点(不限书), detail:'outline'}`，无单源限制（多书卡、无来源卡都能声明）。`repath` 级联卡 topic（复用 skeleton-authoring 导出的 `beneath/remap`）；`removePaths` 带依赖须 `detachDependents`。
- `card-service.ts`：`ChapterClaim.chapter→path`（内部改名）、第二端口 `topics`、`assertTopic`（坏路径 `card_topic_invalid`、未接 `card_topic_missing`）、`placementPlans` 双收集（chapter 按 materialId + topic 按 main）、`selectCardRows` topic 过滤。
- `skeleton-authoring.ts`：`beneath`/`remap`/`changedChapter` 导出复用。
- `package.json` + `tsconfig.base.json`：`./atlas` 导出与 src 映射。

### Host

- `index.ts`：atlas collection、AtlasService/AtlasDeriver 接线、CardService `topics` 注入、provide。
- `organization-tools.ts`：`read_atlas`/`propose_atlas` 工具；`observedVersion` 认 `read_atlas`。
- `proposal-executor.ts`：`atlas-save` validate/apply（缺失时 baseline 0→创建）。
- `organization-service.ts`：`map` remote→`{books: BookStructure[], atlas: AtlasView}`（列当前材料版本各读 book structure + 读 atlas）。
- `teaching-context.ts`：`helperForbidden` 补 `propose_atlas`（帮手可读不可提案，与 `propose_skeleton` 对齐）。

### 客户端

- 新 `planning/MapPage.tsx`：`studyforge.map` 页。按书籍（默认，书根→骨架节→卡/知识叶森林）⇄ Atlas（topic 树 + 卡按归属落层，无 topic 卡收「未归图」伪根）双视图共用 `Mindmap`；图/列表形态、展开、刷新。点卡→`cardOpenRequest` 进卡库；点节/书→`MaterialNavigation` 定位原文。只读不写。
- `register-organization.tsx`：main slot + sidebar panellist 行（order 36，知识地图）+ `.sf-map-*` 样式。
- `NotebookSidebar.tsx`：`PRIMARY` 白名单补 `studyforge.map`——**漏补则行注册了但不渲染**（卡片页同因缺 PRIMARY 也不显示，既有行为）。
- `CardEditor.tsx`：topic 输入框（`card-editor-topic`）、create/冲突合并/预览带 topic。
- `CardBrowser/CardDetail/format.ts`：topic 显示与 patch 生成。
- `ProposalCard.tsx` + `SkeletonSummary.tsx`：`atlas-save` 展示（SkeletonSummary 泛化复用，node.sources 改可选）。

### 提示词与工具描述

- `guided-learning.md`：chapter=书内层级（单源限制）vs topic=工作区级 Atlas 路径（跨书、无来源可声明、缺层顺带铸）；outline≠已精读；repath 级联；list_cards topic 过滤；AI 先 `read_atlas` 再 `propose_atlas`。
- `base.md`：卡检索收窄字段补 topic。
- `card-tools.ts`/`organization-tools.ts`/`proposal-tools.ts`：描述同步。

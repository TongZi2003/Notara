# 2026-09-16 规划入口、课内路线投影与附件入库工具

## 目标

补齐自学链路的三处可交互缺口：学生从空白课堂进入 guided 规划流程的入口、课内阶段路线的常驻投影、学生上传附件由模型收进资料库的通道；并审计各会话管理机制对 compact 的韧性。

## 实际改动

- `packages/client/src/classroom/LearningComposer.tsx` `MoreActions`/`LearningActionsMenu`：「+」菜单新增「规划学习路线」项（testid `learning-entry-plan`，图标 `plan`）。仅空白会话（`byId[].blank`）且课程未 `guided` 时显示，参与搜索过滤。点击后 `studyforgeCourses.update` 写入 `{guided:true, teachingRef:'diagnose'}`（`expectedVersion` 校验、失败重读并提示），再经 `insertTaskSkill` 同款路径向输入框预填「我想规划一下自己的学习。」——发送权留给学生。guided 流程本体仍是 `resources/teaching/presets/guided-learning.md`，未新增第二套规划系统。
- `packages/client/src/classroom/LearningWorkspace.tsx` `StageTracker`（新增）：工作区级「本课路线」条，渲染在视图栏与面板区之间。每阶段一 chip（序号/标题/状态：进行中·已完成·已分支·已暂停），当前阶段目标随行显示；点击 chip 经 `thoughtAnchors` + `revealWorkspaceView` 打开思维图并定位到该阶段首节点。数据来自 `studyforgeTrace.read`，`running`/`learning-changed`/focus 时重读；无阶段不渲染。样式在 `learning-workspace.css` `.sf-stage-tracker` 段，窄屏保留 chips 隐藏目标长文本。
- `packages/host/src/teaching/teaching-context.ts` `installTeaching`：`studyforge:teaching` section 新增「本课阶段路线」简报——从 `studyforgeThoughts` 持久化 frames 轻量读取（不走重的 `trace.read`），每轮重组装注入，compact 后模型仍知道当前阶段与 `nextGoal`。同文件 `helperForbidden` 加入 `import_uploaded_material`。
- `packages/host/src/tools/material-tools.ts`：注册 `import_uploaded_material`。模型按消息中显示的文件名调用；Host 经 `sessionQuery.observeSession` 扫本会话 `user/message` 事件的 `FileBlock`，按 `attachment.name`（或 `fileHostPath` 兜底）匹配 → `attachments.readFileStream` 读字节 → `mediaTypeForFileName` 定格式 → `studyforgeMaterialService.import` 走既有校验/不可变版本/重名拒绝管线，返回真实 `materialId`/`versionId`/`revision`。不匹配、格式不收、读不到字节均如实报错。
- `packages/domain/src/materials/import-validation.ts`：导出 `mediaTypeForFileName`（扩展名 → `MaterialMediaType` 反查）；`material-service.ts` 再导出。
- `packages/host/src/tools/tool-disclosure.ts`：新工具归入「资料与卡片」组，`load_tools` 可发现。
- `packages/client/src/classroom/ClassroomTrace.tsx`：锚点解析改为先精确命中 `event:*`/sequence 节点再回退阶段范围；`edit` 在首读未返回时先拉一次基线再保存，不再静默丢弃学生措辞。
- `resources/teaching/guided-learning.md`「确定目标与资料」：补外网取料约定——`web_search`/`web_fetch` 找公开资料、实际读到的内容用 `create_markdown_material` 入库并保留原始 URL；学生附件用 `import_uploaded_material`；新资料进学习集/本课资料栏走提案确认。

## Compact 韧性审计结论

| 机制 | compact 后 | 依据 |
|---|---|---|
| 已加载工具、先读再写观察 | 安全 | 扫原始 `snapshotEvents`，compact 只重写派生消息面 |
| 学习目标/路线/诊断简报、上节小结 pin、本课材料、世界书 | 安全 | 每轮 `system-prompt/assemble` 从持久化记录重注入 |
| 当前课堂阶段/nextGoal | 本轮已补 | 此前只在思维图 frame 上，现每轮注入简报 |

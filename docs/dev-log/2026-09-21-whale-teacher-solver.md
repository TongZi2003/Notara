# 大肥鱼与解题者：首版实施记录

## 已确定范围与实施计划

用户将首版收敛为固定两角色：大肥鱼老师（爱吃白饭的鲸鱼娘女仆、DeepSeek 拟人化）与后台解题者，解题者使用用户选择的 `gpt-5.6-sol`。完整世界观、公开同学、自动参与规则暂不实现；保留在总方案后续范围。

- 教师人格与解题者行为分别放 `resources/vault-teaching/persona.md`、`solver.md`；既有教法继续生效。
- `examples/native-vault/solver-runtime.js` 负责模型选择、固定任务、原生独立 spawn、取消和学生状态投影。首版一题一委派，同步把结果交回老师；不建立持续驻留或可公开发言的子会话。
- 沿用原生 session 扩展事件保存独立路由和任务状态，配置使用 revision CAS；题目与完整输出保留在原生工具/子会话轨迹，不复制到学生任务列表。
- 用户随后明确要求能点开看子代理做了什么：任务在原生子会话建立后提供“查看分析（含完整解法）”，Host 从本课日志定位并核对子会话归属，然后进入原生 one-shot 只读页。默认不内联后台报告，显式查看允许完整题面、分析与轨迹，不另造聊天。
- 教室 bench 展示两个角色、任务状态和按需展开的模型配置，复用现有分屏和唯一 composer；工具行不内联后台报告，用户可主动打开原生子会话查看。
- 主 Agent 独占后端/资源接线；体验 Agent 独占 UI；验证 Agent 独占新增 Host/browser 用例及合成模型 fixture。

## 验收计划

已先新增 `solver-runtime.test.js`，首次运行六项测试均因实现缺失而失败。接下来验证独立模型路由、无静默 fallback、零工具/无父历史、配置冲突与恢复、取消后迟到结果、递归委派拒绝；真实 Host 请求捕获与浏览器可见行为由隔离实例验收。真实模型证据与合成 adapter 分开记账。

## 实际交付与证据

- 包版本升为 `@notara/vault-native@0.6.0`。仅目标工作树改动，未提交、未更新其他实例或用户插件快照。
- `NotaraSolver.ask/task/cancel`：独立路由、有限供料、零工具 spawn、状态与 child 绑定落原生日志、同课归属核对、取消后同输入禁止自动重派、失败收尾与单次执行资源释放。
- `classroom-client.js` 与 `workspace-client.js`：独立教室 bench、路由编辑与草稿冲突保留、原生子会话查看及返回；子会话不显示主教师的教室/教学设置。
- `installTeachingRuntime`：主教师加载大肥鱼人格，子代理装配独立解题指令；归档协调取消任务。普通非教学预设保持原有委派能力。
- PASS：构建；152 个 Node 测试；11 个真实 Host/合成模型集成场景；两条浏览器流程（配置保存重开，以及分析查看/返回/取消）。主 Agent 另核对截图并运行定向装配复验。
- FAIL（既有全仓测试类型问题）：`typecheck:tests` 仍报 `teaching-rounds.test.ts`、`tool-disclosure.test.ts`、`journey.test.ts` 既有错误，新文件不在报错清单。
- 未运行：真实 `gpt-5.6-sol` 解题与长期教学质量；隔离实例使用合成 adapter，本次环境未提供外部模型凭据，不读取真实用户配置替代测试。
- 初次失败保留：单元实现缺失与未同步的新资源；复核发现原生 dispose 异常可造成完成状态与失败回执不一致，已先复现后修正。浏览器最初错误地假定中文 locale、只读页会卸载 composer、工具过程默认展开，已按原生真实行为修正断言，无控制台异常。

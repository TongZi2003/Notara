## 实际改动（产品源码）

- `packages/client/src/classroom/session-recovery.ts`（新增）：启动竞态兜底。上游 `watchNavigation.reconcile` 的会话绑定判断不可逆，且 `openWorkspace` 内部 `beginNavigation()` 信号会被后续导航静默中止（正常 resolve 不抛错），早期实现的 `attempted` 一次性标志因此卡死。现行实现按上游 `recentWorkspace` 语义选最近工作区，直接调 `ctx.uiWorkspace.connectWorkspace` + 复查 current + `ctx.sessions.open`，失败有界重试；只在本次生命周期从未绑定过会话时生效，不覆盖用户主动的清空/新会话选择。注册于 `packages/client/src/client/index.tsx`（注入 `workspaces`、`sessions`、`uiWorkspace`）。
- `packages/client/src/materials/source-selection.ts` `active()`：serialized pick 不再短路当前浏览上下文；右栏 active 匹配不到工作区 pane 注册的 `workspace:<sid>:materials` 浏览标签时，回退到本会话最近的 browse tab。修复发送消息后 `currentMaterial` 不再随浏览走的回归。
- `packages/client/src/classroom/lesson-uploads.ts`：上传队列从 `WeakMap<Context>` 改为按 `sessionId` 键控——LearningWorkspace 插件与 Classroom 插件是两个 cordis context，按 context 分队列会把同一节课的上传拆成两份。
- `packages/client/src/materials/MaterialsPage.tsx`：列表 loading 期间不再渲染 `ImportMaterial` 输入框（`empty` 未定时不给输入框）——加载完成时头部输入框被空态输入框替换，`setInputFiles` 的 change 事件派发到已卸载节点，文件被静默吞掉。
- `packages/client/src/materials/LessonResources.tsx`：sheet 的 `onPointerDownCapture`/`onFocusCapture` 激活不再触发 scroll-into-view（`activatedInside` ref）。原实现 pointerdown 置 active → 同步重渲染 → 滚动 effect 移动 × 按钮 → click 落空，`closeSheet` 从未触发；真实用户点部分出屏 sheet 的关闭钮第一次必被吞。
- `packages/client/src/classroom/ClassroomTrace.tsx` `resolveAnchor`：锚点解析先精确命中 `event:*` 节点（sequence → turn），阶段范围作兜底——`sources` 只挂在事件节点上，先命中阶段节点会让「查看原文」永远不出现。
- `scripts/dev-isolated.ts`：临时 `DSH_HOME/settings.yaml` 预置 `ui-onboarding.welcomeNoticeVersion: 2026-08-13.1`，消除上游 Internal Testing Notice 遮罩拦截点击的 flake。

# 2026-09-17 拒绝语义统一修复

## 目标

修掉真机演示暴露的缺口：`propose_route` 被门控拒绝后，教师误诊断为「学生没点确认」，让学生「再点一次」；实际是提案根本没有生成，需要重提。要求：拒绝就是拒绝，拒绝的 result 直接说清「未产生任何提案或改动、如实告诉用户并听取意见、修正后需重新提交」，其他同类拒绝同样小修。

## 实际改动

在 `packages/host/src/tools/learning-context.ts` 新增共享 `rejected(reason)`：在原因后统一追加「本次调用被拒绝，未生成任何提案或改动；把原因如实告诉用户并听取其意见，修正后需要重新提交，不会自动生效。」（措辞用「用户」，同时覆盖课堂学生与创作会话作者）。

把「可修正的域拒绝」逐点换用 `rejected(...)`；内部不变量（target/baseline 不匹配、快照损坏、schema 校验）保留原错误码，不裹进模型话术。

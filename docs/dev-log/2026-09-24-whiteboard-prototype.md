- `docs/ui/notara-frontend-prototype.html` 的 `lessonHTML`、`render` 和伴随面板动作：新增白板页签，示例 l1 默认打开；保留原对话与教室页签；白板旁只有一个既有课堂输入框。重新渲染时保留白板滚动位置。
- `docs/ui/notara-whiteboard.js` 的 `state`、`blocks`、`content`：Markdown 作为唯一可写正文，按稳定分块标记投影；渲染转义用户 HTML。分块语法仅供此机制原型，不是生产合同。
- `html`、`blockHTML`、`install`：分别折叠题面/尝试/提示/参考解释；记录和编辑想法；对话摘录加入板书并保留所引资料；围绕内容追问进入同一输入框，保留已有草稿。选择题反馈是确定性的合成示例，不代表真实模型教学。
- `graphHTML`、`source`、`jump`：知识视图为本课笔记引用的实际示例资料；关系复用原资料的来源、上级专题与案例链接；可打开资料、按小节定位并跳回板书块。未新增概念图或掌握/复习状态。
- `exportData`、`exportDialog`：生成相同范围的 Markdown 与独立 HTML；默认物理排除学生尝试/对话摘录、提示/参考解释。普通笔记里手动写入的内容照常导出并明确提示。HTML 内联样式与 SVG，保留原生 details；Markdown 用本地来源锚点和内嵌 SVG，避免依赖原型内部链接。导出只列出处，不打包原资料全文。
- `persist`：种子示例课 Markdown 写入当前浏览器 localStorage；失败提示导出备份。新建课堂保留旧原型的临时内存生命周期，刷新前可导出，未虚构真实会话持久化。
- `docs/ui/notara-whiteboard.css`：沿用白灰主题及已有深色/手帐变量；移动端设计为白板与同一对话互切。当前版式明确为机制占位。

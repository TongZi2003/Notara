# 2026-09-16 世界书角色扮演：情景设定、选择性条目与会话级亲密度

## 目标

按用户裁定的「先做 1+2，然后 3」把世界书扩成角色扮演设施：1) 情景层静态字段（scenario/studentPersona/personality/greeting/talkativeness/relations）；2) 条目机制（次级关键词+选择性逻辑、角色绑定、亲密度门槛、有限扫描深度）；3) 会话级动态亲密度（运行时状态面 + 教师调整工具）。全程坚持纯情景信息定位：不写学生记忆、不作学习判断。

## 实际改动

- `packages/contracts/src/classroom.ts`：`ClassmateSchema` 增 `personality`/`greeting`/`talkativeness`/`relations`（沿用本轮早些时候的 `ClassmateRelationSchema`）；`ClassroomDefinitionSchema` 增 `scenario`/`studentPersona`；`ClassroomSessionRecordSchema` 增 `intimacy` 覆盖表（`${roleId}:${target}` → 0-100）；`ClassroomRuntimeView` 增 `intimacy` 投影（有效值 + `runtime` 标记是否本课覆盖）；导出 `Key` 供工具参数复用。
- `packages/contracts/src/plugins.ts`：`WorldbookEntrySchema` 增 `secondaryKeywords`（≤10）、`selective`（and-any/and-all/not-any/not-all）、`role`（绑同学）、`roleVisible`（默认只给教师侧，勾选才进同学扮演上下文）、`intimacyAtLeast`；`WorldbookDocumentSchema.superRefine` 校验 `worldbook_role_missing` / `worldbook_intimacy_needs_role` / `worldbook_role_visible_needs_role`。
- `packages/host/src/plugins/worldbook-selection.ts` `selectWorldbookEntries`：新增第四参 `WorldbookScan`（`scan` 额外扫描文本、`activeRoles`、`intimacyOf` 解析器）。匹配序：enabled → 角色在场 → 主关键词/always → 次级关键词逻辑（selective 缺省按 and-any，与 UI 显示一致；修复过「填了次级词但没碰下拉导致 selective=undefined 使过滤静默失效」的隐患）→ 亲密度门槛（对 student 的有效值）。容量 8 条 / 5940 字符预算与 omitted 计数不变；仍无递归触发、无助手输出参与匹配。
- `packages/host/src/plugins/worldbook-context.ts` `recentUserTexts`：取最近 3 条真实 `user/message`（`source.kind==='user'`）作扫描深度；`worldbookContext` 传入。排队/取消/生成消息不参与。实测语义：当前用户消息经 `agent/inbox/spliced` 进轮、轮结束后才落成 `user/message` 事件，所以窗口=「当前输入 + 之前 3 条已落盘用户消息」，触发词续燃约 3 轮后消退。
- `packages/host/src/plugins/workbench-data.ts` `background`：透传 `scan`。
- `packages/host/src/plugins/classroom-runtime.ts`：
  - `relationText`（导出）双向渲染并接受 `IntimacyOf` 解析器，行内标注「仅是角色背景设定，不涉及学习评价」。
  - 同学 persona（`system-prompt/assemble` 钩子）追加情景块：性格 → 情景 → 学生身份 → 关系（有效亲密度）→ `roleVisible` 且绑定自己的世界书条目 → 开场白；文档丢失时回退任务快照；隔离契约原文保留（无工具/无资料库/无父会话/不写学习事实）。
  - `intimacyOf`：会话覆盖优先，文档默认兜底。
  - `adjustIntimacy`：校验角色/目标存在 → `ensureSession` → CAS 更新 session record 的 `intimacy` 覆盖表 → 返回新 view。只写本课情景状态，不动文档。
  - `selection()`：扫描深度取最近学生消息；`activeRoles` = 本轮已派发任务的角色 ∪ 扫描文本中被 @ 点名的角色；传 `intimacyOf`。
  - `view()`：投影 `intimacy` 列表（覆盖键 ∪ 文档默认键，解析名称）。
  - 教师 `本课教室` 上下文：带 `scenario`/`studentPersona`，roles 行带 `personality`/`talkativeness`/`relations`（目标解析成名、有效亲密度）。
- `packages/host/src/classroom-service.ts`：注册 `adjust_classroom_intimacy` 教师工具（schema 校验 id/roleId/target/value，走 `teacherContext`）；`tool-disclosure.ts` 归「教室参与」组。
- `packages/client/src/plugins/ClassroomWorkbench.tsx`：成员页加「情景设定」折叠块（情景前提 textarea + 学生人设 input）；角色设定页加 性格标签/开场白/发言倾向 + 已有「情景关系」编辑器 + 有效亲密度显示（`本课亲密度 · 对X：N（本课已调整/文档默认）`）；条目编辑器加 次级关键词/触发逻辑/仅当同学在场/亲密度门槛（仅绑角色时显示）/「同时带进这位同学自己的扮演上下文」勾选。
- `examples/plugins/worldbook`：creator.md 补情景层与条目机制约定（纯扮演背景、收窄语义、不写学习事实）；templates.json 更新示例；版本 1.1.1 → 1.2.0。

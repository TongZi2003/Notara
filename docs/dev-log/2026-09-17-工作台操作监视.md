# 工作台操作监视（board activity）

## 目标

学生不可避免地会在 board iframe 里拖拽、调参、增删对象——这些操作此前只落为不可见的文档版本，教师模型要下次主动读板才知道发生过什么。本轮把「写路径」变成一条可查、可注入的操作轨迹：只记写操作（不记 UI 事件），每个板一份追加式轨迹，语义标签由插件上报，通用 diff 由 host 派生。

## 边界与取舍

- iframe 不透明（sandbox + CSP），父页看不到指针事件；权威边界是文档写路径 `Notara.saveDocument → writeDocument → LearningWorkbenches.write`。
- 活动记录独立于 `PluginDocumentRecord`：文档是权威状态，活动是审计投影；append 失败只记日志、绝不让成功的保存显得失败。
- 轨迹键 `sessionId:id` 不含 digest——插件升级后历史连续；补录走 `RecordStore.changes()` + 不可变版本重算 diff。
- 读路径不得有副作用：`plugin-manager` 新增 `openedWorkbench`（只读、不建 pin）；所有写路径本身会先建 pin，故未打开的板必然无轨迹。

- `packages/contracts/src/plugins.ts`：`WorkbenchOpSchema`（`{labels?: string[]}`，≤8 条）、`WorkbenchActivityEntrySchema`（at/actor/kind/revision?/labels?/detail?，kind ∈ document|draft|worldbook|note）、`WorkbenchActivitySchema`（events ≤160）。
- `packages/contracts/src/tool-facades.ts`：`board.activity → read_workbench_activity`。
- `packages/host/src/plugins/board-activity.ts`（新）：`summarizeDocumentChange`（math 语义化 diff：对象增删/点位移/参数值变/视区/相机/观察；其余板型走字段级 genericChange）+ `summarizeWorldbookChange` + `BoardActivity`（append 幂等按 operationId；activity 合并存储条目与未覆盖的 record 操作；view/boards/prompt）。
- `packages/host/src/plugins/learning-workbenches.ts`：`write()` 收 `op?: WorkbenchOp`，写后 append document 条目（try/catch 包裹）；注册 `read_workbench_activity` 工具（teacherContext、拒 subagent、无 id 列板/有 id 返回条目）。
- `packages/host/src/plugins/workbench-data.ts`：`saveWorldbook`/`saveDraft` 记 worldbook/draft 条目。
- `packages/host/src/plugins-service.ts`：`saveDraft` remote 接 `op`；`saveNote` 记 note 条目（operationId 前缀 `plugin-note:`）。
- `packages/host/src/plugin-learning-service.ts`：`writeDocument` remote 接 `op`（签名用 `WorkbenchOp`，typert 边界不接受 `unknown`）。
- `packages/host/src/plugins/plugin-manager.ts`：拆出 `workbenchContent`，新增 `openedWorkbench`（只读 peek）。
- `packages/host/src/index.ts`：`owner.collection('workbenchactivity', …)` 装配 `BoardActivity`。
- `packages/host/src/teaching/teaching-context.ts`：`owns()` 内注入 `notara:board-activity` context（仅学生条目、每板至多 8 行、总行封顶 8）；`helperForbidden` 加 `read_workbench_activity`。

- `packages/client/src/plugins/workbench-sdk.ts`：`saveDocument`/`saveDraft` 第三参 `op`；`learning-bridge.ts` document-write 校验并透传 `op`；`PluginWorkbench.tsx` draft-save 白名单加 `op` + `WorkbenchOpSchema` 校验。

- `examples/plugins/math-workbench/package.json`：1.4.1 → 1.4.2；`workbench.html` 已重建（1748037 字节）。

- e2e 只覆盖了 pan + 落点；拖拽已有对象（'移动 X'）的指针路径未在浏览器里打。

# PDF 文本层：学生拖选文字直接落 pdftext 字节级锚点

## 目标

PdfViewer 从「canvas + 拖框」升级为「canvas + pdf.js TextLayer」：学生拖选字形直接产 `pdftext` 锚点（页文本层 UTF-16 偏移），存的摘录卡在字级高亮渲染；扫描件/旋转页自动退回拖框。

## 实际改动

### 渲染侧

- `packages/client/src/materials/pdf/PdfViewer.tsx`：
  - render effect 在 canvas 提交后同批次建 `TextLayer`（`page.streamTextContent()` → `layer.render()`），`viewport.rotation !== 0` 或抽不出文本时不建层——诚实退回矩形捕获。
  - 渲染后给每个 `textDivs[i]` 盖 `data-sf-base` = 该 item 在域 `read-material` join 序列（`str` items `'\n'` join）里的基准偏移；`textDivs`/`textContentItemsStr` 与 join 序列同源同序（`item.str === undefined` 两边一起跳过）。
  - 层宿主盖 `data-sf-page`/`data-sf-pdf-text`（`ready|empty`）；`--total-scale-factor` 按 pdf.js 6.x 的 CSS 变量契约设在层上。
  - JSX：`.sf-pdf-page-inner`（`position:relative`）包 canvas + `.sf-pdf-text`；effect 清理 `textLayer.cancel()`。
- `packages/client/src/materials/register-materials.tsx`：移植 pdf.js `.textLayer` 核心规则为 `.sf-pdf-text`（透明字形、`--text-scale-factor` 字号、`--rotate/--scale-x` 变换、`markedContent{display:contents}`）；**层 `pointer-events:none`、item span `pointer-events:auto`**——字形上可拖选，空白处穿透回 canvas 保住拖框。

### 锚点侧

- `packages/client/src/materials/anchors/pdf.ts`：
  - `pdfTextLocator(layer, range)`：`Range.comparePoint` 沿 item span 文档序归并端点；span 内精确、span 间钳到下一 item 起点、末尾钳到 join 长度（无尾换行）；`start >= end` 或页戳缺失 → undefined。
  - `pdftextRects(layer, start, end)`：同一组 span 上算覆盖矩形——高亮与锚点不可能不一致。
- `packages/client/src/materials/anchors/index.ts`：PDF 分支先试文本层（命中即 `pdftext` + `quote`），未命中再退回 `pdfLocator` 矩形。

### 呈现侧

- `packages/client/src/materials/SourceCapture.tsx`：
  - 拖选暂存时即画 span 高亮（`pdftextRects`），「存为标注」照旧走 `createCard` source-only 管线。
  - 持久标注层：`pdftext` 锚点有 span 且层在正确页 → 字形高亮（`annotation-mark`）；层不在（未渲染/旋转/扫描）→ 退回「指路」角标。
  - locator 定位高亮：`pdftext` 早退改为画 span 框。
  - `saveAnnotation` 页码取 `pdf|pdftext` 两者。

## 设计要点

- `comparePoint` 归并保证「span 外端点」也有诚实偏移（界点钳到 item 边界，包含或不包含 join 的 '\n' 都对应真实文本位置）。
- `data-sf-pdf-text="empty"` 的层 `display:none`——扫描页零开销零干扰。
- 旋转页显式跳过文本层（未移植 pdf.js 的 `[data-main-rotation]` 翻转规则），拖框不受影响。

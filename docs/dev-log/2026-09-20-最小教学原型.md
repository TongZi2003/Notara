# 最小教学原型

## 目标

默认课堂只保留知识库、对话内路线图、世界书、只读子智能体和完整路线规划。数学工作台、round、Seminar 和其他工作台保留实现，但移出默认 UI 和默认模型工具面。

## 实际改动

- `packages/contracts/src/tool-facades.ts` 增加默认课堂 facade method allowlist：保留学习资料、阶段、路线规划、世界书/课堂和只读委派；排除 `board`、`round` 和 `delegate_problem`。
- `packages/host/src/tools/tool-disclosure.ts` 在默认课堂投影 facade schema 时按 allowlist裁剪分支。
- `packages/host/src/tools/tool-facades.ts` 的静态能力目录使用同一 allowlist，不再把隐藏能力写进默认提示上下文。
- `packages/client/src/classroom/workspace-layout.ts` 默认视图从 `chat/thoughts/materials/rounds` 收缩为 `chat/thoughts/materials`。
- `packages/client/src/classroom/LearningWorkspace.tsx` 和 `WorkbenchGuide.tsx` 不再自动把已安装插件工作台或 round 加进默认课堂入口；插件实现仍保留在插件页和 Host 注册表。
- `examples/plugins/README.md`、`docs/runtime/plugins.md`、`docs/runtime/skills-and-tools.md` 对齐默认插件和工具边界。
- 教学提示词 `resources/teaching/` 未改动。

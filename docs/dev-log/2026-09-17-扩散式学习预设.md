# 扩散式学习预设

## 目标

新增「diffusion 学习法」教法预设：围绕一个核心话题向外发散（例：AI agent 前世今生 → 前缀补齐 → chatbot → langgraph → coding agent → harness），学生疑问长成待确认分支，终期是真实任务验收（例：用 rust/python 重写 pi core）。

## 设计结论（讨论已定）

- **约九成由现有原语承载**：`RouteNode.parent` 树形分叉、`decl.stance`/`teachingRef` 按节点选教法、`route-edit` 提案即「待确认发散点」、`note_method` 存认知、`create_markdown_material` 存自产教材、handoff/continuation 跨日接续。缺的是一个课程级 preset，不是新数据模型。
- **发散授权、收敛职责**：开不开分支由学生提案确认；「值得一站还是一个坑」是老师的判断。主干深度由终点倒推，越近终点越向应用层收窄（GPT-3 之后不再深挖 infra/pretrain）。
- **留名的坑用认知笔记，不开节点**（用户拍板）：笔记零成本，节点是承诺；坑留在纸面上，想回头随时开成新课。
- **终期站材料反转**：验收课的材料 = 学生沿途自产的认知笔记和教材，即任务规格说明；老师从讲解者变评审者。
- 支点：学习目标行已常驻 teacher system prompt，「终点是什么」每轮可见，收缩判断有固定参照。
- 不进 `INTERACTION_MODES`（课程级模式，不是学生快捷互动档）；不加 `LessonMaterial.kind:'knowledge'`（认知锚点靠永久索引 + stance 文字，暂不需要合同扩展）。

## 实际改动

- 新增 `resources/teaching/presets/diffusion.md`：四段——定位、铺主干（终点倒推/应用层收窄）、发散与收敛的分工（提案授权 + 留名的坑）、每站收口与终期验收。
- `resources/teaching/manifest.json` 注册 `diffusion`；`course.teachingRef`/`decl.teachingRef` 选 `'diffusion'` 即注入。
- `tests/integration/teaching-current.test.ts` choices 断言补「扩散式学习」。

## 未完成与下一入口

- preset 正文由人读稿审（提示词改动不钉断言）。
- 真机验收：起点消息「我想学 AI agent 的前世今生，最后用 rust 重写一个 pi core」+ 课程 teachingRef=diffusion，观察主干铺法、疑问→提案分支、坑笔记留名、终期站材料反转是否如设计发生。
- 受众校准（用户确认：面向大学生——已经到了自学者阶段，学的是课堂约束装不下的知识）：终点需要的先修基础按同一尺度排进主干；问题是学生自己的，模糊时一起磨清楚不替他改写；终期验收标准=学生能解释自己写出的每一行。
- 轨迹成书：不做 Host 汇编机制——模型按路线顺序用 search_learning/read_method 读回真实产物、create_markdown_material 存库（references 指真实材料）即可；自产教材可再走骨架→卡，重进沿书管线。

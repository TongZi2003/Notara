# 从一道题开始

先完成[安装和模型配置](install.md)。在首页选好学习目录，输入：

> 我想学会解方程 x²−3x+2=0。我知道怎样展开乘法，但不理解乘积为零为什么用“或”。请一次问一个问题，先让我试一试。

跟着老师的问题写出自己的想法。不必等到完全正确才回答；如果老师讲得太快，可以说“先停在这一步，让我解释”。如果它误解了你的回答，直接指出原话和分歧。

## 看板书和资料

课堂上方可以切换对话、白板和教室。白板是否有内容取决于老师是否实际写入；没有写入时保持空白。

讨论收束时可以说：

> 请把原题、参考理解和我刚才实际的理解变化整理成题卡，再总结本课。

写入需要批准时，核对当前操作后正常批准。保存成功后，从对话里的文件链接或左侧 Vault 找到题卡。“参考理解”默认折叠，自己的尝试和变化在“学生理解”里。如果老师说已保存但没有文件，让它核对写入回执。

## 下次接着学

保存小结后，原课堂仍可继续交流。停止服务再重新启动，可以从首页面板的课堂列表打开它。

想把课堂从列表收起，点“课堂”标题旁的“管理课堂”，再点该课堂旁的归档按钮。正在运行时会先确认是否停止；归档不调用模型。要恢复，在管理列表的选项中选择“全部对话（显示已归档）”，再取消归档。需要保存小结时，先点课堂上方的“总结本课”或向老师提出要求。

要查看用量，在“设置 → 通用设置 → 性能与用量”选择“详细”；输入框旁可打开 Token 用量明细。这个设置不需要开启调试记录。

复习记录围绕本次实际检验的关键一步，区分“做出来 / 没做出来 / 这次没考”。老师讲过不等于你已经做出来，复习档位也不等于对整个知识点的掌握。计划页可以查看已安排课程和到期复习。

需要处理讲义、备课或规划课程时，打开输入框的“添加文件或调用指令”菜单，再选择对应技能。先完成一道题的讨论和保存，就已经走通了第一条学习路径。

## 4. Codex review 必查

- **来源正确：** 用B固定代码和新用户裁决，而非旧main或过时CLAUDE段落；新基线若前进说明差异。
- **当前产品完整：** knowledge同身份、可修订学情及默认分类、共同编辑、全局读/归属分离、原生用途、确认收课、课后讨论、Creator和图示未被漏掉。
- **本次设计正确：** 混合/零材料、DSH原生Session资源标签/分栏、四类定位、原件版本、选区发送、未学首页、显式提示变化；不复活强制拆课或另建预览active/openTabs。
- **首版精简与新设计：** 五主预设数量/名称一致，搜索主/子共用能力且真子会话隔离；原卡片顺序/按书/标签/放射保持。书籍左原文右根起脑图/列表、明确生成与只读展开分开、卡原身份/原件定位；不把旧全菜单/繁复布局当必迁。
- **日历与时间：** 原roadmap筛选不改变接续/布局，过去/今天/未来内容正确；Host定时日报同日幂等、休眠恢复补算、晚确认按发生日、未来不编活动、未学不计到期。日报不发课堂消息/自动收课/写学情；源坏不能报零。
- **写者与证据：** native身份、operation、target/version、发生时刻、当前/历史依据、close cutoff、晚确认、回执轮权限。
- **交互是真实的：** 浏览器检查原生流式/滚动/Queue-Steer、模型/强度下一请求、token真实与估算口径、Raw JSON只读/来源、红笔前后版本与归属；公式/刷新/冲突保留不能仅看build，Creator须真实预览/安装。
- **自然课堂可用：** 不点工具名的正常请求，看首次调用、修复次数、耗时和结果对象，不把最终保存掩盖反复猜字段。
- **已接受精简：** 原生web/subagents/skills/systemPrompt/storage优先；无两对象认证、minor门槛、global审批、固定重试次数；Creator按文件编辑/整作品验收；无重复证据表/日期服务/无逻辑包装。截图检查能力可达，不按组件文件数判完成。
- **工程边界：** domain与DSH适配分开，同源schema、清理正确、包闭包、无新增旧兼容路径。

Codex亲自看diff并跑相称检查，写接受commit、PASS或CHANGES_REQUIRED、严重度/代码锚点和精确补改范围。执行者不能自行给阶段PASS。review不需要再次发起产品问卷。

# 首版界面与主 Agent 预设设计

日期：2026-09-11；对应迁移计划 v2.3。本文融合本轮用户逐项提出并要求纳入计划的设计，优先于 B 的旧布局与完整模式菜单。产品事实仍参考 B@3831987；DSH 原生能力见 [DSH-PREVIEW.md](DSH-PREVIEW.md) 和 [DSH-NATIVE-EXPERIENCE.md](DSH-NATIVE-EXPERIENCE.md)。

## 1. 已确定范围与执行取舍

已确定：保留当前主题、精简界面；书籍采用左原文右脑图/列表；脑图从书根开始按节点逐步拆解到卡；卡片视图保留当前能力；首版仅五种内置主 Agent 预设；对话树沿用 roadmap 并支持时间筛选；日历加入定时日报与未来安排。

本版接受SIMPLIFICATION中的精简裁决。展开/生成分离、真实日期与来源是产品行为要求；缓存结构、服务类名和固定次数不是产品要求。它们不增加新的主要 Agent 或学习事实种类。具体视觉构图、roadmap 新增视图种类、日报排版和默认生成时刻仍可讨论；本计划不预先锁定日/周/时间轴等新视图，不硬编码某个日报时刻。P1–P5 可先按既定合同推进；相关 UI 任务按本文的最小交付执行，后续新裁决先同步任务和验收。

## 2. 资料页：书籍与卡片

### 2.1 书籍阅读与逐层拆解

- 从知识库/资料页或学习集书架打开一本书，宽屏左侧直接显示原文，右侧显示该书的骨架与卡片脑图。沿用纸面、字迹、三色笔主题，设置按需出现。
- 初次进入只显示书本身一个根节点。已有骨架和卡片仍保留，只是尚未展开；不能为符合初始画面而删掉已生成内容。
- 点击节点显示适用动作：展开/收起已有子层；选择“继续拆解”则请求围绕该节点生成下一层。节点深度不固定为章/节两层，可逐层到达知识卡片；不要一次自动生成全书全部层级。
- 展开、切换脑图/列表、打开详情和原文定位都是阅读动作。明确请求拆解才调用资料整理教学能力，沿已有原生课堂入口发送意图；没有课堂时，经明确整理动作创建真实资料整理课，不能为单纯阅读造占位课。
- 本轮拆解绑定书、原件版本、已读节点范围、已有骨架版本和目标父节点；读原文后提出骨架/卡片，保存沿 P5/P6 既有确认与写者。浏览脑图不等于确认生成。
- 每次只追加/修改选定范围；保留其他章、其他层和已有卡。重复提交、刷新或取消后的重试沿原操作处理，不能复制卡；陈旧骨架版本先重读合并。
- 叶节点引用已有普通卡（包括普通知识卡）的真实身份，点击打开对应详情预览；已有收录知识只有存在真实该书关系时才展示。这里的“知识卡片层”是用户界面称呼，不新建第三种卡模型，不自动收录私人知识或复制成有独立复习梯子的普通卡。
- 卡片通过固定原件版本的 SourceAnchor 定位到左侧原文对应图层/区域。多来源保留列表；点哪个来源就跳哪个。无来源卡或尚无精确定位时显示实际情况，不能用章节标题猜坐标。
- 切换到列表后仍是同一本书、同一层级与同一组对象，保留当前选中节点及展开范围。该书的层级脑图与全库卡片放射图各自表达现有关系，不互相覆盖。
- 窄屏允许在原文/结构之间切换，保留选择与阅读位置，卡详情按需打开；不得把两列压成不可阅读的小栏。具体比例和动效由 P6.6 视觉验收确定。

### 2.2 卡片视图保留

沿用 B/app/js/screens/assets.js、screens/card.js 的当前体验与行为：顺序排列、按书组织、标签筛选、放射图、详情和学习入口。保留现有排序规则，不为新书脑图重做卡片模型或替换卡片视图。全库标签筛选/跨书关系仍可使用，无来源卡和未学卡仍可找到。

P5.7 的红笔修订仍在卡详情/本课修改入口按需展示，普通卡保持当前正文。卡片浏览/展开和生成都不自动成为学习记录；未学卡不进首页到期提醒。

### 2.3 阅读与 DSH 课堂预览

资料页的左侧阅读器使用 P3/P4 同一格式 renderer、定位器和授权资料服务，但它是资料页自己的阅读区；真实课堂中仍使用 DSH 原生右侧标签/分栏。只共享原件和来源引用，不双向同步两套打开标签列表。没有 Session 的资料页阅读用 workspace 授权入口，不借其他课的地址或额外创建课。

## 3. 首版五种内置主 Agent 预设

| 默认配置键（不作封闭领域枚举） | 显示名称 | 默认任务与迁入能力 |
|---|---|---|
| material-organization | 资料整理 | 阅读原件、按节点/章节拆骨架、整理知识与卡；吸收 book-prep 和相关备课/规划 Skill |
| diagnostic-analysis | 诊断分析 | 从实际作答与解释找问题，保留候选原因、等待证据和反证修订 |
| socratic-teaching | 苏格拉底授课 | 用提问、提示、练习逐步学习；承接导学/讲题能力；明确要完整讲解时讲清，再另看独立表现 |
| brainstorming-extension | 头脑风暴拓展 | 发现知识关联、比较思路、提出假设与延伸任务，避免变成开发需求问卷 |
| search | 搜索 | 搜索本人资料/卡片/知识及可用外部来源，核对原文，返回出处、链接和已有材料的定位符；可独立对话，也可接受其他 Agent 委派 |

这是五种可选择的主 Agent 预设，不是五个独立 runtime、workspace 或聊天状态机。它们共用原生课堂、材料、卡/知识/复习/学情/计划工具与权限。规划、复习、导学等仍可作为按需读取的 Skill/工具能力，不再全部平铺成首版主 Agent 选项；不自动按固定顺序串成五段流程。

开课与“本课”共用五条教学配置目录和一个学习composition；原生agent-presets不能在已有消息后换composition，同课切教法由动态systemPrompt.section读取当前选择，在下一请求生效。保留session/材料/草稿/model/effort。临时改语气或补一句要求直接保存本课覆盖文本，不要求Creator制包；发布复用配置才走包管理。Skill按需读取沿原生provider。

搜索主Agent与搜索subagent共用原生web_search/web_fetch及本人资料查询工具。外网结果保留原生URL/读取范围；本地结果保留对象ref、资料version/locator。界面可临时合并结果，不把所有来源强制纳入SearchService/外网实体或readState状态。是否相关、是否继续阅读由Skill判断，实际未读取不能假称读过。

子任务生命周期、父子目录、取消、结果和用量交ctx.subagents/ui-subagent；搜索/命题/制作只是任务配置。独立spawn仍可能继承父prompt/tools/resources，实际出站内容要满足角色所需，不能以空历史代替隔离证据；授权范围沿真实工具backend。点名帮手原文展示保留，查找/阅读不自动制卡或写复习。

独立命题、助教/同伴/点名帮手仍按 P7.4 的隔离合同工作，它们不是主预设菜单扩容。Creator 保留独立制作入口与 creation 用途，不列为第六种学习预设。用户自制版本仍走 P8 工作台/安装绑定；首版不增加内置主预设或恢复旧角色×模式×人格的常驻组合表单。

## 4. 对话树与时间筛选

沿用 B/app/js/screens/map.js 的 roadmap 布局、接续、分叉、定位与学生布局操作。源码已有日期快捷筛选（mapMatch/mapRenderFbar），本次承接并在原生会话身份下接好日期信息；不要把这部分说成从零新增。

最小交付是在现有 roadmap 上按日期/范围筛选。未开课程用安排日期，已开课可按真实课堂活动日期命中；无日期的未开课在“全部”中保留。DSH 身份是不透明 ID，日期必须读结构化时间，不能继续从 Pi 会话文件名截取。日期范围在 workspace 时区按本地自然日处理。

筛选只改变可见结果，不改挂载、预设继承或学生手动坐标。需要保留祖先帮助理解时，将其作为上下文显示，不算入筛选命中数；隐藏父节点不能把子课持久化为新根。清除筛选恢复原图，选择节点始终定位到真实课。额外的日/周/时间轴等视图种类另议，本阶段不擅自扩成多个新页面。

## 5. 日历与定时日报

### 5.1 日期内容

- 过去：展示当天真实活动的日报，包括参与的课堂、整理资料、创建/修改卡片与知识、实际学习和复习。每项能回到现存课或对象；参与课堂与确认结束分开。
- 今天：展示截至当前已完成的活动与剩余安排，到了设置时刻生成日报；已生成后发生新活动时更新同一天的摘要，不追加第二份日报。
- 未来：展示按当前 schedule 预计当日到期的复习卡片数量，以及已安排的课程。到期数量随实际复习/改期重新计算，不预设学生未来完成了哪些复习。
- 没有活动的过去日期如实显示无活动；有计划却未执行的课程显示未完成/原安排，不把它写进完成摘要。缺源数据时标暂不可用，不能当作零活动。
- 未学库存不计入复习到期数；显式安排学习未学卡的课程仍显示。今天的逾期待复习可单列，不把全部逾期每天重复叫“当天到期”。

### 5.2 生成与恢复

首版从真实活动生成可读摘要，日历与日报使用同一日期查询。无需独立日报实体、sourceDigest/revision或全历史补算队列；旧日期按需计算，晚到复习按发生日归属。确有性能测量需要才加可删除重建的缓存。

设置保存启用、时区、本地生成时刻及最近成功生成时间；尚未选定默认几点，允许配置。活跃Host通过Cordis生命周期timer到点刷新摘要并通知日历；插件卸载自动撤销timer。关闭/休眠期间不承诺准点，恢复时刷新最近到期/当前日期，其余旧日打开即计算。

到点生成是实际日期聚合成功；源读取失败不标成功、不显示零活动。当天继续学习后，日报与日历都从同一查询反映变化。生成时间与活动发生时间分开，时区按本地自然日；今天逾期与预计当天到期分开计数，未学卡不进到期提醒。

日报不发课堂消息、不自动收课、不给卡/学情写新事实，也不新增日报Agent或系统推送。DSH schedule是给原会话发follow-up的机制，与这里的日历定时刷新用途不同。

状态：A+B+C 已接入独立 Vault 教学组合。确定性、浏览器和外部模型的证据分别记录在 [实现与验收](../evidence/vault-teaching/verification.md)，不以实现完成代替教学效果验收。

目标：从主分支抽出最小且完整的教学入口，围绕 Vault 资料开始教学，在同一原生会话中讲练，把产物可靠保存回 Vault；再按已确定的设计接入长期记忆、路线和课堂日志。

目标工作树为 `codex/notara-vault-clean`；核对时 HEAD 为 `6592886`，有本线程既有未提交 Vault 改动。主分支 `main` 的 `f84a29b` 作为行为和代码来源，不能直接启用整套旧 Host 来代替迁移。

## 1. 文档关系与已确定选择

本文件负责总范围、批次和验收；专题合同负责机制细节：

- [Vault 视图](../evidence/vault-views/design.md)：资产页阅读编辑、图谱、卡片、分屏、标签聚合与邻接图。

这些是同一目标的组成部分；历史分册和 HTML demo 只作来源，冲突时以本轮已确认选择及上述当前合同为准。下列选择已经确定，不再列为待决：

1. 教学者作为 DSH 原生 Agent 预设管理，新会话默认教学，并保留普通助手的原生预设选择。预设组合遵守原生会话锁定规则；同课换教法不靠切换原生 Agent 身份。
2. 用户明确要求保存/修改时进入执行，实际工作区写入由原生权限批准。教师主动建议写入时给出具体内容/修改，用户同意仍沿同一批准通路；不重建旧 Proposal/收录/收课的第二套审批。
3. 首批文本与 PDF 教学闭环，不包含可执行 HTML 互动演示。现有受限 HTML 预览不是互动执行能力。
4. 原生 session 是课堂；主 Agent 保持同一教师身份完成解释、练习、诊断、搜索与拓展。
5. Vault Markdown/媒体是内容事实源；Host 负责权限、原生 session、来源定位、版本校验与工具接线。不把同一内容双写进旧 `.studyforge` 域库。
6. 资产页统一阅读和编辑；阅读相关特殊视图收进小图标/菜单。对话输入属于原生对话 pane，不在其他 bench 底部复制一份。
7. 长期教学记忆只有画像与锦囊；锦囊合并触发条件、方法、教法、个人经历与适用边界。原则性教法 Skill 是能力资源，不是第三类记忆。
8. 路线独立 bench 保留；通常无剧本，要求备课时才生成。归档时有剧本就追加本次小结，无剧本才创建独立小结；lesson_log 统一索引。

## 3. 原生会话与本课设置

复用既有 `teachingRef`、`learningGoal`、`temporaryInstructions` 的语义和可用 schema；来源为 `packages/contracts/src/courses.ts`。不得再造一份自由文本目标字段与 learningGoal 并存，也不直接迁回旧 course closure 对目标修改的限制。

- 教法：默认三项为苏格拉底、费曼、讲解式，来自同一资源目录；当前所选正文在下一次模型请求中生效。切换不换 session，不清空资料、对话或草稿。
- 学习目标：沿 `learningGoal` 保存真实标题与用户提供的时间条件；未提供的期限/时长不编造。设目标不自动排路线或复习计划。
- 临时要求：属于当前会话，后续请求和重开仍使用，直到修改/清除；不自动写成全局偏好，不自动继承到另一课。
- 首次发送前：设置与附件放在原生新会话/草稿上下文中；原生 session 创建时由 Host 绑定到实际会话。不能等模型第一次回复后才补上，也不能由模型猜草稿 ID。
- 已有会话：设置沿可恢复的原生 session 配置/投影持久化；旧域字段只是语义来源，具体迁入的存储接缝必须通过恢复测试。切页不丢草稿，重开保留已持久化设置；草稿也需检查原生恢复能力并补齐缺口。

旧 `CourseMetadata` 已有按 session 的默认读取、version 0 首次写入和版本化修改，可作为恢复语义参考；它不等于新 Vault 组合已经接通。字段省略表示不修改，临时要求清空、学习目标删除和教法恢复默认要在唯一配置 schema 中明确表达；当前旧 CoursePatch 对学习目标的清除并不完整，不能用省略字段冒充删除。

顶栏只增加一个简短教学设置入口，不铺开多种教师身份按钮。结构分析等扩展 Skill 可从原生技能入口调用；把它们纳入目录不表示必须展开全部正文。

## 4. 资料带入与模型端读取

用户在资产页或图谱中选择“带入对话”，使用现有原生引用 codec，把真实文件与定位带入 composer 并打开/聚焦对话 pane；不直接复制原生 composer，也不把被动浏览当成已选择的教学材料。

引用覆盖文件、Markdown 段落、PDF 整页和框选区域。发送前重新读取/核对文件 revision；变更则提示重选或重读，不静默沿用旧 quote、页码或坐标。原生引用的定位与模型端返回的来源必须指向同一内容。

模型端需要的通用 Vault 能力如下；这是能力合同，不在总文档另立一套重复工具名：

2026-09-22 用户确认缩减工具面后，普通资料与画像/锦囊使用原生文件读取、搜索与编辑，PDF 按页读取和复习计算通过 Bash 调用本地辅助脚本。`examples/native-vault/agent-tools.js` 只保留课堂生命周期接口，文件格式与读取策略渐进加载 `notara-vault-workflow` Skill。当前入口以 [原生工具与教学 Skills](2026-09-22-native-tools-and-skills.md) 为准；以下能力要求继续有效，native 文件版本与 Vault 内容 revision 各自在对应调用链使用，不混填。

| 能力 | 必要返回与边界 |
| --- | --- |
| 列目录/搜索 | 有界候选、真实可读定位、分页/截断与已查范围；字面命中不是教学相关性的结论 |
| 读 Markdown/文本 | 正文或有界片段、文件来源、revision、实际段落范围与继续读取入口 |
| 按页读 PDF | 真实页数、请求的页、该页文本可用性、对应渲染图/可用预览、同一原文件 revision |
| 读 PDF 选区 | 原文件、实际页与区域、对应图像及真实可提取文本；不把整页当选区、不猜 OCR |
| 查看图片 | 实际图像、来源和 revision；可预览不等于模型已读懂 |
| 新建/修改 | 真实写入目标、expectedRevision、批准后的原子保存结果与新 revision；新建和修改的冲突语义明确 |

浏览器已经显示 PDF，不证明模型拿到了题面；扫描件无文字层时必须沿真实图像读取能力处理。当前模型/工具链不能处理时如实返回缺口，不能用文件名或空文本代替原题。复用现有媒体转换与渲染能力，避免浏览器一套定位、模型另一套页码。

当前 `client-source.ts` 的 `registerVaultReference` / `pdfReferenceText` 已能在用户显式带入时序列化选中文本或 PDF 页文本，并在发送前核对 revision；这条已有能力保留，不能误报为所有 PDF 文本都对模型不可达。缺口是教师自主、可分页且有来源/版本返回的 PDF/图像工具，尤其无文字层页面。现有 fullDocument 路径会拼接整份 PDF 文本，迁移时改为有界引用与按需读取，不能默认把整本资料注入。

界面与模型共用同一文件解析、版本规则和写者，调用模型的读写适配同时经过原生权限。当前客户端 Remote 使用 Node 文件 IO 的事实不构成模型侧绕开权限的理由。

## 5. 教学行为、Skill 与写回

原则性教法：苏格拉底重视学生下一步动作，费曼法重视学生自己的解释，讲解式先给清楚结构与依据；学生明确要完整解释时尊重当前要求。结构分析等教法按相同 Skill 机制提供，不新建独立教师生命周期。

结构分析正文已整理在 `resources/vault-teaching/presets/structural.md`，与三个默认教法共用目录和加载接缝；具体教学效果仍需真实模型与学生验证。

资料整理、诊断、搜索、拓展是教师可采用的任务策略。练习与诊断根据真实题目和作答进行，区分独立完成、提示后完成与尚未检验；不把看过、听过或保存过当成掌握。

首批任务 Skill 的来源与迁移要求：

| Skill 来源 | 迁移要求 |
| --- | --- |
| `resources/teaching/skills/studyforge-semantic-search.md` | 改为真实接通的 Vault 查找/读取；保留按需精读、范围与来源，不把字面搜索包装成语义引擎 |
| `resources/teaching/skills/studyforge-essay-review.md` | 保留读实际作文、定位问题、反馈和修订的教学行为；旧卡/资料工具名需替换 |
| `resources/teaching/skills/studyforge-markdown-handout.md` | 输出可编辑 Markdown 讲义，保留数学排版、真实资料来源与写回结果 |
| `resources/teaching/skills/studyforge-method-distillation.md` | 在 B 按锦囊新定义修订：方法/教法/经历/触发条件一体；不再排除情境教法、不设第二次收录审批，也不因案例未成功就丢弃它 |

Skill 目录与正文沿原生 provider/输入框入口，未迁移能力不进入当前生效提示词和工具示例。正文、参数 schema、Host 执行和 UI 结果必须一致；不能留下退役模型工具和强制收课的可调用指引。当前复习使用辅助脚本 `review-queue` / `record-review`，由原生 Bash 执行与批准。

普通卡片、讲义、笔记、小结保存后，资产页能打开同一文件，图谱/列表/搜索投影反映新内容；修改保持原对象，不因为标题变化创建副本。保存失败或拒绝批准不声称已保存，外部修改发生冲突时保留用户草稿并重读。

普通学习小结的保存不自动结束/归档会话。用户选择“归档并总结”时才走路线专题中的组合操作：有剧本 append、无剧本独立，索引可读后再原生归档。两者的触发意图不能混淆。

## 6. 记忆、路线与视图的统一

- 画像/锦囊读侧先给范围和入口，再给候选，最后按需读正文/证据；当前学习集优先，跨集由原生权限决定。主 Agent 可直接完成，子 Agent 可选。
- 锦囊的经历、方法和情境教法保存在同一卡片，图谱可以把它作为特殊节点连接题目与知识资产。
- 原则性 Skill 持续规定教学方式；检索命中锦囊不自动切换本课教法，也不自动修改画像。
- 独立路线 bench 与对话/图谱/资产并列，复用画布交互但保持课序语义；默认无剧本，需要备课才生成。
- 有剧本的小结追加到原剧本，无剧本才生成独立资料；lesson_log 索引每次实际课堂的小结块，不按文件数量统计课堂。
- 图谱按 tags 聚合并查看一阶/两阶邻接，可组合筛选；多标签不复制资产，不从同标签生成虚假引用关系。

## 7. 迁移接线顺序

1. 形成独立原生教学预设接线与新资源目录，挂载会话设置、当前教法和原生工具/技能，不启用整个旧 Host。
2. 接通通用 Vault 模型读写与 PDF/图片来源，复用原生 composer 引用；界面与模型使用同一版本与权限边界。
3. 跑 A 的同会话讲练、设置恢复和真实产物写回，确认基础闭环。
4. 按记忆专题接 B：两类记忆、渐进读取、锦囊资产、标签聚合与邻接图。
5. 按路线专题接 C：路线 bench、可选剧本、前课进度、小结块、lesson_log、保存后归档。

保持 A/B/C 的实施与验收可分段，不把某层完成宣称为整个目标完成。本轮必须完成三层，未完成项明确保留。

# Vault 日历与间隔复习

2026-09-22 用户追加迁移授权，替代旧迁移范围表的“复习调度不启用”。参考 Documents/测试 的 `工作流规范.md`（卡片、评估与复习）及 `复习队列.base`；未修改或导入该库的真实资料。该库实际只有核心 Bases 过滤和默认 daily-notes，没有 Calendar 或 Spaced Repetition 插件。日历复用原 DSH 的文件/记录投影思想，不把旧数据库 Host 搬回 Native Vault。

## 文件合同

- 仅 `type: card` 参与复习；锦囊和画像没有额外评估生命周期。
- 未评估卡片：`learned: false`，`mastery: 0`，`interval / last_review / next_review` 为空。旧 Vault 卡片缺省这些字段也视为待评估。
- 0.14.3 起每次评估使用 `assessments`（1–8项不重复的具体 `ability` 与 `outcome`）及必需 `note`。`outcome` 为 `demonstrated`（学生完成了该项关键认知工作）、`needs_practice`（实际暴露困难）、`not_observed`（证据尚不足）。不能仅按是否受过提示分类；组织性追问、唤起一个候选方法不天然减分。老师完成的步骤也不能归给学生。
- 每次只评估原定检验的能力：可同时记录“判断方法适用范围已表现”“未经提醒主动唤起方法尚未观察”，不能为取得全通过删掉后者，也不把不相关的所有能力都列成未知。具体引导、学生贡献、判断依据合写在 `note`，详细认知演变仍留在正文的学生理解。
- 只要有实际 `needs_practice`，降一档并从本日重新安排；未开始复习则从第1档开始。没有实际困难但含 `not_observed` 时只留历史，档位、上次有效复习和到期日保持原值，未开始复习的卡仍无排期。全部 `demonstrated` 时，首次从第1档开始；已有排期且当天不早于 `next_review` 才升一档，否则保留原排期。上下界仍为1–5，间隔仍为1、3、7、16、35天。提前或同日反复成功不升档、不推迟到期。
- `learned` 仅表示已开始间隔复习，界面同名属性展示为“已开始复习”；它不表示学会，也不等于已有多少评估历史。`mastery` 仍是复习档位，不新增第二份可写掌握度分数。档位不宣称跨题型、无提示或长期掌握。
- 同一张卡片的 `review_history` 保存评估身份、时间、逐项观察、说明、来源、前后状态，和当前属性一次 CAS 落盘。身份、时间及真实课堂归属由 Host 绑定，模型只提供已读卡片引用、能力观察和说明。自评与课堂评估明确区分。
- 旧历史的 `passed` 按原值只读保留，标为“旧评估”，不倒填能力、提示或认知判断；新调用拒绝 `passed` 及混合格式。仅有旧复习字段、没有历史的卡仍可读，不批量重写既有资料。
- 撤销恢复最近未撤销记录的 `before`，但要求当前属性仍与其 `after` 一致；原记录保留撤销时间。外部更正或过期 revision 不覆盖。
- 允许在资产页手工修订 Markdown；自相矛盾的复习属性在队列/日历提示，不悄悄当作未学。教师通过原生工具改正文时按 Skill 保留复习字段，评估通过受批准的 Bash `record-review` 命令计算并写回。

## 视图与写入

- 0.14.4 起主教师在一道题讨论收束、切换下一题前主动记录，不等待学生再要求保存；同段讨论只记一次，下一次实际尝试或复习可追加。教师按语义判断收束，没有新增逐消息监听或自动评估后台。纯讲解也可留下本题检验点“尚未观察”的记录，不编造学生观点、不启动复习。
- 保存位置是该题的Markdown题卡：页头review_history为逐次评估与证据摘要，正文学生理解为详细认知演变。先复用已有题卡；确无题卡时按模板与完整题面建卡，不改写原书或专题的type。先补有证据的正文变化，再取得最新revision写评估，两次操作各自核对回执。无法可靠建卡或写入失败时如实说明未落盘部分。
- 新增并列“日历”bench，与现有对话/资产/图谱/路线一样支持分屏。
- 月历读取路线节点 `scheduledOn`、课堂小结真实学习时间、卡片到期日和未撤销评估、日记日期。只读投影不生成每日流水或第二套学习事实。
- “打开或新建当日日记”优先复用现有 `type: daily` + `date` 或 `YYYY-MM-DD.md`，否则创建 `日记/YYYY-MM-DD.md`；存在多份时要求从列表选择，扫描不完整时拒绝盲建。
- 课程日期写回路线现有节点；安排、修改和清除日期不自动开课、不标记完成、不归档课堂。点击课程调用原生路线开课/回课入口。
- 复习队列：今日到期（含逾期）、待评估、复习中（1–3 档）、熟悉（4–5 档）、全部；支持搜索、标签过滤和分页。
- 从资产或卡片库可进入复习安排；从队列带入原生对话、打开原文、自评、查看经历及撤销。带入对话只填入资料引用和意图，发送由学生操作。
- 自评先填写具体能力及其观察结果，再共用一份证据说明；支持添加能力。保存回执区分“更新复习安排”与“仅保存观察”。日历、评估经历、卡片属性逐项显示三态，不把尚未观察渲染为失败。下次复习先读完整认知演变和最近观察，据此决定检验什么，不强制每次引导后补测。

## 工具与权限

日历与复习查询通过 CLI 的 `calendar`、`review-queue` 按需读取，不每轮塞入系统上下文。`record-review`、`schedule-lesson` 沿用原生 Bash 权限，工作员不写入评估。用户 UI 操作使用同一工作区写入器和文件版本校验。`record-review --help` 是参数合同，`notara-method-distillation` 是能力判断口径，`notara-vault-workflow` 是调用入口。当前工具面以 `2026-09-22-native-tools-and-skills.md` 为准，没有增加定时通知或自动触发模型。

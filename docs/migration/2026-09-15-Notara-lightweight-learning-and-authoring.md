# Notara · 轻量教学与共建资料

日期：2026-09-15。状态：规格已实现；确定性、集成和代表性浏览器场景已验收，真实模型教学质量尚未验收。源码基线：`codex/dsh-native-migration@499f8f6`。

## 1. 问题与用户裁决

用户已明确：“无资料入口其实不需要进行刻意设计，因为本来就支持空资料 bench”，需要的是“把生成的东西及时写回去”，产物可以是卡片、Markdown 讲义乃至自己的教材。

因此本规格处理两件事：老师在普通对话里如何先学起来，以及课堂内容如何成为可继续共编的学习资料。面向从主题、问题或目标开始自学，并希望长期积累笔记的使用者；不要求先上传文件、建立学习集或配置教室插件。

以下误判撤回：`materials` 数组非空不等于必须上传书籍；带标题的教师交付文本也可以是子任务上下文。“无资料不可教学”不是已证实的缺陷，正常空资料课堂是现有基础。

## 2. 范围与完成目标

P0 为本轮不可缺少的行为，P1 为同周期优先完善项；测试数字是验收标准，不是已观测的教学效果。

| 优先级 | 要求 | 可观察的结果 |
|---|---|---|
| P0 | 同一原生对话接受从资料、问题、目标开始的请求，由教学 Skill 与工具编排选择适当动作。 | 必需上传次数、额外入口选择次数均为 0。 |
| P0 | 普通主题学习先完成必要的起点判断并开始教学，正式路线独立按需提出。 | 本节教学不等待全面诊断、收课或路线确认。 |
| P0 | 保留卡片/笔记通路，新增当前课堂直接创建及持续编辑 Markdown 资料的接缝，个人教材复用同一资料的章节结构。 | 同一产物保持 1 个身份，至少 2 次编辑与刷新后能读回。 |
| P0 | 写回保留真实课堂及引用来源，已保存产物可在对话、工作台和相关课堂间跳转。 | 伪造本地资料、虚构网页出处、无写入成功却显示“已保存”的次数均为 0。 |
| P1 | 生成长文时可恢复最近已保存的完整草稿，支持未发布草稿继续编辑。 | 中断后不要求重做整份讲义，不重复创建资料。 |

反向约束：增加保存次数、卡片数量、教材页数均不算成功指标；不通过强制提问、无用保存或降低出处要求完成上述目标。

## 3. 统一入口与教学行为

“从资料开始 / 从问题开始 / 从目标开始”是意图分类，不是三个页面、三个 Agent 或三个必须手选的模式；普通对话与“＋”/“/”加载的技能执行同一套行为。

| 用户输入 | 老师的第一步 |
|---|---|
| 给定书页或讲义 | 读取指定位置，围绕用户要研究的内容教学。 |
| 明确题目或具体疑问 | 直接处理当前问题，不先要求制定学习计划。 |
| “我想学导数” | 若基础或目的会改变切入点，提出一个有助于选择起点的问题，再用简短目标开始首个教学动作。 |
| “第一次接触导数，先讲变化率，今天只学一点” | 复用已给的信息，直接开始；不重复询问基础、目标、时长。 |
| 有长期目标或期限 | 区分用户想立即学习还是明确要求系统规划，不因出现“目标”二字自动转为完整诊断。 |

轻量流程为：主题 → 按需判断目标与起点 → 本节重点 → 首个讲解/尝试 → 根据实际表现调整；它是教师的编排指引，不是 Host 强制的状态机。边教边判断合法；本节目标可以是一句话，不要求填表或提交成功后才能上课。

## 4. 本节重点与正式路线

短期教学焦点先存在于真实对话；需要持久化本课重点时复用既有 `stance`，不并列新增 `lessonFocus`、`currentObjective` 等重复字段。已有字段的读写、确认与版本边界保持一致，保存重点不构成教学前置门。

普通主题输入不得仅为记录一个目标而开启完整诊断。`note_learning_goal` 所属的目标—诊断绑定用于明确选择的完整诊断学习流程；普通课不自动设置 `guided`。

第一节课中或结束后，老师可根据已观察到的需要，用普通路线提案安排后续课程；无需为了提交路线制造诊断课、小结或假来源。近期节点给出具体任务，未判断的基础如实保留，日期只来自用户的实际约束。只有学生接受提案后才形成正式路线，已有课程与事实不被重排覆盖。

学生明确要求“先完整诊断再规划”时，继续遵守[完整诊断学习主线](2026-09-13-DSH-diagnosis-learning-route-design.md)；允许试学不等于允许把局部观察宣称为全面诊断。未收课时，学生明确取消系统诊断，可经既有 `propose_lesson_settings` 确认修改 `guided`，保留已有观察；已确认收课的诊断目标/小结绑定保持固定，新目标另开课。老师不能为让提案通过而自行退出诊断约定。

## 5. 课堂生成与内容写回

### 5.1 何时写

普通回答保留在原生会话，不将每次回复自动复制成资料。用户明确要求写讲义/教材，或接受本课整理任务后，老师在一个内容单元完成时保存草稿，并返回可打开的产物；后续修改同一个对象。无需切换创作者身份、创建发布项目或安装一个包才能获得本课讲义。

“草稿”表示正在共编的资料内容，不表示独立数据库、第二份正文或必须经过发布才能阅读的状态。Markdown 第一次成功写回就成为可预览、编辑、刷新恢复的资料，此后保留同一 `materialId` 并追加版本；未完成/需核对的章节在内容中如实说明，不新增通用发布审批。普通新卡保留原确认通路；学生已明确发出的创建/修改资料指令是相应写入授权，不再机械要求每段正文点一次确认。

课堂写回通过限定学习资料对象的工具调用既有资料写者；不能为此把老师会话切成创作者，或扩大为任意文件写权限。模型给出标题、正文、要修改的实际对象和已读引用；Host 绑定当前课堂、身份、事务和读取基线。保存回执返回实际资料及版本，并在现有工作台定位；“本节课用到的”只加入本次真实写回的对象，重试不重复建书。没有选学习集时正常保存到当前学习空间，不要求补选。

自动草稿保存不记掌握、不启动复习、不关闭课堂，也不触发“阶段已经结束”。沿用现有学习笔记保存与阶段摘要通路，摘要可以关联原卡或本次 Markdown 资料版本；Markdown 每次保存不新增阶段，不为触发阶段把整份讲义复制成卡片。草稿修订与阶段收束分别验收。

### 5.2 存成什么

| 产物 | 适用内容 | 持久化约束 |
|---|---|---|
| 卡片 | 可独立学习/复习的题目、概念、结论 | 复用普通卡，无书源也合法；建卡不自动记复习。 |
| 笔记 | 当堂推理、方法、错误与反思 | 复用既有笔记对象及课堂关联；不再造第二套学习记录。 |
| Markdown 讲义 | 连贯的讲解、例题、练习和总结 | 正文只存一份；AI 与学生共用读写、冲突处理及预览。 |
| 个人教材 | 跨课逐章长成的讲义 | 首版用同一 Markdown 资料的标题层级/目录及版本承载，不另建教材实体或先生成全书。 |

“我的教材”可先只有一章，后续向同一资料增补章节；跨课编辑保留每次修订的课堂来源。旧版行号引用继续指向旧版，新版重新绑定实际章节/行段，不将旧定位直接套入重排后的新正文。导出多文件目录和高级出版排版可后续扩展。

## 6. 上下文与出处

教室同学接收的是教师选择的任务上下文：上传原文的摘录、已读卡片正文、师生刚说的一段话、生成例子或已读取网页的摘录均可；不需要先把这些文本保存成书或卡。同学实际读取 `{title,text}`，不能只交一个无法自行解析的卡片 ID 代替正文。`materials.min(1)` 的“至少一段文本”约束可保留，不能继续把它列成“必须上传文件”的阻塞。

不以改名 `materials → context` 或增加四种枚举为功能交付；只有需要真实回跳时才增补可解析的引用，沿已有引用合同扩展。教师负责选取任务依据，同学仍不继承父对话、不自行检索或写事实。助教没有参考标准不能评分、同伴不接收答案等既有职责边界继续有效。

| 出处 | 记录与呈现 |
|---|---|
| 上传资料 | 已读取的资料身份、固定版本和位置；展示书名及实际页段/行段。 |
| 卡片/笔记 | 引用已有对象与版本，不为了供料复制卡片。 |
| 本课生成/整理 | Host 从真实会话和写入动作绑定来源，显示“来源：本课讨论”，仅存在可靠消息位置时精确跳转。 |
| 外部检索 | 保留实际读取的 URL、标题及读取依据；只搜到但未读取的结果仍是候选线索。 |

内容可以有多个来源。“谁整理”与“依据哪里”是不同维度，不能把模型改写归为一个来源类型并丢掉原书/网页引证。无外部来源的生成内容不补造资料 ID、页码或 URL；已记录出处也不代表内容一定正确。

本课出处优先从既有写入记录的 `sessionId/actor/版本` 投影，不新增一套让模型手填的来源账本。无会话编辑保持无会话，不能借最近课堂补齐。网页 URL 不塞进只接受本地版本的 `SourceAnchor`；普通讲解可保留已读网页的外链，需要在资料工作台固定引用时再保存实际网页内容快照及原 URL，并引用生成的真实资料版本。

联网搜索按教学需要调用 DSH 现有搜索/读取能力，可派检索子智能体调查独立缺口，由老师核对采用；无资料不代表每轮必须联网，书架为空也不等于必须创建一份伪教材。检索失败时保留已写内容并说明具体缺口，可继续不依赖该外部事实的讲解。

## 7. 验收合同

下表同时包含保留能力的回归和新增行为的验收；课堂内 Markdown 写回是待实现目标，不是当前代码已经通过的场景。

| 场景 | 必须观测到 | 不能发生 |
|---|---|---|
| 空空间输入“我想学导数” | 正常原生对话开始，按需判断起点并进入第一步。 | 强制上传/选模式/收课；无意开启 `guided`。 |
| 明确信息或具体问题 | 直接使用已给条件教学。 | 重复询问已提供的目标与基础。 |
| 第一课后请求安排后续学习 | 普通路线提案可编辑确认并打开原生下一课。 | 为绕过约束编造全面诊断结果。 |
| 明确完整诊断请求 | 保留目标、实际诊断、小结确认及版本绑定。 | 将试学一题冒充完整诊断。 |
| 无书源的笔记闭环 | 学生实际回答 → 保存一张笔记/卡 → 阶段思维图关联 → 刷新/重启/接续可回看。 | 保存或查看自动成为掌握、原卡被重复创建。 |
| 本课写 Markdown 教材 | 创建一章 → 学生编辑 → AI 加第二章 → 保存 → 重开仍可编辑、预览、回跳来源。 | 强制转创作者/安装包；新旧版本行号串用。 |
| 教室仅接教师交付文本 | 同学能完成任务，工具集合和父会话隔离仍生效。 | 无本地文件就拒绝参与，或自动开放同学读库。 |
| 检索失败、写入失败/冲突 | 诚实报告可恢复状态，旧正文/已存版本保留，同事务重试不复制。 | 虚构引用、覆盖学生并发编辑、未保存却显示成功。 |

验证分开报告：合同/确定性测试证明写者与恢复；真实浏览器证明两主题的入口、编辑和引用；真实模型用不含工具名的自然请求证明轻量教学与写回编排。每个代表场景记录首次结果、工具拒绝/重试次数、耗时及未完成处；目标是 0 次因合同歧义导致的参数猜测，不能把硬编码工具脚本冒充自然教学验收。

本轮实现了课堂 Markdown 窄写者、同一资料版本编辑和对应 ThoughtMap 阶段框；确定性合同、隔离集成和代表性浏览器场景已运行。真实模型自然语言编排、长期学习效果和全量历史回归不从这些结果推断。

## 8. 不在本轮范围

- 新的“无资料学习”页面、Agent 或必须选择的开课向导。
- 自动生成完整课本、强制全库检索、每句对话自动卡片化。
- 重写 DSH 会话/调度、另建复习梯子或教材事实生命周期。
- 新增教室升级路由；同学默认模型与老师单次 `routeOverride` 沿用现状。
- 在线教材市场、多人同步编辑、高级出版系统，以及对教学效果的未经验证承诺。

# 路线 bench、课堂资料与 lesson_log

状态：路线、剧本绑定、小结块与原生归档已接通，见 [实现与分层验收](../evidence/vault-teaching/verification.md)。补充 [教学记忆加载机制](2026-09-21-teaching-memory-loading.md)。

本专题属于 [Vault 教学迁移总合同](2026-09-21-vault-teaching-migration.md) 的 C 层；用户已确认本轮完成 A+B+C，分阶段验收，不导入旧运行环境数据。

## 1. 已确认的产品结构

- “路线”保留为独立 bench，与对话、思维图、资料并列，支持现有分屏使用方式。
- 路线以节点连线呈现，复用思维图的视觉风格和基础交互。节点可进入对应原生课堂，或查看课堂小结；有剧本时可打开剧本资料。
- 一般课程没有预设剧本，可以直接开始。用户提供资料要求 Agent 备课时，才编写并保存本课剧本；路线中的课程也不强制事先备课。
- 剧本和小结都是资料，可在资产页展示和编辑。
- 有剧本的课堂：把本次小结 append 到原剧本，不额外生成小结文件。没有剧本的自由课：生成独立小结资料。
- `lesson_log` 统一索引两种小结位置，支持按实际时间、学习集、科目查找与综合分析。
- 路线保存安排，小结保存实际经历；学生画像与锦囊仍是两类长期教学记忆。

## 3. 独立路线 bench

路线页沿用 `type: route`，表达目标、课序和明确前置关系，节点可以关联实际课堂与可选剧本。路线不要求所有节点都存在剧本，也不因计划节点显示在图上就创建会话。

视图复用思维图的画布、节点连线、平移缩放、选择与详情展示方式；数据语义保持独立：路线边表达课序/前置或接续，不复用知识图的“拆分”“引用”来推断课堂依赖。

路线在 workspace 的 choices/components 与统一视图 ID 中注册，沿现有 openView 处理分屏与资料焦点。可提取共用画布组件，但路线数据由路线投影提供，不直接把整个知识图当路线数据源。小结锚点跳转需要接入资料定位解析与渲染。

数据投影也区分两种关系：路线的课序/前置、课堂绑定、小结挂载仅由路线投影解释，不进入知识图的 split 深度和子卡计数。route/lesson/lesson-summary 文件仍是可读资料，知识图若展示它们应标识其资料类型；指向讲义/题目的普通链接只作为资料 reference。不能用 parent 或嵌入语法偷存课序再让 `buildVaultGraph` 把它计成知识拆分。

节点交互：

- 选中节点查看课程重点、已有关联、当前可读小结与可选剧本。
- 未开课节点可开始原生课堂；已开课节点可回到该课堂，重复点击不创建副本。
- “查看小结”定位到具体资料和本次小结段落。有剧本时打开剧本中的小结，无剧本时打开独立小结。
- “查看剧本”只在有真实资料时出现；无小结时如实呈现缺失，不提供伪造详情。
- 独立路线 bench 与对话/资料分屏后，节点跳转沿原生 session 导航，资料详情沿已有资产阅读编辑器，不开第二套课堂窗口生命周期。

路线上的“再学一次”新增实际课节点，可以引用同一剧本；原节点与原 session 绑定保持不变，新节点各自绑定一个新 session。新节点的前课由其明确前置/接续引用确定，不在一个节点内积累多次绑定再按日期猜选。自由课再次学习不强制建立路线。计划、归档和学习结果分开：排期、打开、归档均不自动表示学完或掌握。

## 4. 按需备课

用户明确要求根据资料备课时，由教学 Agent 阅读材料、相关画像与锦囊，生成普通 `type: lesson` 资料，保存走原生工作区写批准。

输入讲义/题目是备课材料，生成并明确绑定的 lesson 页才是本课剧本；不能因为课堂引用了一份资料，就在归档时向该原始资料追加小结。

剧本包含本课重点、涉及资料、阶段提纲、可选检查点与世界书互动，以及需要引用的原则性教法 Skill 或锦囊。材料使用真实文件/页段引用，不全文复制。阶段是默认教学安排，允许教师根据学生实际表现调整；不做必须逐项执行的状态机。

检查点描述希望观察什么；实际独立作答、提示后完成和未检查状态在课后小结中记录。世界书互动说明时机和教学用途，执行时读取对应可用背景，不把整本世界书注入剧本。未发生的互动不能写成课堂经历。

没有剧本时，课堂根据当前问题和目标直接推进。路线节点可以只带简短重点和材料，无需为了开课自动生成一份占位剧本。

## 5. 开课时的加载

```text
原生课堂确定当前学习集及可选路线节点
  → 装配共同规则、当前原则性教法 Skill、画像/锦囊读取入口
  → 若有剧本，主 Agent 读本课重点、阶段提纲与材料目录
  → 若有明确前课，简读其小结中的“下次从这里继续”
  → 按当前要做的阶段/问题读取资料并召回相关画像、锦囊
  → 教学中按需要展开后续材料、检查点与世界书背景
```

剧本与前课进度是本次任务背景，单独计量；开课不加载完整路线全部课程、所有历史小结或全部资料正文。长剧本先读概览和阶段目录。

前课优先用显式接续引用，其次沿路线中明确的课序/前置关系找到实际课堂。层级分组父节点与日期最近都不天然是“上一课”；多个前置课只读当前所需进度，无法唯一确定时保留候选/未知，不猜引用。

上节课未完成的部分据实际小结协调，不把归档当成计划全部完成；当前课重点仍服从当前要求和本课安排。自由课无前课时不自动读取最近聊天，同课重开优先恢复原生对话。

## 6. 小结的两种落点

| 本课情况 | 保存方式 | lesson_log 指向 |
| --- | --- | --- |
| 有真实关联剧本 | 在原剧本末尾追加本次课堂小结，保留既有备课内容 | 剧本文件 + 本次小结段落锚点 |
| 无剧本 | 在当前学习集生成独立 `type: lesson-summary` 资料 | 独立资料 + 本次小结段落锚点 |

独立小结默认可放在 `lesson_log/` 目录，目录不是事实身份或权限。日志索引必须也发现分布在其他目录中的剧本小结，不能只扫描这个目录。

小结正文记录：实际问题与材料、推进到哪里、选路/试探/转向、检查点表现及帮助、已成功保存的产物、尚未解决的内容。末尾保留简短“下次从这里继续”，作为同一小结的组成部分，不另存 handoff 正文。

默认续课只读取这段短摘要，建议不超过 600 个 Unicode 字符；需要依据时展开相关经历或原始课堂。计划中的内容、查看过的材料和已经掌握的内容必须按真实发生情况表达。

一次实际课堂只有一个小结身份，由原生 session 绑定。保存位置是一个 Markdown 文件里的一个稳定小结块；Host 生成段落锚点及索引元数据，模型只写有意义的总结正文。稳定小结块定位需要新增支持，不能拿会随编辑移动的行号作永久身份。

实现中的落点在第一次成功保存后固定：后续解除或更换剧本背景仍修订原小结，不在别集同名文件里写第二块。文件移动时只在原集合内按真实课堂块定位，多个命中明确报错；原剧本缺失不能静默换文件。独立小结被删除后，用户再次明确总结可重新生成，索引在重新保存前如实缺失。

区分目标身份和保存操作：小结目标固定为实际学习集 + 原生 session，截止点是该目标随修订更新的字段；一次保存操作用 Host 生成的原生请求身份去重。同一操作重试返回原结果，新截止点的新操作更新同一个小结块，不用截止点生成第二个块。旧操作重试也不能覆盖已经更新到较新截止点的正文。

同一剧本可以被多次真实课堂使用，每次各 append 一个小结块；反复点击同一次归档不追加重复块。原课堂后续又继续讨论时，更新其原有小结块和截止点，不删除别次课堂的小结，也不再额外创建文件。

小结元数据与正文保存在同一文件中：Host 绑定来源 session、实际总结截止点、所属学习集、实际学习时间范围、相关路线/剧本及科目。科目来自已有明确课堂/剧本配置，无依据则未标注；跨科允许多科。之后剧本标签变化不能悄悄重写历史课堂归属。

小结块的标识、元数据和段落定位使用一个共享合同，写入、读取、日志查询和节点跳转从同一解析结果派生。若明确绑定的剧本位于另一已接入学习集，小结仍属于实际课堂的学习集；通过原生 session 的剧本绑定发现其文件，在真实文件权限允许后读取/追加，不能仅凭目录位置改归属。

学生可在资产页编辑剧本及小结。append/修订使用文件 revision 的 CAS，冲突时重读并保留学生修改；不得用旧整篇文档覆盖新版备课或其他小结。删除小结或破坏定位后索引如实失效，不从同名段落猜替代对象。

## 7. 教学归档与保存顺序

2026-09-23 确认：小结保存就是教学归档，原生会话默认保留，可以回来继续。“总结本课”执行以下操作；原生会话菜单的归档则是用户另行选择的收起动作：

```text
用户请求总结课堂或保存学习经历
  → 取得原生稳定截止点与实际关联剧本
  → 主 Agent 起草本次小结
  → 有剧本则 append/修订原文件；无剧本则创建独立小结
  → 原生工作区写批准并保存
  → 重读验证小结块，并确认 lesson_log 可定位
  → 保留原会话；只有明确要求从列表收起才调用原生 archiveSession
  → 返回实际结果与可打开的小结位置
```

不增加旧式提案确认门槛；批准对应实际修改内容。总结本课默认不改变原生归档状态；后续继续同课时更新原小结块。普通非教学 Agent 的归档不被统一改成教学写入，关闭页面、沉默和压缩不触发总结。

失败与重试：起草失败、拒绝写入、保存失败或索引不可读时不宣称完整归档成功；已写成功的原文保留。原生归档失败时仅重试归档；同 session 不重复创建小结块，同一保存操作不重复执行。追加期间文件已变就重读再合并。

已有剧本绑定但文件丢失、无权写或锚点无法解析时，返回具体缺口；不能为了让归档成功而静默改成独立小结文件。原始材料和其他 session 的小结也不能被拿来替换目标。

准备归档时出现新的用户输入或待处理输入，不能用不包含它们的旧草稿直接隐藏会话；中止归档提交并处理当前输入。截止点、幂等身份、串行化与取消沿 Host/原生控制，不让模型填“现在时间”代替事件截止点，也不建立第二套聊天状态机。

空课堂没有真实学习内容时如实记录，不生成进度或能力结论。

## 8. lesson_log 的统一索引

`lesson_log` 从资料中的小结块及其元数据重建，统一收录“剧本内小结”和“独立小结”；一个小结只出现一次，不再手写同步另一份日志正文。

拟议只读入口 `lesson_log_find` 按学习时间范围、学习集、科目和可选检索表达查询，返回课名、本次问题、续课短摘要、真实文件/块引用与分页。正文沿拟议 `learning_read` 的有界来源读取机制展开；这不改变 `learning_find` 仅查画像/锦囊的职责。

时间按实际课堂活动归组，保存/归档时间单列；跨日保留范围，不从 session 首尾时间直接计算专注时长。科目未标注仍出现在全科视图，跨科汇总以 session 去重。一个含多次小结的剧本按各实际课堂记录查询，不能把整份文件当一次学习。

跨学习集分析沿同一已接入范围与原生读取权限，先读有界索引，再精读相关小结。小结中的历史观察不能不经判断自动改写画像或锦囊；分析结论能回到原记录。

首批按需扫描并重建，不加入持久缓存；更正、删除、移动和权限变化在查询/读取时核对。无权读取的剧本不能通过索引泄露其中小结。已有归档但无小结标为缺失，不自动补写所有旧对话。

## 9. 接续版本与历史

开课采用上一课小结时，把真实文件/块引用、revision 和所读短摘要绑定到原生 session 背景快照。之后 append 其他课堂小结或修订剧本，不改写本课当时实际读到的内容。

新开课读当时可用的小结；原课需要采用更正内容时重新读取。Vault 当前仅有内容哈希和现行正文；旧版全文不存在时，只能使用原生背景快照中确实保留的摘录，不能宣称有旧版全文历史库。

路线的当前进度从实际课堂及小结投影，归档状态仍由原生 registry 持有；两者不互相推定学习完成。

## 10. 实施与验收

顺序：路线独立 bench 与原生 session/资料跳转 → route/lesson 模板和可选备课绑定 → 本课剧本/前课进度加载 → 两种小结落点与统一 lesson_log → 教学归档组合动作 → 真实跨课验收。

确定性验收：独立路线与其他 bench 分屏；未开/已开/无剧本/无小结节点；重复开课不复制 session；两条路线交错上课仍读正确前课；不要求自由课先备课。

保存验收：有剧本归档只改原文件、保留原剧本；无剧本生成独立资料；同一剧本的多次课堂小结分别可查；同 cutoff 重试无重复块；CAS 冲突、拒绝、索引失败、归档失败、新输入到达均不假成功。

索引验收：按时间/学习集/科目分页与跨科去重；两种落点返回同一合同；小结块更正/删除/文件移动/权限变化正确反映；引用跳到准确块，旧课堂采用的背景快照不被改写。

真实模型与浏览器验收：用材料备一节课，实际教学中调整阶段并归档；小结追加到原剧本；下一课按真实未完成进度续学。另验随便聊的一课无剧本也能生成可查小结，期间插入无关科目课堂不串线。

对应代码、实际执行命令、已修复的失败和仍待真实模型验收的条目统一记在验收报告中。

# 卡片与独立备课工作流

> 当前补充合同：0.14.0 的学科分离、知识型课本研究、目标驱动备课及五工作预设职责以 [学科关注点与通用工作流分离](2026-09-22-subject-workflow-separation.md) 为准。下文保留该阶段的设计与验证记录；旧模式或学科列表不作为当前调用指引。

本合同补充现有教学迁移、备课与原生工具工作流，落实本轮课堂产物审计后确认的规则。Markdown仍是事实源；不新增数据库、卡片写工具或用户逐卡审批层。

## 产物

- 页头使用 `tags`。正文只有 `## 内容`、`## 参考理解`、`## 学生理解` 三个部分。
- 内容保存完整原题及条件、全部选项/小问、公式与必需图形；题干进入正文搜索。PDF页/区域引用是回溯证据，不能替代正文。
- 原文有参考答案时保留在内容里，可折叠，标明出处，以原文答案为依据。参考理解写知识解释、可检查的推导、方法选择、比较及边界；模型补充标为补充解法。没有原解才标独立求解；发现矛盾保留原文并列疑点待核对，不静默改题或替换原答案。
- 学生理解保存真实表达、尝试、疑问与修正，默认留空；不能由标准答案推造学生认识。普通修改保留该部分与复习历史。
- 题卡原则上一题一卡，关联小问保留完整，多种解法属于同一卡。同类题用 `type: topic` 父节点归纳共性，叶子 `type: card` 的 `parent` 指回它；父节点内容列真实子卡，参考理解说明共同结构、识别线索、先修与差异，学生理解记录对这类题的真实认识。`topic` 没有复习周期。
- 锦囊保留 `type: insight` 与真实经历要求，仍按三段组织。`### 何时想起` 位于参考理解中，兼容现有渐进召回。

## 生产顺序

1. 明确材料范围，逐题列出题面、原解及物理页/区域；看图核对，文字层只导航。
2. 解题者在独立上下文处理一道完整题或一小组紧密关联题。交付完整题面、原文答案、允许使用的先修与原页证据；无关课堂历史不进入任务。
3. 拆卡通常逐题 `draft`，一次在独立上下文完成核对、研究与可保存草稿；父教师不预先解完整批题。`solve` 保留单题分析，`plan` 只安排课程，`review` 针对具体疑点并携带实际正文。已核验同题复用，不机械四连发、不把整本讲义压到一次调用。
4. 主教师核对结果并保存题卡，最后集中归纳一次共性父节点。检查条件、符号、证明与结论的一致性；按已核验小批次保存、回读，核对题干可检索、三段结构、来源、LaTeX、父子关系与覆盖情况，不在主会话重复展开全部解题过程。
5. 未读到、未完成、疑似矛盾的部分明确留在草稿并说明；文件存在、工具返回成功和原页可打开均不代表数学质量通过。

## 运行时接线

当前使用 `ask_worker preset=problem`，保持原生一次性spawn、独立上下文和原生任务轨迹；模型、预算及none/read工具模式按预设配置，完整编排见 [五种工作预设](2026-09-22-worker-orchestration.md)。可选 `sources` 照抄 `pdf-page` 的PDF embed，每次最多4处。Host核验当前工作区路径、页/区域与revision，渲染原页并写为原生附件后交付子会话；不接模型提供的base64、任意宿主路径或自造附件身份。未声明图像能力时明确失败，不静默把图片替换成文字后宣称核对原页。

独立生成上限 `maxTokens` 默认32768，教室设置可调整1024—131072；这是请求上限，不是最低用量或质量承诺，推理与输出的计数由provider解释。自动匹配使用可用的较高推理等级，显式选择保留，不继承父会话短输出上限。API能力不足或任务未完成如实报错，不能更换用户模型自动重试。

普通读写和Bash沿用当前原生权限。原题识别、数学推导、题型归纳由模型负责；路径、版本、预算传递、附件身份、并发取消和持久化由Host负责。

0.12.2 对非法JSON、字段和数组形状返回具体修正位置，不自动修复或删减题面。预算耗尽不交付截断内容；同一用户输入下，已耗尽的相同材料/任务/有效模型预算不再启动，缩小任务、用户明确重试或调整配置后允许再次尝试。摘要哈希与失败码随原生任务事件保存，重启后仍有效，不新增任务数据库。模型不可用先配置，不自动由主课堂接管整批研究。模型是否遵循逐题分工仍需真实轨迹验收，确定性测试不替代此证据。

## 资产入口与兼容

对话中的Vault产物提及/产出文件chip打开对侧资产页或复用已有资产pane，保留唯一原生composer和草稿。资产切换沿用未保存修改守卫；非Vault文件与系统打开动作维持原生路由。

仅精确匹配旧内置内容的卡片/专题/锦囊模板升级；用户自定义模板保留。既有卡片不自动重写，旧原文摘录仍可显示。PDF区域引用卡暂未转写时明确标记，不将低质量文字层冒充已核对的题干。

预览支持分行或同行的 `<details><summary>教师参考</summary>`，默认折叠；卡片、专题、锦囊的 `## 参考理解`（兼容 `## 教师理解`）默认折叠，内容与学生理解保持显示。折叠是渲染状态，不重写已有Markdown；点击可展开，资产编辑器可显式编辑，路线只读预览不显示编辑动作。

## 验证边界

确定性验证覆盖原生子请求收到图像和预算、父历史隔离、旧版本拒绝、取消/重启/配置保持、模板保护、题干搜索、父节点关系和三段生成。浏览器验证覆盖真实产出链接、左右交换、草稿与设置；不能用注入的按钮替代原生写入产物。

真实模型质量需另按同一原题逐卡复核：原题与原解不走样、关键推导有效、结论一致、条件与边界齐全、学生理解不造假。已有课堂审计材料保持在本机，不复制私密记录或用户PDF进入仓库；测试通过不等于本批旧卡已纠正或教学效果已证明。

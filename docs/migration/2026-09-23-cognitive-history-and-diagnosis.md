# 学生理解的认知演变与诊断召回

用户确认：学生理解应保留曾经不完备或错误的认识，以及它如何发生变化；诊断需要召回过往错误模式并综合分析。本轮将这条规则接入现有教学 Skill、工作员公共规则、动态导航和收课提示。不新增卡片字段、工具、记忆实体或历史数据库；专项诊断的并发调度仍待单独实现。

状态：0.14.1资源与提示接线已实施并更新到长期试用实例；确定性验证通过，真实模型诊断质量未验证，详见 [开发与验证记录](../dev-log/2026-09-23-cognitive-history.md)。

## 记录什么

继续使用“内容／参考理解／学生理解”三段。学生理解记录与当前对象有关、有真实证据的关键演变：

- 当时的理解、尝试、错误或不完备之处，包括尚未说清的疑问。
- 促成变化的问题、反例、提示、反馈、实验或自主发现。
- 随后学生实际表达与行为，区分独立、受助完成和尚未检验。
- 后来复习或新任务中的保持、迁移、反复或再次修正。

日期、来源与顺序只使用真实依据；缺失环节留未知，不推测不可观察的内心过程。没有学生证据仍留空，不能把老师的解释或模型生成的感悟补成学生理解。不要求四个阶段全部出现，也不抄成逐句聊天日志。

一个合成示例（仅展示格式，不写入学生模板）：

```markdown
## 学生理解

### 首次尝试
在数组边界练习中写下 i <= 3，解释“数组有3个元素，所以最后访问3”。
来源：本次练习的原作答。此前的理解未知。

### 对照后的修正
老师请他列出3个元素的下标。他改为 i < 3，并说“最后一个下标是2”。
这是得到提示后的修正，尚未检查能否独立迁移。

### 后续独立表现
在长度为5的新数组任务中自行写出 i < 5，并解释有效下标是0到4。
目前证据支持这次边界判断；更复杂循环尚未检查。
```

更新前读原小节，补充新的阶段，保留真实旧认识。当前概括可以更新，但不能用最终正确结论覆盖演变记录。误转写或误归因可以据证据更正并说明；用户明确要求更正或删除时依其要求处理，不能以保留历史为由保留虚假归因。

## 如何召回和综合

1. 从本次错题或试卷的真实作答、题目结构和错误步骤提出检索线索，不能先给学生贴标签再只找支持材料。
2. 在当前学习集以原生 glob/grep 找相关卡片/专题的学生理解、画像、锦囊和必要课堂小结；跨集按实际需要及原生权限读取。
3. 读命中片段的完整时间上下文，特别是后续修正、成功表现和提示程度。长文继续读到相关变化，截断的旧错不能直接代表当前状态。
4. 分别考虑支持、反证或已经改善的表现、情境差异与未知项；同一次经历的多个引用不能当作多次独立错误。
5. 历史表现用于提出原因假设，结合当前作答及用户补充信息验证；必要时设计一个能区分原因的小任务。结论写清依据、适用范围、不确定处和下一步。

给工作员只传相关证据包，区分当前作答、历史阶段、后续变化和老师假设。用户补充只交给相关任务；主教师负责最终综合。现行每课堂一个后台任务的限制未改，不能宣称本轮已支持并行诊断。

## 事实源与现有机制

- 题目或知识上的详细演变留在对应卡片的学生理解中，可复用的选路和教学经历进入锦囊。
- 画像保留带范围、来源和修订来由的当前概括，指回相关证据；不复制所有卡片形成另一套历史账本。
- 课堂小结记录本课的重要转折与真实来源，不能替代原始作答或全部历史。同课小结的既有更新机制不变，重新总结必须保留仍成立的关键经历。
- `learning-data.js` 的画像/锦囊候选不是全库认知历史索引。普通卡片仍通过原生文件检索和读取访问，不因候选为空推断没有经历。
- 当前 revision 是文件变化检测，不是历史版本恢复能力。原文件从未记录或已经丢失的经历不能重建为事实。
- 三段模板继续保持空白，不把本合成示例或固定占位内容写进学生卡片，不批量重写旧资料。

## 本轮接线与验收边界

共同规则说明保留历史；`method-distillation` 承担记录与综合原则；`material-search` 承担发现及时间上下文读取；`material-outline/vault-workflow` 守住写回；备课、路线、工作员和正式收课保持相同口径。`manifest.json` 描述及 L0 导航让教师能发现入口，不每轮加载整份历史。

本轮验证资源登记、实际组装、上下文预算、卡片读侧与小结接缝；不把这些结果当成模型已可靠诊断学生的证明。真实模型需要分别验证：只命中旧错但后来已修正、同一经历多处引用、老师提示后的正确表现、当前新证据推翻旧印象、缺失时间或来源、没有学生作答的空态。

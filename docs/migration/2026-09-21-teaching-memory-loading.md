## 1. 已确定的产品边界

- 教学者是 DSH 原生 Agent 预设；课堂仍是原生 session。写入继承原生权限，工作区写需批准，不迁回旧提案/收录的第二套审批。
- 长期教学记忆只有两类：学生画像与锦囊。画像包括学习进度、相关水平、教学偏好、值得关注的思维模式。锦囊合并触发条件、方法、教法、个人解题经历、适用边界及关联题目；方法与教法是一体两面。
- 原则性的教法 Skill 保留，例如苏格拉底法、费曼法、结构分析法。它们规定一般教学方式，属于教学预设的能力资源；锦囊中的教法是具体情境中的做法及经历，两者可共同使用，Skill 不算第三类学生记忆。
- 同课教学方式的三个默认选择为苏格拉底、费曼、讲解式；结构分析等通过相同 Skill 目录扩展，不替换讲解式。本课设置同时包括既有 learningGoal 与临时要求，首次发送前设置、重开恢复和清除语义按总合同执行。
- 锦囊是 Vault 中可编辑的卡片资产，作为图谱特殊节点连接题目与知识资产。画像和锦囊的事实源都是 Markdown，不再双写旧 `.studyforge` 记录。
- 图谱支持按已有标签聚合、展开标签组，以及以节点为中心查看一阶/两阶邻接关系；锦囊沿用同一资产投影。详见 [图谱标签与邻接设计](../evidence/vault-views/design.md#补充标签聚合与邻接图2026-09-21)。
- 原题、备课、当堂作答和提示已在课堂上下文中；本设计解决课堂之外的主动召回，不另存一套当堂过程。
- 当前学习集优先；可检索用户已接入且权限允许的其他学习集。跨集读取不复制记录、不改变写入归属。全局检索不要求全局目录常驻。
- 主 Agent 可自行读取并判断；原生子 Agent 是可选的检索/核查分工，不是必经步骤。
- 首批支持文本/PDF教学；本设计不引入互动 HTML。
- 路线保留独立 bench。一般课堂没有预设剧本，用户要求备课时才生成；开课可读已有剧本和明确前课进度。归档时有剧本就追加本次小结，无剧本才另建小结资料，统一进入 `lesson_log`。详见 [路线 bench 与课堂日志](2026-09-21-lesson-route-and-log.md)，两类长期教学记忆保持不变。

旧 `resources/teaching/skills/studyforge-method-distillation.md` 要求所有教法走创作发布、排除出锦囊，与当前决定冲突。修订该排斥规则；保留原则性教法 Skill 的正文及渐进加载能力。旧 `base.md` 中的门面工具名、提案收录流程和全量索引规则也不能原样迁入。新预设只挂载迁移后的教学资源，避免旧 provider 再次披露矛盾规则。

当前 resources 中已有苏格拉底和费曼法正文；“结构分析法”是本轮确认应支持的原则性教法示例，当前 manifest 未发现同名独立条目，实施时需明确新增或整理对应正文，不能把目录名存在当作已实现。

## 3. 内容与索引的最小约定

以下类型名是拟新增的约定，不是已实现 schema：锦囊用 `type: insight`，画像条目用 `type: learner-profile`。`tags` 沿用 Vault 现有能力；不要求固定目录名，不用目录名授予权限。默认模板可放在 `锦囊/` 与 `学情/`。

每条记录需要一个简短的召回描述：何种题目结构、思维障碍或教学决策值得想起它。建议在正文中使用模板小节 `## 何时想起`；这段原文就是索引的来源，不另维护一份模型摘要作为事实。缺少小节的导入文件仍可全文搜索，候选明确说明尚无召回描述，不自动编造。

锦囊正文保存方法、教法、学生经历及边界；排版自由。案例使用真实文件链接及可定位的课堂来源。画像可以分成若干有标题的条目，不要求一个不断增长的总画像文件。笼统水平判断应展开到具体主题和实际表现；推断与学生原话保持可区分。

候选投影只包含：真实标题、类型、召回描述、已有标签、关联案例的简短定位、来源学习集、内容 revision 与可读 ref。案例摘要仅取原记录中实际写下的内容；缺失时只返回链接。文件路径/作用域/revision/ref 由 Host 确定，模型不补造。

首批读侧索引在实际查询时从有权读取的 Markdown 构建，不引入持久缓存；每次查找/读取重新核对范围，修改、删除、重命名后的原文以当次读取为准。画像概况如由已有记录汇总，也只是可重建投影，不形成第三类长期记忆。

## 4. 三层披露

### L0：开课入口

教学预设的稳定 section 规定共同教学边界和召回职责：何时召回、如何区分旧经历与当前判断、如何使用两个只读工具、何时停止查找并回到学生动作。

原则性教法 Skill 通过 DSH 原生 skills provider 披露名称、适用描述和真实读取入口；开课只保留简短目录，当前明确选定的教法正文作为独立 section 生效。没有显式选择时沿用教学预设的默认项。切换或组合教法由当前教学目标与用户要求决定，不因为检索命中某锦囊就自动切换。

当前教法选择保存在可由原生 session 恢复的预设选项中；每次 assembly 从当前所选资源生成正文，设计目标是压缩后仍生效且不要求每轮重新调用 load-skill，实际生效必须用压缩后的出站请求验收。选过但已切走的 Skill 不继续叠加为现行规则。原则性教法遵守学生本轮明确要求，例如索要完整解释时不能用默认追问阻挡。

原则性 Skill 的正文预算单独记账，不纳入画像/锦囊动态 context 预算；默认只展开当前所选正文，不能借此把所有教法全文常驻。当前选项的持久化与生效投影需要在精简原生教学接线中实现，不把旧 course metadata 服务直接视作已接通。

每次装配的动态 context 绑定当前 session/cwd/读取范围，给出：

- 当前学习集的名称、两类内容的读取入口与刷新语义；具体 revision 随查找/读取结果返回；
- 当前输入及显式选中材料的原生引用（已有就复用），不重复题面；输入变更只提供定位，不自动等同于换题；
- 少量学生明确设定的通用教学约定；其原始画像条目可展开；
- 当前任务明确关联的画像条目线索；没有相关线索时不猜画像；
- 跨集检索是否可用及实际覆盖范围，不列出所有学习集和文件；
- 查询或重读已发现来源变化时，提供重新读取提示；不声称每轮自动监测全部读过的文件。

通用约定没有可用来源时为空；不扫描整盘寻找全局画像。学习集尚未确定时只披露允许使用的检索入口及当前范围状态。

初始预算建议：教学记忆动态 context 总计不超过 1,200 个 Unicode 字符。此数值是可调实现默认值，尚无教学效果证据；实际请求记录字符数和模型 token 用量。超过预算的条目保留可读入口，不静默拼接更多正文。

### L1：候选索引

主 Agent 读懂当前题目后，在第一次实质讲解/选路引导前，主动查一次相关画像和锦囊。新题或真正不同的学习目标出现时重新查；同题普通往返不重复查。

教学中新增障碍、学生提出另一条路线、主动提及旧经历、或形成值得连接的发现时，可以再次查找。是否换题、是否需要新记忆由教师根据语义判断；Host 不使用关键词规则去判定教学阶段，也不增加第二套课堂状态机。

检索词由主 Agent 从题目结构、求解目标、学生当前理由和教学疑问中提出，可使用多个相关表达。字面/标签/图关系负责产生候选；主 Agent 负责语义筛选。查询不得依赖先知道最终方法名。

优先使用明确文件引用、已连接案例和当前学习集记录；必要时扩展至有权限的其他集。存在跨集教学线索时，即使本集已有结果也可以跨集查。

初始预算建议：每页最多 6 条，每条召回描述不超过 180 个 Unicode 字符；引用与案例定位单独受总响应预算约束。返回游标、是否截断、实际查过的范围，不能把“本页没有命中”表述成“学生没有这段经历”。无合适命中时可扩展关键词/浏览同类索引；已有足够依据选择下一步时停止。

### L2：正文、经历与证据

选中候选后，主 Agent 读取相关小节/案例；需要核对数学适用性或提起共同经历时，再读原题或原始课堂片段。正文不需要每轮重注入。

锦囊经历是对过去的记载，方法内容是待对照当前条件的建议。当前题中是否适用与是否值得用于教学比较是两个判断；一个旧方法不适用时，其失败或换路经历仍可能很有用。

初始单页正文预算建议为 4,000 个 Unicode 字符；按可定位的段落/行范围截取，返回连续读取位置及 revision，不截断后假称完整读取。预算控制单次读取，不给所有课型规定固定总检索次数。

## 5. 两个只读工具的拟议合同

下列名称用于本设计，尚未注册；最终 schema 由实现中的单一来源导出，不维护多份参数名单。

### `learning_find`

- 输入：可选 `query`（一个检索表达）、`kind`（画像/锦囊，省略表示两者）、`scope`（当前集/全部已授权集合/之前返回的具体集合引用）、`cursor`。
- 省略 query 是有界索引浏览；空结果不得自动扩权。只携带 cursor 时延续其绑定的查询；其他条件必须与原查询一致，否则明确要求重新查询。
- 输出：第 3 节的候选投影、Host 生成的可读 ref、实际范围、`nextCursor`、截断或范围不可用的具体原因。
- 不接收任意绝对路径作为跨集授权，不将关键词命中分数称为教学相关性或方法正确性。

### `learning_read`

- 输入：工具/动态入口曾返回的 `ref`；可选由前次返回的 `section` 或 `cursor`。ref 绑定真实作用域、路径和 revision；不要求模型填写额外 ID、时间或哈希。
- 首次无 section/cursor 时返回有界正文及真实小节目录；之后按返回的定位继续展开。重名标题以服务返回的小节定位区分，定位随 revision 变化。
- 输出：原文、来源类型（画像/锦囊/关联题目/课堂依据）、文件与小节定位、revision、真实关联证据 ref、下一页。
- 读取时重新检查原生权限与当前文件版本。文件已变化则给出陈旧状态和当前可重读 ref，不用新版内容冒充旧版；删除/重命名无法解析时明确返回，不凭标题猜替代对象。
- 当记录关联原生课堂时，沿现有 session 的可用读取接口解析来源并核查访问范围；尚未迁移或不存在的旧来源返回不可用，不能补编经历。

两个工具都只负责读取。它们对工作区内、跨工作区和子 Agent 调用使用同一原生权限判断。写入仍走已有批准流程，不因读侧工具名称改变权限。

Native Vault 当前仅支持现行文件内容哈希，没有历史正文库。历史 revision 不可恢复时必须说明；本轮机制不宣称增加了版本历史存储。

## 6. 读取时机与请求顺序

```text
用户在原生 session 发起学习
  → DSH 接受当前输入、cwd 与原生文件引用
  → 装配共同教学 section + 当前原则性教法 Skill + L0 动态 context
  → 如有剧本则读当前安排；如有明确前课则读其续课短摘要
  → 主 Agent 读取题目，形成当前要解决的教学疑问
  → learning_find：当前集候选，按需跨集
  → 主 Agent 选择候选并 learning_read：相关正文/经历
  → 必要时读关联原题或课堂依据
  → 主 Agent 决定下一句教学动作
  → 持续教学；只有出现新的召回需要才展开其他记录
```

“主动”由预设中的操作职责与实际工具调用实现，不依赖用户提醒查记忆。第一版不增加每回合后台模型来判断是否检索。如果真实模型经常跳过新题召回，应针对该失败改提示与接线，并以真实请求复验，不能只因为写了规则就宣称可靠触发。

## 7. 压缩、重开与文件变化

- 复用 DSH 原生 system prompt/runtime context 的装配与投影；动态入口在模型请求前重新提供。不要通过另发一条伪学生消息来注入背景。
- 原文工具结果留在原生对话；当堂已读且仍可见的内容继续使用。压缩后的摘要可能只保留来源引用，需要时重读实际内容，不能因为“曾读过”而省略当前需要的证据。
- 同课重开从原生 session 恢复；L0 重建读取入口和范围。没有当前题目依据时不要自行选择新题或重新声明掌握。
- 动态快照的最新版本语义不等于从模型历史中物理删除旧文本。记录更正后要明确旧判断已失效，必要时重读；权限撤销阻止后续读取，不能宣称模型忘记了已读内容。
- 异步检索结果绑定原生父 session、任务及文件 revision。回来时用户已换题，应重新判断相关性；不得作为新题的既定背景自动采用。
- 后续实现需核对实际准备发往模型的请求，证明动态入口在压缩后存在、没有每轮追加整份锦囊，不能只检查 provider 的返回值。

## 8. 索引与全局范围

全局范围仅是已接入且原生权限允许的学习集集合。原生工作区列表是发现入口，登记为工作区本身不构成额外读取授权；不扫描用户主目录。

跨集接线由 Vault 的 Host 只读适配层负责：为每个获准学习集绑定独立根和索引，不能把另一个集的绝对路径塞入当前 `createVaultStore`。发现与读取分开；每次实际读取都按当前 session 的原生文件访问策略执行，并在枚举候选前排除无权读取的内容。参考原生 `dsh-tool-fs` 的 `resolveRegularReadTarget` / `applyReadTool` 中 execute 所用 `ctx.fs.resolve`、`stat`、`readText` / `streamText` 路径；不能从模型门面直接调用当前 store 的 Node 文件读取来绕过原生后端。

独立 Vault 的 `agent-io.js` 已接跨集适配：注册表限定可发现集合，实际读取调用原生 `ctx.fs`。rc.2 原生读取继承本机文件访问能力，没有额外的逐集读授权 API；写入另走原生批准与 sandbox。未注册集不读取，某集不可用时返回实际覆盖/错误并保留其他集结果；`scope=all` 不静默退回当前集。当前与跨集查询均有真实 Host 自动化断言。

读侧索引按学习集构建，保存文件定位、revision、类型、标签、召回原文与关系。查询跨集时合并有界候选；不把整个全局索引送进课堂，不复制锦囊事实。

当前 `createVaultStore` 每次遍历读取 Markdown，适合小库但不是增量索引。首批在实际检索时扫描当前集和本次需要的其他获准集，支持取消并记录耗时；每轮 L0 不遍历全库。索引响应说明实际覆盖与刷新状态；正文读取重新核对 revision。只有规模实测需要时再加入增量缓存，届时需定义目录项增删改、内容变化的失效规则，并仍在每次读取时检查权限。

首批无需向量库即可验证接线：字面候选复用 `searchDocuments`，标签候选复用 `queryDocuments` / `matchesWhere` 的 frontmatter 匹配，图邻接复用 reference 投影，再由主 Agent 语义选用并按需浏览有界索引。是否需要语义检索应由“不提方法名”的真实召回用例暴露；不能把当前字面搜索称为已具备语义召回。

## 9. 子 Agent 与事实边界

默认主 Agent 直接读即可。历史材料多时，可用原生只读子 Agent 查找候选并返回小包：召回原因、原文片段、来源、相似点、差异与不确定性。复杂数学适用性可另做窄范围核查。

子 Agent 获取任务所需的画像/锦囊范围；没有必要就不继承整课历史。原生工具过滤与实际读取权限都必须落实，不能只靠角色说明。检索结果不能自动写回记忆或变成系统级教学规则。

不按“是否符合常见套路”淘汰反常案例；以原题、实际尝试和适用条件判断。历史经历可用于比较，但不能证明当前方法有效；两道关联题也不自动认证一个通用定理或稳定个人偏好。

## 10. 具体示例与验收

以下是合成测试场景，不是真实学生画像。

当前题涉及解析几何选路，用户未提及极点极线。锦囊记录学生在旧题中优先尝试极点极线、因未找到预期结构而改用参数方程；画像记录该主题近期学习范围。

1. L0 只给画像/锦囊入口和当前范围。
2. 主 Agent 基于“解析几何、方法选择、约束的表示”等当前疑问查候选，而不是预先知道需要哪张锦囊。
3. 候选揭示这段选路经历；主 Agent 读实际案例。
4. 主 Agent 可以问“这次哪些条件让你更愿意用参数方程”，但不能直接断言极点极线适用或学生总是偏好它。
5. 学生的新解释与旧记忆冲突时，先据当前证据继续讨论；需要持久更正时沿原生批准修改原记录。

确定性验收应覆盖：

- 新原生教学 session 仅加载精简 section/L0；普通 Agent 和无关子 Agent 不加载课堂画像；客户端 Remote 与模型工具均实际接线。
- 当前原则性教法正文生效，其他 Skill 只有简短目录；切换、临时要求、压缩和重开后选择可恢复，旧教法不继续作为现行规则叠加。命中锦囊不自动修改教法选项。
- 两类记录的发现、分页、正文定位、截断提示和空范围；没有召回小节的文件仍可搜索。
- 文件修改/删除/重命名、查询期间 revision 变化、权限变化、压缩和重开；旧内容不被冒充成现行证据。
- 当前学习集优先与有权限的跨集检索；注册工作区不能绕过原生权限，读取不写事实。
- 锦囊特殊节点能打开同一 Markdown 资产并回到案例；reference 不错误增加拆分子卡数。

真实模型验收必须覆盖：

- 不告诉方法名，仅给新题，教师能发现相关个人经历并读证据。
- 有字面相似但结构不同的旧题时，教师能比较差异；不适用的方法经历仍可作为教学比较材料。
- 加入一个错误/条件不足的锦囊，教师不把它当数学规则；当前学生反证能修正旧印象。
- 同题连续往返不机械重复检索；换题后能重新查；无记录仍能正常教学且不编共同历史。
- 实际发送请求的上下文体积、工具次数、等待时间与新增内容；静态检查不能代替这层证据。

教学效果另以真实学生的新题选路、试探与修正表现观察，不把召回成功等同于直觉培养成功。

## 11. 实施顺序

1. 整理精简教学预设及当前资源，保留原则性教法 Skill 并明确当前选择，消除与两类记忆冲突的旧规则；定义画像/锦囊模板及召回小节，接通 L0。
2. 在当前学习集实现统一有界索引、`learning_find` / `learning_read`，接原生权限、版本与工具返回，完成渐进披露。
3. 接通已授权其他学习集的独立根、受控读取与查询；加入锦囊节点类型与案例 reference 投影。
4. 从新原生 session 跑上述真实模型用例及上下文体积检查；根据具体失败调整召回质量，再考虑可选子 Agent 或语义索引。

跨集能力属于完整设计的一部分；步骤 2 完成时只能报告当前集可用，不能提前宣称全局召回已实现。

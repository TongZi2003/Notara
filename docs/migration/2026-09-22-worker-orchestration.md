# 五种工作预设与工作流

> 当前补充合同：0.14.0 的学科分离、知识型课本研究、目标驱动备课及五工作预设职责以 [学科关注点与通用工作流分离](2026-09-22-subject-workflow-separation.md) 为准。下文保留该阶段的设计与验证记录；旧模式或学科列表不作为当前调用指引。

本合同取代固定“解题者”和 solve/plan/draft/review 四模式的当前调用设计。原有原题证据、三段卡片、单份课堂剧本、原生权限与课堂事实边界继续有效。

## 主教师与后台任务

主教师负责用户沟通、范围确认、任务清单、课程总框架、轻量审阅、共性父节点与最终写回。后台任务使用 DSH 原生 one-shot spawn，每次独立上下文；不是五个必须依次执行的阶段，也不引入新的聊天生命周期。

| preset | 工作预设 | 交付 |
| --- | --- | --- |
| problem | 题目研究员 | 一题及关联小问的独立研究、完整题卡；即时咨询可只交解题分析 |
| lesson | 课时备课员 | 按既定框架完成一节课的单份 Markdown 剧本 |
| review | 核验员 | 实际原文与产物中具体疑点的判断、证据、最小修改 |
| general | 通用工作员 | 边界清楚的资料查阅、证据整理或其他局部产物 |
| exercise | 出题员 | 围绕目标的小测与变式、学生题面及折叠教师参考，自解检查后交付 |

拆卡先略读书目结构，范围不明才问章节与深度；列题目及来源清单，逐题交给 problem，教师检查产物并保存，最后据真实子卡集中归纳父节点。保留原题全文与原文答案，学生理解无证据留空。

备课由主教师给总框架、每节课目标、先修、前后课要求与时间约束，lesson 逐课完善，主教师检查衔接、重复、遗漏、难度与时间。必要题目交 problem；练习交 exercise；有具体疑点才交 review。

小测和变式按学习目标区分基本功、识别与迁移；可按需设计巩固、条件变化、逆向提问、对比与边界。所有新题先自解，开放题给评价依据；区分原题、改编题、新题，不把预计难度或一次表现当作掌握结论。

## 提示词与材料

每次只组装 workers/base.md、当前 workers/{preset}.md、至多4个选定学科/教法 Skill；任务中带 goal、focus、materials、PDF sources。已登记且可注入的 Skill 候选由工具 schema 公布。没有父历史、全量画像或全部工作流。

公开模型入口为 ask_worker，必填 preset、goal；参数约束以注册合同为准。移除 ask_solver 的新调用入口，但旧原生事件与分析记录仍可读。独立研究返回完整产物和简短交接，不回传全部推理历史；主教师的接收和保存不等于独立核验通过。

清单记录完成、待核对、缺材料、未完成及产物位置。返工只交相关正文与反馈；疑点不能在摘要、路线、剧本中变成已确认结论。模型缺失或预算耗尽不能自动由主教师重做整批，也不原样重复失败请求。

## 配置、工具与持久化

每个预设分别配置模型、推理等级、生成上限与工具模式。默认沿用旧 solver 的已保存模型；没有配置时仅精确匹配已接入的 gpt-5.6-sol，不静默切换父模型。none 只处理显式交付材料；read 只允许原生 read/glob/grep/read_image，仍受原生权限约束，不提供 Bash、写工具或二次委派。PDF 按版本读取与原图附件交接继续由现有来源辅助实现。

正式 Vault 写回由主教师使用原生权限完成。任务配置写 notara/worker-settings，任务状态写 notara/worker-task，均使用现有 ignorable 扩展事件；旧 notara/solver-* 只读兼容。已有 configureSolver/solverTask/cancelSolver 是内部 RPC 接缝，前者增加 preset/tools，模型侧不再暴露旧工具。

当前每课堂同时执行一个后台任务，按清单逐项处理；使用原生任务查看、取消和冷恢复，不另造调度系统。取消后同一输入不自动重跑；旧运行任务重启后显示中断，不伪装继续执行。

## 教室展示与验收边界

列表和像素视图只投影角色、状态及可用操作；题干、答案与子会话过程仍由用户主动打开原生分析记录查看。配置按预设保留，切换预设不能串用未保存草稿。

验收包括：五种不同的实际子请求；独立模型/预算/工具配置；父历史隔离；允许读取且禁止写入/递归；按需 Skill 正文到达；原页版本校验；旧记录读取；取消和冷恢复；界面配置保存及安全投影。合成模型只证明接线，不证明真实模型遵循工作流或题卡、剧本、小测的教学质量。

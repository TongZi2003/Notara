## 2. 本次迁移裁决

- 一个 DSH workspace 是一个学生的完整学习空间；集是组织与默认关注，不是各自独立 workdir。
- 同一学生的跨集、跨学科资料、知识与学情可按需读；学习事实的新增归属、当前关注与读取授权分开。账号/根目录边界仍严格。
- 新系统从空数据开始；不导入旧 Pi 会话、旧学习数据、旧格式、旧事务或迁移锁，不复制旧兼容分支。
- 使用 P0 核验的最新 DSH 并在阶段内锁定；允许的构建期修正及其证据以 P0 review 为准，不擅自升级或回退。
- 使用DSH原生界面扩展；保留ui-conversation/ui-chat的流式、输入、Queue/Steer/Stop和滚动机制，StudyForge只补教学renderer；保留笔记本主题和“本课”能力，主入口与页面层级按首版设计精简，不能以保留主题为由复刻旧繁复布局。
- 课程资料按 DSH 对话资源预览接入：复用 Session 的右侧标签、聚焦与分栏，StudyForge 保存教学引用和来源定位，不维护第二套打开标签状态。具体机制与限制见 [DSH-PREVIEW.md](2026-09-11-dsh/DSH-PREVIEW.md)。PDF、图片、Markdown、DOCX 补齐定位，代码/文本/HTML沿用官方能力；PPT、表格、音视频及二进制DOC不列必交新增类型。
- 资料页打开书即左读原文、右看该书脑图/列表。初次仅书根，按节点展开已有结构或明确继续拆解，直到卡片详情；卡能回到原件图层位置。原卡片视图的顺序/按书/标签/放射能力保留。
- 内置主Agent预设收敛为资料整理、诊断分析、苏格拉底授课、头脑风暴拓展、搜索。搜索既能独立对话，也能作真实subagent，复用同一检索能力与来源合同。共享Skill、独立帮手与Creator用途边界保留，旧全模式菜单不再迁回。
- 对话树沿用roadmap及已有日期快捷筛选，接日期范围；具体新增时间视图种类另议。日历过去看活动日报，今天看已做/剩余，未来看预计到期复习和已排课；定时生成/恢复更新同一天投影，不自动收课。
- 以上新设计及执行取舍见[首版界面与主Agent预设设计](2026-09-11-dsh/UI-FIRST-RELEASE.md)。未定视觉样式/默认日报时刻不在本轮硬编码。
- 原件按资料版本共享保存；卡和消息固定引用原版本。用户明确改来源时才重新绑定。
- 一课可零材料，也可混合多份原文、卡片和图片。课程 materials 是教学安排中的引用，native active tab 只决定当前预览；预览不要求先加入课程清单，清单也不是读取白名单。删除“不同材料必须拆课”的规则。
- 发送时明确选区优先，否则使用当前资料位置；浏览不发消息，也不把整课全部材料每次塞入上下文。
- 未学卡不进入首页库存提醒，仍在资料中可找、可开始学习；明确安排与真实学习后的到期复习照常。
- 新增本课卡片红笔修订：按真实操作的前后版本展示旧行红色删除线与新版内容，不把别课/课外修改或机械字段混入，也不把删除线写回正文。
- 保留原生模型与思考强度选择、回合/本对话token用量；新增显式Raw JSON调试者模式并复用Trajectory。用户明确要求的控件允许显示模型/强度/token；调试视图可展示本会话技术字段，普通教学正文与公开导出仍按各自边界。详见[原生对话能力设计](2026-09-11-dsh/DSH-NATIVE-EXPERIENCE.md)。
- 日常教学使用原生Skill provider，五种教学选择是同一learning composition上的配置。临时语气/要求直接保存本课覆盖文本，动态systemPrompt.section在下一请求生成完整提示；不要求先制包，不复制底层prompt管理器。
- learning / creation 是当前已有的运行用途与权限边界，必须保留；不能误当成被撤回的“自动教学模式切换”删掉。
- 插件能力与学生事实分开。停用/卸载能力不删除学生卡、学情、知识、复习和小结；内容删除走明确资料管理动作。

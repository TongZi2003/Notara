# 完整诊断驱动的学习主线

日期：2026-09-13。状态：本地实现与分层验证已完成，真实模型教学质量尚未验收。计划见 `../plans/2026-09-13-DSH-learning-flow-implementation.md`，实施与证据边界见 `../../dev-log/2026-09-13-DSH-learning-flow-implementation.md`。

2026-09-15 范围澄清：本文的完整诊断顺序适用于用户明确选择的诊断学习流程；普通主题课与第一节后按需提出的普通路线见[轻量教学与共建资料](2026-09-15-Notara-lightweight-learning-and-authoring.md)。三种起点共用原生对话，本文旧双入口布局不再作为新增页面要求。此补充是规格更新，不代表新流程已验收。

## 用户已确定的行为

综合本人上传的全部资料（也允许没有资料）与学生诊断，生成学习路线，安排学习计划，逐步沉淀卡片、学情和联系。诊断采用“先完成一轮较完整的诊断，再生成学习路线”。

后续讨论明确：不要求指定主讲书；可跨多份材料取用内容，由 AI 自己的教学叙述串联。材料定位与选材是关键环节，可以用多个 scout 独立查找。

检索与备课范围明确包含学生已有的卡片：题卡、方法、笔记等可直接成为教学材料；不必有原书来源，也不以是否学过决定能否被选材。

已接受渐进积累：顺便整理实际读清部分的局部脑图，挑选可复用、带内容标签的卡片；希望按页码看到哪些区域已细化、哪些仍未整理。

每个书籍板块、原文片段和卡片都应能追溯到涉及它的具体课堂，课堂也能回到当时的材料位置与产物。

课中导入整本书时，整书作为本课可用资料；实际参与本课的关联只落到有依据的页段或选区。用户已确认这一设计，不以整书导入推断整书参与教学。

## 推荐方案与取舍

把“制定学习路线”作为首页和课程页上的一个入口，进入原生课堂完成诊断。路线、日历、工作台继续使用现有页面。推荐把全过程接成一条有事实依据的学习主线：比仅增加一个规划提示词多做上下文接续和结果回流，但能支持刷新、跨课和真实后续行动。单独新建学习应用/另一套课堂会重复现有对象和导航，不采用。

首页直接采用原生对话入口，两个学习入口放在输入框下方的推荐框中；布局见 `2026-09-13-DSH-home-two-entries-design.md`，与本设计的完整学习流程联合接线。

流程：明确目标与时间 → 盘点资料和既有表现 → 完整诊断 → 确认诊断小结与路线/日程 → 按路线学习 → 检验、记录与关联 → 调整尚未学习的部分。

只有学生主动选择制定路线时进入这套流程；日常问一道题、整理资料或自由探索仍按原意执行，不强制先诊断。

## 1. 确定范围

- 学生说明学习目标、期限及可用时间；已有明确信息不重复询问。没给截止日期可以只安排顺序，没给每日时长不能编造时间预算。
- 先枚举本人资料，综合目录、关键原文、卡片和既有学情。全资料可检索，不等于把全文一次塞入提示词，也不等于每份资料都必须纳入本次目标。
- 同一知识点跨书选材、去除重复练习；完整展示当前目标实际采用的材料。未读清或暂时不可读的资料明确留出缺口，扫描资料通过实际图像理解，不冒充已解析。
- 没有资料时从目标、适用课程标准和真实诊断任务确定范围，使用明确标注来源的外部资料或生成练习。上传不是开课前提。

## 2. 完整诊断先行

- 先形成目标范围的诊断提纲，覆盖主要能力、关键先修与综合应用；题量随目标宽度和真实结果调整，不用固定题数冒充完整。
- 在原生课堂中分组完成真实作答、解释、迁移与针对性追问；保留未提示与提示后表现的区别。诊断题没有实际作答时不形成能力结论。
- 已有历史证据只在读取后使用，陈旧、矛盾或与目标无关的证据不替代当前判断。学生自述作为自述保存，不冒充独立表现。
- 可以中断并继续，仍是同一诊断过程；原始作答由原生会话持有，按现有学情/小结记录阶段结果。
- 每个重要部分有真实观察或明确的未判断原因，才给出诊断小结。若学生提前停止，只保存阶段记录，不能宣布已完成全面诊断并自动生成正式路线。
- 小结说明：当前能做什么、卡在哪里、哪些尚未确定，以及相应题目/观察依据。不用一个总分或全局能力标签代替情境判断。

## 3. 诊断转换成可执行路线

- 学习目标组织为阶段与有先后关系的具体学习任务。第一版复用现有课程树，一条目标对应其中一支；任务节点仍打开原生课堂，阶段先通过分组投影呈现，不把空阶段节点冒充已上课程。
- 每个任务说明学习目标、为什么安排、采用的资料/已有卡片和可观察的检验方式。依据是诊断中确认的需要，不能只把教材目录原样转换为课程。
- 跨资料组合合法，无资料任务同样合法；既有已学内容可跳过、压缩或安排抽查，但须有判断依据。
- 初次路线覆盖约定目标，近期任务具体，远期任务允许根据真实结果细化。不得以滚动调整为由跳过用户要求的完整首轮诊断。
- 保存沿现有学生确认通路；路线和日程先展示可编辑提案。后续改动展示实际差异，保留已开展课程与历史。

### 跨资料备课与 scout

- 路线的连续性由学习目标、先修关系和 AI 的教学叙述维持。原书保存作者结构与原文；每节课可组合多份资料，不要求先决定主讲书。学生明确要求学完某书时，其章节顺序和覆盖范围成为该路线的约束。
- 完整诊断后先确定整体路线，近期任务精细选材，远期任务按阶段确定范围。具体课临近学习时再备课；已上课内容保留当时版本，后续修订不改写历史。
- 主教师把诊断转成当前所需的教学材料条件，例如“寻找可从单位圆理解的和差公式解释、递进例题和适用边界”。scout 接收检索任务、资料范围与必要的教学约束，不接收整段课堂或完整学情档案，也不判断学生掌握。
- 先根据书目和实际目录缩小候选范围，再对相关章节精读。独立缺口或不重叠资料批次可并行，例如分别查概念解释、例题序列、反例/先修条件；分工随任务变化，重叠部分由主教师去重。并发和追问复用 DSH 原生子会话，不另建任务队列。
- 已有卡片与书籍原文同属检索候选。scout 能精读题面、卡背解释/方法、来源和已有卡片联系，按当前任务沿来源或关联继续查找；不因标签相同就自动认定相关，也不无界展开整个关联图。

- 按用户后续裁决，scout可按需查看当前卡片自己的学习/复习记录及有依据的课堂使用，帮助判断是否重复取材；不接收完整学情档案、其他卡片历史或私有课堂笔记。`read_content`默认只读内容，`includeActivity:true`才加当前卡片局部历史，并可分页。现有`lastAccessed`是实际学习/复习日期，单纯打开卡片没有浏览账本；`browsing:not_recorded`表示未记录，不能解释为从未访问。
- 卡片候选以真实卡片引用及版本为身份；有原书时附带实际来源，无原书时仍能采用。被选中后直接引用原卡，保留原有学习记录，不为了上课复制一张新卡。卡片与原文重复表达同一内容时，主教师判断需要哪一种呈现，检索去重不删除原记录。
- scout 只负责判断内容能否支持当前任务。是否适合该学生新学、补练或复习，由主教师结合真实学情和学习记录决定；scout 读取卡片不产生学习记录，不把卡片中的参考解当学生作答。
- 每个候选带回实际读取的来源位置、短摘录或内容说明、支持哪个教学环节、需要的前置条件及必要上下文。片段不能只给概括，主教师和学生应能回到真实原文；没有找到、未读范围和读取失败分别保留。
- 固定版本与位置取自真实材料读取；在采纳为本课引用时由 Host 验证可解析。出处能打开只证明引用有效，不证明教学内容正确：主教师仍需精读选中片段，核对解释、例题条件、符号和跨书分歧。
- 主教师选择并组织候选：保留足够的定义/推导/题目上下文，用自己的解释、过渡、比较和追问形成连续教学过程，在课堂逐步展开。检索报告不直接倾倒给学生。
- 候选检索不自动创建学生卡片、学习记录或学情；教学叙述中的原书引用可展开，AI 新解释不冒充原书原话。卡片从实际学习或明确整理请求中按现有写入边界形成。
- 缺少资料时仍允许教学；需要外部检索则保留真实 URL。未导入的外部来源不冒充本地资料；仅需示例而自行生成时按生成内容呈现。
- 可定位片段继续使用现有原文锚点和工作台；不因为 scout 存在就增加学生必须管理的“素材库”或另一套卡片实体。检索进度只在影响等待/失败时显示必要短句。

### 顺便整理与页码覆盖

- 每次备课可留下本次读清部分的目录细化，以及有复用价值的完整题目、方法或概念卡；普通解释段保留来源定位，不要求逐段卡化。主教师先查已有卡并复用标签，再合并提出目录和精选卡片的整理结果，备课不等待学生逐条确认。
- 沿用普通卡与现有确认通路，不新增“备课卡”实体；保存时没有学习记录的卡保持还没学，选材和整理都不自动产生掌握或复习。
- 书籍脑图展示实际页段及整理程度：仅目录/未细化的部分用浅色虚线；已定位但未完成整理的部分显示实际定位范围；已保存的细化部分展开具体节点及卡片。来源定位只到某个片段时标明局部，不能把整页或整章标成整理完。
- “未细化”表示目前没有已保存的细化结果，不能据此断言从未读过。已有真实读取依据时才显示已定位；历史没有读取证据的部分保持未知，不编造未读/已读结论。
- 覆盖绑定具体资料版本和实际内容范围。粗目录或父节点引用整章不能涂满该章的整理进度；提案尚未确认、读取失败或任务中止也不能标为已整理。旧版范围不能自动迁移为新版已处理。
- 页码是学生查空白区域和继续整理的入口：点击未细化范围可定位原文并从那里继续拆解，已细化部分保留并复用。Markdown/Word用其真实章节与文本位置呈现同一含义，不伪造PDF页码。
- 整理进度与学生的学习记录分别呈现：原书可被AI整理而学生尚未学；学生也可直接学习尚未细化的原文。

## 4. 路线驱动计划

- 路线负责学习任务与先后关系；同一任务的日期只有一个写者。课堂日程复用路线节点日期，不能再造一份独立日历安排与它互相矛盾。
- 按学生实际时间安排新学、练习和复习；复习继续使用已有卡片记录与计划，不因为上传或建卡而自动认定学过。
- 首页展示下一项具体行动及其所在路线，可直接打开相应课堂；日历显示排定安排，课程图呈现整体方向。浏览路线不创建会话。
- 漏学、延期或表现改变时提出后续安排调整；学生调整日期优先，不能悄悄顺延全部任务。

## 5. 开课与结果回流

- 点一个节点开课，Host 绑定该节点、目标及诊断依据的实际版本，带上本课材料、学习重点和检验方式。不能要求学生每节课重新解释前情。
- 延续某节课时继续沿既有固定版小结接续；路线来源和前课接续是两种上下文，不把诊断课伪装成所有后续课的直接上一课。
- 课堂产物沿现有提案、登记、复习、学情与小结写者保存。普通新卡确认后入库；真实学情用实际证据保存/修订，不另加一套掌握度账本。
- 节点可查看本课形成的卡片、方法、学情观察与小结，以及对应依据。进度从真实开课、收课与学习记录重建；已开课、已收课、通过检验彼此不同。
- 学完后老师比较目标与结果，说明下一步可继续、需补练或需改变安排。对未完成部分提出局部修订，不重新生成整棵树覆盖历史。

## 6. 联系如何形成

- 材料 → 卡片：复用真实原文位置与章节挂点。
- 卡片 ↔ 卡片：复用真实卡片引用；语义关系由阅读后的判断和课堂解释支持，不靠同标签自动连全图。
- 课堂 → 卡片/学情：来自当前真实提交与证据的投影，保持可追溯。
- 路线任务 → 课堂 → 产物：由实际开课绑定与已保存结果连接。
- 课程图回答“下一步学什么”；工作台关系图回答“这个内容从哪来、和什么有关”。二者可以互相定位，关系含义不能混用。
- 更正卡片、撤回关联或修订学情后，展示最新有效结果；历史版本继续能追溯，不重写已发生的诊断或旧课上下文。

### 从内容回到相关课堂

- 书籍脑图节点、页段和卡片详情提供“相关课堂”，列出课名、日期及实际涉及的范围。一个内容可关联多节课，一节课可涉及多本书和多张卡，不能用“最后一次课”覆盖之前的记录。
- 点击课堂关联时尽量定位到实际引用、讨论、练习或保存结果所对应的原生消息位置；只有课程级材料声明时只能打开该课，并如实注明只是本课材料，不假造精确讨论片段。
- 关系按事实说明用途：路线里安排过、备课中引用过、课堂消息带过、实际讲练过、产生过卡片或学习记录。备课和引用不能自动升级成讲练或掌握；“实际讲练”需要真实课堂内容/依据支持。
- 同一节课涉及同一部分多次时，先合并为该课一条入口，展开再看各次位置和产物。同一章仅一个例题被涉及，只标注实际例题/页段的范围；整本书挂进本课不意味着所有下级板块都讲过。
- 通过卡片来源间接关联原文时，显示为通过某卡片涉及，保留引用链；不能把来源上的每个片段都表述成当场精读。没有引用或证据支撑时不根据同标题/同标签补造课堂联系。
- 关联固定到当时的资料版本、卡片版本和原生课堂身份，正文整理路径变化不切断已有出处；卡片改写或资料换版不追溯改变旧课材料。课堂归档仍可回看，原记录不可读取时说明不可用，不跳到同名的新课。
- 从现有课堂材料、接受的消息引用、已保存产物和采用的学习依据生成可重建的反向查询；不让模型给每个板块手填课号或维护第二份课堂历史。尚未记录的关联保持未知，不把缺少历史记录说成学生从未涉及。

### 课中加入整书、只使用部分内容

- 导入时建立资料库记录和本课材料声明，整书可继续浏览；该动作只表示本课可用，不生成全书页段的讲练关联、细化覆盖或学生学习记录。
- 具体选区被学生消息引用，或主教师实际采用为教学内容/练习时，关联真实资料版本、页段/区域和对应课堂消息或记录。老师采用的出处必须能回到实际读取的内容，Host绑定真实身份；仅有书级信息时只保留书级声明，不猜具体页码。
- 例：导入100页书，本课引用 p12–14、p37、p81。书籍节点可显示“本课引用5页”，展开列出各范围；这5页的相关板块能回到具体课堂，其他95页不因导入而新增本课的片段使用记录。
- 同页被重复引用时页数去重；只采用一道题或部分区域时保留精确选区，并说明涉及该页部分内容。“引用5页”不表示这5页都已讲完或学会。
- scout搜索/预读20页而课堂采用5页时，两种范围分别保留；顺便确认的目录/卡片细化是另一个整理范围，不能把这三种覆盖互相替代。
- 正式课堂引用能从内容端回查；未采用候选仍只是备课线索。重复添加本课资料不重复创建书，也不重复累计页数；资料换版后旧课继续指向当时版本。

## 最小验收链

1. 多份同主题资料加既有学情：盘点范围、完成诊断、提出有依据的路线及日程，确认后首页/课程/日历一致。
2. 零资料、零历史：允许开始；实际诊断前不声称学生掌握；正式路线在诊断后生成。
3. 诊断中断、刷新与恢复：作答和已存观察仍在，不凭页面打开判定完成。
4. 节点开课重试：只创建一节课，材料版本和诊断依据正确；另一个目标的上下文不会串入。
5. 学习 → 检验 → 确认卡片/记档 → 保存学情 → 收课：节点结果、来源和关联可回查，浏览不推进学习进度。
6. 学生表现与原诊断冲突、延期或手动改期：修订同一认识，提出可审核的后续差异，已开展课程与历史不丢失。
7. 真实模型分别走有资料和无资料两条正常学习路径；模拟模型只能证明接线，不代替诊断与规划质量。另保留手写主题、点阵工作台、宽窄屏和关闭恢复验收。
8. 多 scout 对不同资料/缺口检索：每个采纳片段能回到实际固定版本，重复候选被合并，截断/扫描不可读/没有找到不冒充完整覆盖；引用悬空时不能进入已备好状态。
9. 跨书内容有不同符号或前置条件：主教师明确处理后形成连贯课文，原书位置保留；未采纳的检索候选不生成卡片或学习记录。
10. 只有卡片而没有原书，以及混合书籍/卡片两种选材：候选可精读并按原卡身份进入课堂，版本可追溯；同卡跨课复用不重复建卡或改变复习记录。scout默认只收内容，显式请求只增加该卡自身历史，不混入完整学情及其他卡片记录，也不虚构浏览历史。
11. 同一本书有粗目录、已定位片段、已确认局部拆解和未细化区间：脑图准确显示页码及覆盖；父节点整章来源不冒充全章细化，单页片段不冒充整页完成。刷新、取消任务、提案未确认和资料换版后仍准确，学生学习记录不随整理变化。
12. 同一页段/卡片在多节课引用或练习，一节课使用多处原文：内容端列全有依据的课堂，能跳到正确课及已有消息锚点；重复引用按课合并，整书引用不泛化为每节已讲。换版、卡片更正、归档和历史缺失时不串课、不改写旧依据。
13. 课中导入100页书，scout预读20页、课堂只采用不连续5页：整书可读，内容端只按实际采用范围关联课堂；同页多次引用去重，局部选区不冒充全页讲完，未采用95页不新增本课学习记录。没有准确位置时只显示书级材料关系。

本地证据包括109单元、47个不同集成用例、4个不同浏览器场景的最终通过记录，以及构建、测试类型和84项原有同源schema检查。覆盖原生诊断确认→路线→开课/接续、卡片局部历史、100页只采用5页、跨版本来源、覆盖与课堂往返。上述13条中依赖真实教师判断的诊断完整性、选材质量、跨书叙述连贯性、正常学生完整学习效果仍未验收，不能用模拟模型替代。旧64004临时目录已缺失；用户已同意从空白新空间开始，未做旧数据恢复或在新预览发送测试课堂消息。

# Notara 0.23.2：修好 Windows 课堂写入喵

本版修复 Windows 教师命令无法启动、已有资料修改时出现权限错误的问题。也修好了空白课堂重载后的草稿恢复，以及 ChatGPT 登录回调偶尔选中浏览器禁用端口的问题。

下载 [notara-0.23.2.zip](https://github.com/TongZi2003/Notara/releases/download/v0.23.2/notara-0.23.2.zip)，或查看 [0.23.2 发布页](https://github.com/TongZi2003/Notara/releases/tag/v0.23.2)。依赖仍为 DSH 0.2.0-rc.1，Node.js 下限为 24。

## Windows 教师命令与资料写入

Windows 教师现在使用固定版本的原生 BusyBox ash，解决 Git Bash/MSYS 在 DSH 受限令牌下初始化失败的问题。教师命令仍由原生沙箱执行，普通会话继续使用原生 PowerShell。

中文、空格路径、长脚本、heredoc 和管道均有回归覆盖。工具说明明确使用 POSIX ash 语法；依赖 Bash 数组或 GNU 扩展的脚本需要调整。源码首次启动会下载并校验固定 shell，缓存齐全后可离线复用。Release ZIP 附带二进制、完整对应源码、GPLv2 许可证和来源说明。

六种使用 Vault IO 的 CLI 写入命令改走本地写入桥：`write-batch`、`record-review`、`undo-review`、`create-route`、`revise-route` 和 `schedule-lesson`。课堂、工作区及调用身份由 Host 绑定，保留内容校验、版本冲突检查与文件 ACL。每次调用的写入能力独立，结束或取消时撤销，并等待已经开始的写入完成。

只读模式、越界路径、重解析路径和过期请求继续拒绝。文件替换保留完整 DACL 与完整性标签，也验证了原受限令牌后续仍可写入。沙箱、令牌完整性和全局 ACL 的权限边界继续生效。

前台、后台、超时移交和取消都会清理临时脚本与写入能力。清理失败会返回错误，后台任务也保留非零状态和诊断。

## 另外两处修复

- **空白课堂草稿恢复**：重载时等待原生学习目录与课堂登记就绪，保持原课堂身份。教学设置的未保存草稿留在原课堂；切换目录、导航退出或取消恢复时释放等待订阅。点击「新的一课」可继续使用当前目录已有的空白课堂。
- **ChatGPT 登录回调**：排除 Fetch 标准禁用端口，遇到端口被占用等冲突时，关闭监听后有界重试。取消与超时均释放监听，减少登录页面偶发打不开的问题。

发布流程新增 Windows 原生沙箱与 CLI 回归作为发布前检查，再进入 Linux 构建与发布。Actions 运行时与 runner 版本也同步固定。

## 安装和升级

Windows 需要 **Windows 10 1903+ / Windows 11 和 x64 Node.js 24+**。完整解压 Release ZIP 后，双击 **安装 Notara.cmd**，按提示安装环境与依赖。成功后使用桌面「启动 Notara」「关闭 Notara」，或包内同名 `.cmd`。安装本身不启动服务。

原来的 Git 与 npm 安装方式继续适用于 Windows、macOS 和 Linux。Windows 用户仍可在 Git Bash 中执行源码安装与启动命令。ngrok 是可选功能，默认关闭，按需在「设置 → 远控设置」配置并启用。完整步骤见[安装说明](https://github.com/TongZi2003/Notara/blob/v0.23.2/docs/install.md)。

Windows 教师 CLI 写入要求本地、支持 Windows ACL 的学习目录。UNC/SMB 共享及工作区内部重解析路径会拒绝，详细限制见 [Windows 说明](https://github.com/TongZi2003/Notara/blob/v0.23.2/docs/runtime/windows-native-vault.md)。

已有用户可等待「设置 → 更新」准备兼容更新，再在课堂与后台任务结束后重启。手动升级前，先停止旧实例，完整备份实际数据目录，包括隐藏文件。源码用户在代码目录执行：

```sh
git pull --ff-only
npm ci --no-audit --no-fund
npm run vault:upgrade
npm run vault
```

Release ZIP 用户先在新包目录安装依赖，再执行 `npm run vault:upgrade` 和 `npm run vault`。使用自定义数据目录时，给升级与启动都加 `-- --root "/你的数据目录"`。已有目录采用固定插件快照，单独拉取源码或新建课堂不会替换它。快捷安装器也不迁移已有数据或快照。备份请收好喵。

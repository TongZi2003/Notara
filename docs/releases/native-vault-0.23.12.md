# Notara 0.23.12 · 同步教学与 Vault 工作流

把桌面新版的教学体系和 Vault 工作方式同步到 WebUI，并补齐空间白板、学情上下文、专用 Vault 工具与工作员权限。旧课堂记录和现有配置保持兼容。

## 教学与资料工作流

- 同步桌面版的共用教学概念、混合教法、高中数学/物理/化学课堂指导与备课/拆书技能。
- 将梳理、路线规划与资料整理整合到新版教学工作流。旧技能调用名继续加载对应新正文；旧课堂的教法记录按新混合教法读取，不改写历史事件。
- 新增专用 `vault_read`、`vault_search`、`vault_save` 和 `vault_command` 工具。领域命令复用 Vault 校验与数据操作，不需要启动 shell；全文保存使用版本校验，冲突时保护已有内容。
- 更新学情模板与课堂快照。学情变更只追加到对话尾部上下文，分支单独建立快照；扫描不完整时不会误报学生画像已删除。

## 工作员与空间白板

- 工作员可选择只读或工作区范围。启动时绑定原生沙箱，只读课堂不能授予写入能力；旧配置继续沿用原有权限。
- 学生可用的工作员状态显示任务阶段、可见输出长度和活动时间，不展示工作员思考或工具内容。
- 空间图支持空间坐标、立体图形、拖动旋转、滚轮缩放、复位与 SVG 导出；保留平面图和 0.23.11 的白板分支继承。

## 修复与模型请求

- 修复空间圆锥几何、SVG 导出目标、非法表达式隔离、画布滚轮和触控样式。
- 修复 PDF 页面图像向原生模型附件的传递；不支持图像的模型会明确说明没有核对原页。
- 修复学情变更提醒重复或遗漏、未播种模板的只读参考、旧技能菜单标题与工作员范围兼容。
- 白板、学情等动态状态继续追加在请求尾部。本次教学资源升级会改变固定提示词，首次使用可能重新建立模型缓存；各服务商的实际命中与计费取决于其实现。

## 下载与更新

- **Windows x64 免安装版**：`notara-portable-0.23.12-win-x64.zip`，解压后运行 `start-notara.cmd`。
- **普通安装包**：`notara-0.23.12.zip`，解压后运行 `install-notara.cmd`。
- 已安装用户可在 Notara「设置 → 更新」检查并重启更新。手动更换源码安装目录，请先停止服务，再更新代码、执行 `npm ci` 和 `npm run vault:upgrade`。

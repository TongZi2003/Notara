# Notara 0.24.4 · 回复、远控与启停修复

本次 0.24.4 以 0.24.3 为代码基线重新发布，只合入独立修复和相关测试修正。此前撤回构建中的实验长上下文组件不在本次安装包内。

## 本版修复

- **ChatGPT 回复与重放**：完成事件为空、不完整或与流式片段不一致时，不再用它覆盖已收到的回复和工具调用。旧的空重放记录回退到可用的历史映射；HTTP 与 SSE 错误统一分类，仅显示安全、有界的诊断信息。
- **HTTPS 远控模型设置**：识别单模块与合并模块请求中的连接模块，修复远控网页加载模型设置失败。认证、Host/Origin 校验及未知模块拒绝保持有效，连接模块响应使用 `no-store`。
- **Notara「拾页」标题**：初始 HTML、PWA 名称和课堂标题统一品牌，重命名、切换与刷新后保持一致。
- **目录锁释放**：自身释放开始后，迟到的心跳回调不再误报锁异常；活跃锁的真实异常仍会报告。手工升级和运行目录迁移复用相同的锁处理。
- **启动记录清理**：只清理本次精确匹配且所属进程全部停止的记录，持有目录锁后再次核对；不删除其他实例或新一轮启动的记录。

测试修正包括按原生轮次等待、按工具调用身份核对结果、将大文件准备排除在 PDF 操作期限外，以及限制测试文件并发。Windows 发布检查覆盖更新安装与意外退出恢复；远控浏览器检查同时验证真实消息订阅和即时更新。

## 上下文与升级范围

- 保留 0.24.3 的原生 `@deepseek-ai/dsh-compaction-basic`，不引入 Billion、Notara 请求预算协调器、私有历史归档/检索及对应 SDK 补丁。
- 数据格式仍为 5，DSH/Cordis 版本保持不变。0.24.3 可通过「设置 → 更新」检查，并在课堂空闲时重启更新。
- 曾安装撤回的同版本实验构建时，请先停止服务，备份运行目录和外部学习目录，再手动下载本次程序并执行快照升级。同版本不会自动提示更新。
- 本版不重写原始课堂，也不承诺自动修复旧实验构建已经写入的压缩记录。漏教章节、重复读取人设及长程教学效果仍需专项处理，不能据此宣称已解决。

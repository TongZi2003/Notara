# Notara 0.21.1

本版本基于 DSH 0.2.0-rc.1，包含 Native Vault 和可选像素教室。旧 StudyForge 工作台已退役。

- 默认收起输入框权限快捷选择、性能用量与 Feedback/Export 日志类指令；沙箱和审批规则保持原生行为。
- Coding Tools 默认关闭。“设置 → 学习界面 → 显示调试记录”联动原生代码工具，可进入轨迹；保存失败时恢复开关并提示。
- “改动文件”保留原生差异查看，行内 Vault 文件链接继续打开资料面板。
- 升级识别带版本号的旧快照，更新两处安装链接，保留已安装的像素教室；同版本换代码目录时也可以刷新依赖链接。
- 升级失败会恢复快照、安装链接、原配置与受影响的显示设置。
- 旧版抛物线互动图在收起前等待参数保存，避免紧接着“带入对话”时使用旧值。

升级前停止服务并完整备份学习目录。0.21.0 以前的课堂会在首次打开时迁移格式，回退需要旧代码、旧依赖和整份旧数据备份。详见[安装说明](../install.md)。

Windows 实机验收尚未完成。脚本模型的自动化结果不代表真实教学质量已通过。

# Notara 0.23.7 · 书院画廊开门啦

小猫把画框摆好、书页理齐，九位角色的故事终于有自己的小展厅啦。首页点 **书院画廊**，就能在新标签页慢慢翻看。

- **九位角色的立绘与设定**：完整角色图、人物来历、性格、日常与人物关系都收好了；点图可放大，手机也能浏览。画廊独立展示，不会改动你的课堂人格和教学设置。
- **新的书页 N 图标**：浏览器与新建桌面快捷方式换上新标识。已有快捷方式运行 `create-notara-shortcuts.cmd` 就能刷新啦。
- **Windows 安装体验改进**：补齐过程日志和失败提示，出错时方便找原因；原有安装方式和免安装版继续保留。

悄悄提醒：普通安装包里藏了个小彩蛋，留给你自己发现呀。

## 把新版本抱回家

- **Windows x64 免安装版**：下载 `notara-portable-0.23.7-win-x64.zip`，解压后双击 `start-notara.cmd`。内置 Node.js、依赖和构建文件，无需现场安装依赖。
- **普通安装包**：下载 `notara-0.23.7.zip`，完整解压后双击 `install-notara.cmd`。
- **已有源码安装**：更新代码后运行 `npm ci`、`npm run vault:upgrade`，再重新启动；学习数据仍使用原来的目录。

完整操作说明见 [README](https://github.com/TongZi2003/Notara/blob/v0.23.7/README.md)。

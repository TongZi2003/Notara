# Notara 0.24.2 · 稳定性修复与白板操作设置

本版修复全量测试报告中的编辑、资料定位、草稿、设置发布和恢复问题，增加鼠标模式独立滚轮映射，并调整白板底部缩放控件。

## 白板操作与编辑

- 「设置 → 学习界面 → 白板操作」分别保存鼠标/触控板模式和鼠标滚轮映射。鼠标滚轮可选择放大缩小或上下滚动；切换触控板保留鼠标映射，已打开白板即时响应。Ctrl/⌘ 滚轮始终缩放。
- 底栏改用「− 滑条 ＋」和独立百分比输入框，范围30%–200%，数字按Enter或失焦后生效；缩放保持视口中心位置。
- 调换窗格按钮缩至28px，避免被两侧面板遮住；白板顶栏按钮高度、字体与文字位置统一。
- 修复自由绘图、导图操作、选区和撤销历史的边界，保存冲突保留学生草稿，菜单撤销不删除仍需引用的图片。
- 白板历史引用与缓存按预算保留；正常保存、轮询和分支不自动清理对象或升级数据格式。

## 资料、草稿与页面刷新

- 修复PDF页码/区域引用定位与主动切换文件之间的迟到请求竞态，以及创建成功后列表刷新失败被旧文件覆盖的问题。
- 整文件预览上限256MiB，较大的PDF在512MiB内走有界范围读取；单RPC最多1MiB、单连续对象最多32MiB，并限制并发与等待区间。PDF文字层缺少映射时仍以真实页图为准。
- 本地草稿合并写入，存储配额失败保留本页输入并提示处理；在途保存不清除后续输入。
- 白板、路线、教室、图谱与星图的投影按来源revision复用，未变化时返回小回执，继续观察外部文件修改和删除。

## 启动、更新与故障恢复

- Windows设置发布只对明确的文件占用错误有界重试，每次重新检查版本冲突；普通保存错误按真实原因提示。
- 修复删除课堂恢复、更新失败回退及启动旧快照时的数据格式守卫。
- 更新缓存保留当前、回退、待更新及活动进程使用的快照；缺少所有权标记的旧缓存可只读盘点，保持原状。
- ngrok两路进程输出分别限长并脱敏，保留真正的退出错误；已释放视图的正常取消不再误报打开失败。
- 25份学习Skill、混合教法与共用概念共27份教学正文保持0.24.1采用的桌面原文。

## 下载与升级

- Windows x64免安装包：`notara-portable-0.24.2-win-x64.zip`，完整解压后运行 `start-notara.cmd`，另提供 `.sha256` 校验文件。
- 普通安装包：`notara-0.24.2.zip`，完整解压后运行 `install-notara.cmd`。
- 更新清单：`notara-update.json`。

本版继续使用白板格式v2与dataVersion5，与0.24.1保持同一数据格式。已有安装先停止服务并备份运行根及外部学习目录；手动采用新源码或新便携目录时执行快照升级：普通目录运行 `npm run vault:upgrade`，便携目录运行 `./runtime/node.exe --import=tsx ./scripts/vault-upgrade.ts`，自定义数据根追加 `--root`。

**0.24.0及更早版本跨越dataVersion5边界时必须备份后手动升级。** 旧程序不能安全读写新白板；回退旧数据格式时恢复对应的程序与数据备份。

## 验证范围

修复通过本地构建、类型、插件、单元、集成与真实浏览器回归，浏览器使用隔离Vault、合成课堂与测试模型。正式发布流程分别执行Windows命令/安装/恢复/便携启动检查与Linux类型、单元、集成、浏览器检查；两种ZIP在打包时独立解压核对全部条目CRC和长度，更新清单与便携包附带SHA-256。

这些检查不代表真实付费模型、ngrok公网账号或实际教学质量的验收，本次没有修改真实学习数据。

# Notara 0.24.1 · 自由白板与学习 Skill 原文同步

学生可以直接在白板上写、画和整理资料，再把选定内容交给老师完善。内置学习 Skill 使用桌面端作者的最新原文，Web 工具接口在正文之外适配。

## 自由白板与局部共建

- 新增文字、绘图、思维导图、真实资料、链接和函数图；编辑自动保存，保存冲突与在途新输入保留草稿。
- 绘图使用本地懒加载的 Excalidraw，字体和依赖随包提供；思维导图保存语义父子关系、关系线与备注。
- 资料卡引用当前学习集真实文件，Markdown 与代码支持原位编辑；PDF、图片和媒体复用原生阅读器。
- 学生可连线、分组，查看老师贡献的原稿与撤销记录。请老师完善先填入本课堂唯一输入框，学生发送后才调用模型。
- 老师先读最新版再提交局部修改；原生选区回执约束目标，元素选区不能任意添加自由图形或改整块布局，整块选区可补新图。冲突与过期回执明确拒绝。
- 保留选择、补一步、排序、图形、关系流程和逐帧演示六类组件、作答历史与重发、双面知识视图、高亮、三维图、流式板书、导出及分支继承。

## 下载与升级

- Windows x64 免安装包：`notara-portable-0.24.1-win-x64.zip`，解压后运行 `start-notara.cmd`。
- 普通安装包：`notara-0.24.1.zip`，解压后运行 `install-notara.cmd`。
- 更新清单：`notara-update.json`；便携包同时提供 SHA-256 校验文件。

白板新增场景、关系与贡献历史，数据格式标识从 4 提升为 5。**从 0.23.12 或更早版本升级需先备份，再手动升级**，设置中的更新器会说明这一点，不自动重启迁移。

停止旧服务，备份 `~/.notara/vault-runtime` 或自定义运行根，以及所有外部学习目录。采用新版源码或解压新版程序后，在新目录运行 `npm run vault:upgrade`；便携包使用 `./runtime/node.exe --import=tsx ./scripts/vault-upgrade.ts`，自定义根加 `--root`。不要直接覆盖已安装快照。

新版本可读取旧白板；旧版本不能安全读写新版内容。回退时恢复升级前的程序与数据备份，不能只换旧插件。此次发布工作没有改动用户当前安装或真实学习数据。

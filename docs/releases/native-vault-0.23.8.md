# Notara 0.23.8 · 换张小名牌，把虫虫抱走

小猫抱着工具箱巡完教室啦。这回给课堂换上整理菜单，也把白板、启动关闭和后台任务的小绊脚石一起收拾进工具箱。

## 课堂整理：三个点里有小名牌

- **重命名**：在左侧课堂列表点 **三个点 → 重命名**，填写名称后保存。列表和课堂顶栏一起更新，刷新后也在；原聊天记录和未发送草稿留在同一课堂。空白名称不能保存，中文输入法选字时的回车不会提前提交。
- **归档对话**：收起后可点 **撤销归档** 恢复记录。课堂或关联工作仍在运行时，先确认是否停止并归档；取消不会停止工作。取消归档只恢复记录，不自动重启已停止的任务。
- **删除对话**：保留原来的永久删除确认。把警示框里的课堂名称原样复制粘贴，再勾确认框；运行中的课堂和关联任务要先停止。学习资料、白板和共享附件保留。
- 菜单会避开屏幕边缘，长列表底部和手机上也能操作；方向键可选项目，Esc 收起后回到三个点。

## 白板：题面真的收好，再喊你动笔

- 补强常驻教学规则：邀请学生去白板作答前，先写完整题面并核对成功回执的板块与标题；学生说找不到时，先查真实保存的板书，缺题就补写，已有题就帮忙定位。
- 流程图会按箭头说明的文字尺寸留间距、换行与避让；页面和导出的图使用同一布局，减少标签被节点盖住或互相压住的问题。
- 修复深色主题下理由输入框的文字与光标看不见的问题；已输入内容在失焦、轮询和切换宽窄屏后仍可见。
- 高亮不再插进公式、代码或链接语法内部；表格里的公式绝对值、引用别名和转义竖线不会被误拆成新列；跨课堂切换不会复用另一课堂的旧图片。

## 把运行时的绊脚石也捡走

- 教室显示 Host 提供的最近二十条任务，取消客户端六条截断，并修复宽屏和手机下的滚动裁切。
- 启动与远控状态核对真实服务；处理遗留锁、状态文件消失、关闭失败重试及锁释放竞态。并发启动、构建和打包使用同一构建锁，避免复制到半成品。
- 自动监听端口避开浏览器禁用端口；关闭 Windows 子进程树后再清理临时目录。远控上游响应中断时，客户端连接也会结束。
- 修正 ChatGPT 缓存输入重复计量、额度及上下文错误映射，以及工作员重新登录后的恢复；修复旧读取覆盖新技能保存结果和恢复课堂时设置页被自动关闭的问题。

## 把新版本抱回家

- **Windows x64 免安装版**：下载 `notara-portable-0.23.8-win-x64.zip`，完整解压后双击 `start-notara.cmd`；包内有 Node.js、依赖和构建文件。
- **普通安装包**：下载 `notara-0.23.8.zip`，完整解压后双击 `install-notara.cmd`。
- **已有用户**：在 **设置 → 更新** 检查新版，待课堂和后台任务停止后重启更新。源码安装也可以在停止服务并保留数据备份后，更新代码、运行 `npm ci` 和 `npm run vault:upgrade`，再启动。

这次没有改变课堂数据格式。原安装方式、可选 ngrok、画廊与图标继续保留；安装包里的小彩蛋也还在哟。

修复经过隔离实例的确定性测试与浏览器操作检查；白板规则审稿和保存链路验证不代表真实模型永远不会口头误报。真实订阅账号权限与公网 ngrok 连通未在本轮联机验收。

完整操作说明见 [README](https://github.com/TongZi2003/Notara/blob/v0.23.8/README.md)。

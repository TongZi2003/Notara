# Native Vault 0.22.1

修复“性能与用量”设置被调试显示规则覆盖的问题。简洁或详细统计现在跟随原生设置，关闭调试记录也能查看；刷新保留选择。

修复会话归档只排队生成小结却提前返回成功的问题。归档恢复原生持久化和运行中停止确认，不依赖模型；“总结本课”继续单独保存小结。课堂标题旁新增“管理课堂”，直接使用原生列表归档、撤销和恢复已归档课堂。

包含正式版本的自动检查、后台下载和校验，以及首页和“设置 → 更新”中的“重启并更新”。课堂与后台任务结束后才能重启；新版启动失败时尝试恢复旧安装。课堂、资料和设置会保留。

DSH、Cordis 和数据格式不变。0.22 以前的用户需停止服务，先执行一次 `npm run vault:upgrade`；已采用更新启动器的用户可从界面采用此版本。Windows 实机验收尚未执行。

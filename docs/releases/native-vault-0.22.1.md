# Native Vault 0.22.1

修复“性能与用量”设置被调试显示规则覆盖的问题。简洁或详细统计现在跟随原生设置，关闭调试记录也能查看；刷新保留选择。

修复会话归档只排队生成小结却提前返回成功的问题。归档恢复原生持久化和运行中停止确认，不依赖模型；“总结本课”继续单独保存小结。课堂标题旁新增“管理课堂”，直接使用原生列表归档、撤销和恢复已归档课堂。

保留 0.22.0 的更新机制与同一 DSH、Cordis 和数据格式。旧安装需停止服务并执行 `npm run vault:upgrade`，正式发布后已支持界面更新的用户可从界面采用此版本。发布操作及 Windows 实机验收尚未执行。

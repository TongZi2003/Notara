# 0.24.4 撤回构建与重新发布范围

此前的 0.24.4 实验构建因长上下文处理问题撤回，原安装包不再提供。本次沿用 0.24.4 版本号，以 0.24.3 为基线重新整理，只保留回复、远控设置、品牌和启停相关独立修复。

实验压缩器、请求预算协调器和私有历史归档/检索组件不再包含在本次构建中。原生压缩器保持 0.24.3 行为，原始课堂记录不做自动重写；旧实验构建写入的数据应保留备份，不把换程序当作已完成历史数据修复。

完整的本次功能与升级边界见 [0.24.4 版本说明](native-vault-0.24.4.md)。曾使用撤回的同版本构建时需手动下载和升级，同版本不会自动出现更新提示。

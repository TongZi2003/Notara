# Notara 0.23.11 · 带着板书继续学

对话分支现在会继承创建分支时的完整白板，继续讨论时可以接着看已有板书、作答和资料关系。

## 白板跟随新分支

- 创建对话分支时，复制点击这一刻的完整白板，包括板块、布局、学生作答和资料备注。即使从较早消息分支，也保留当前白板。
- 新分支独立保存板书，后续修改不会影响原课堂；旧数学交互场景也会复制并重新绑定。
- 白板读取或复制失败时，如实报告创建失败，不再生成看似成功却缺少板书的课堂。
- 此前已经创建的空白分支不会自动补填；可以从保有完整白板的原课堂重新创建分支。

## 作答提示与上下文

- 修改答案草稿后，会清除上一次本地必填提示；再次提交仍正常校验。保存或发送失败的提示继续保留，便于重试。
- 白板状态仍作为对话尾部的动态上下文追加，不因更新板书而改写系统提示词、工具定义或已有消息。
- 白板概览最多 3,000 字符。超长时优先保留最近有效作答，并提示按需读取完整板书；原始内容、布局与作答记录不被裁剪。
- 修复答案摘要截断 emoji 的问题，并保留旧文件超长标题下的最新作答。

缓存回归覆盖 DeepSeek、GLM、Kimi、Claude、GPT、Gemini，以及常见兼容接口。验证的是请求前缀保持稳定，真实缓存命中与费用仍取决于所选服务商、模型、缓存键和有效期。

## 安装与更新

- **Windows x64 免安装版**：`notara-portable-0.23.11-win-x64.zip`，完整解压后双击 `start-notara.cmd`。
- **普通安装包**：`notara-0.23.11.zip`，完整解压后双击 `install-notara.cmd`。
- **已经在用**：先结束课堂与后台任务，在「设置 → 更新」检查并重启更新；手动更换程序目录请按 [README](https://github.com/TongZi2003/Notara/blob/v0.23.11/README.md) 的快照升级步骤操作。

回归使用临时学习集、合成模型、真实原生分支与浏览器操作；没有使用真实账号进行付费推理，也不将离线请求比较当作实际账单验证。

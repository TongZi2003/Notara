# Notara 0.23.10 · 小弹窗，把焦点抱好 🐾

唔，准备收工时，小猫又在键盘旁捉到一只虫。关闭弹窗已经打开，课堂输入框却可能晚一步抢回焦点，Esc 就没法把弹窗收起来了。这个小尾巴一起补好啦。

## 键盘留在小弹窗里

- 关闭确认等弹窗打开后，键盘焦点会留在最上层的弹窗内，输入框延迟聚焦也不会把它带走。
- Tab、Shift+Tab 在弹窗控件间循环；Esc 取消后，焦点回到打开弹窗的按钮。
- 输入法正在合成文字时，Esc 留给选字过程，不会误关弹窗。原来的取消按钮和点击空白处也仍然能用。
- 取消不会发送或改写输入框里的草稿；正在停机时的防重复操作保护继续保留。

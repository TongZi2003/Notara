# Notara · Native Vault 0.23.1

喵，0.23.1 把安装、课堂和日常维护都收拾得更顺手了。相较上一正式版 **0.22.1**，这次一起带来 Windows 压缩包安装、桌面启停、可选远控、ChatGPT 账号登录、白板尺寸调整、课堂删除，以及右上角更新提醒。运行时继续锁定 **DSH 0.2.0-rc.1 / Cordis 4.0.4**。

## Windows：解压后，把安装交给入口

从 [0.23.1 发布页](https://github.com/TongZi2003/Notara/releases/tag/v0.23.1) 下载 **notara-0.23.1.zip**，完整解压到可写目录，双击 **安装 Notara.cmd**。程序保存在解压出的 `notara` 文件夹内；请使用 Release 资产 ZIP，勿直接在压缩包中运行或选择 GitHub 的 Source code 包。

安装器检查 **Node.js 24+、npm、Git for Windows 与 Git Bash**。已有可用环境直接使用，缺项通过 **WinGet** 安装，系统权限提示由你确认。随后检查官方最新正式版、安装依赖并构建，成功后创建桌面「启动 Notara」「关闭 Notara」。安装本身不启动服务，也不启用 ngrok。Git clone、npm 安装和命令行启停方式继续可用。

发布 ZIP 带有逐文件 SHA-256 清单；安装器只选择更高的正式版，校验新版的压缩包摘要、完整文件清单与版本，在临时目录准备依赖、构建成功后再切换程序。源码仓库、修改过的程序和程序子目录中的额外文件会被拒绝覆盖。普通替换失败会尝试恢复旧文件；异常中断保留备份与恢复记录。网络失败明确报错，可用 `-SkipLatest` 显式安装包内版本。参数与恢复方法见[安装说明](https://github.com/TongZi2003/Notara/blob/v0.23.1/docs/install.md#windows-压缩包快捷安装)。

安装后双击 **启动 Notara.cmd** 或桌面入口，后台服务就绪后打开当前登录入口；关闭浏览器不会停止服务。**关闭 Notara.cmd** 等待它管理的实例停止，保留课堂和资料。重复点击可复用或安全结束；外部终端启动的实例会提示回原终端停止，不按进程名批量结束 Node。入口支持中文、空格及 `&` 路径，拒绝覆盖另一份安装的同名快捷方式；移动程序后需要重新创建。

首次冷启动的等待上限由 55 秒调整为 120 秒，包含后台模块装载与服务就绪时间，避免新安装机器仍在正常启动时误报失败；收到明确失败状态仍立即报错。关闭时先完成最后一次状态写入，再清理控制记录，修复延迟写入重新生成“正在关闭”死记录的问题。

## 远控：想从别的设备继续时，再打开喵

新增 **设置 → 远控设置**。安装 ngrok、保存自己的域名与访问凭据后，手动点击「启用远控」；页面显示启停状态与 HTTPS 地址。**默认关闭，保存不会启动，完整重启后需重新启用**。关闭远控只结束隧道与认证代理，本地课堂继续运行；不用远控就无需安装 ngrok。

保留后台启动、停止、单独启停远控和交互配置命令。页面与命令行共用运行目录锁，限制同一实例的远控入口；控制器只管理它拥有的本地服务。密码、令牌、控制状态和日志保存在私有目录，页面只接收脱敏状态，不回显凭据或写入浏览器持久存储。

自定义配置必须使用独立私有目录。设置目录权限前会检查真实路径，拒绝程序目录及其父目录、盘根、用户主目录和目录链接绕过，避免 Windows 权限继承波及程序文件、触发热重载后出现空白页。

DSH、管理桥和认证代理只监听 loopback。远程入口验证访问密码、Host 与 Origin，保持本地登录与模型授权边界；启用失败时本地课堂继续可用。远程访问者会使用该实例保存的模型账号，请只向允许使用的人提供密码。完整步骤见[远控服务](https://github.com/TongZi2003/Notara/blob/v0.23.1/docs/runtime/remote-access.md)。

## ChatGPT：连接自己的订阅账号

在 **设置 → ChatGPT 账号** 点击 **Continue with ChatGPT**，通过 OpenAI 官方授权流程登录，再在课堂或教室的模型选择器中选择该账号的可用模型。支持多账号与工作区连接，动态读取授权模型目录；已有 API 服务商配置继续保留。

**首次授权在运行 Notara 的电脑上完成**，远程手机无法代替本机 loopback 回调。凭据只存于实例的 `DSH_HOME/notara-chatgpt`，独立于 Vault 与浏览器存储。退出会停止进行中的请求、清除本地凭据并尝试撤销授权；远端撤销未确认时会明确提示。此连接不导入 ChatGPT 历史对话，也不自动转为付费 API 请求。

支持文本、图片和 Notara 本地工具调用，仍遵守 DSH 原生权限与审批；流式请求收到 `response.completed` 才判成功。账号资格、模型与额度由 OpenAI 决定。此入口不提供托管 Code Interpreter、文件搜索、音视频或图片生成；教室输出 token 预算也不是该订阅接口的服务端硬上限。操作与限制见[ChatGPT 账号接入](https://github.com/TongZi2003/Notara/blob/v0.23.1/docs/runtime/chatgpt-account.md)。

## 白板与课堂，留出更合适的空间

- **白板卡片手动长宽**：右下角支持鼠标和触摸拖动，按画布缩放换算尺寸，随布局持久化；文字随宽度换行，长公式在卡内局部滚动，保留 KaTeX 完整渲染。「全览」也按资料卡的实际手动高度取景，避免增高后被裁掉。「恢复默认」同时清除手动位置和尺寸。
- **课堂永久删除**：输入课堂标题，确认关联记录后删除停止的课堂及其工作员对话。删除前检查整棵关联会话树空闲；确认后记录发生变化时要求重新确认。删除处理中阻止其他页面改名、修改输入队列、切换模型或派生会话；已在进行的修改结束后重新核对确认信息。只删除原生会话记录，保留 Vault 资料与共享附件。归档继续用于暂时收起课堂。

## 更新提醒，放在抬眼就能看到的地方

更新提示移到**全局右上角**，适配极简、手帐与深浅色主题，切页和收起侧栏后仍可见。提示可关闭，不抢输入焦点；同一次启动关闭的同一版本不会因轮询或刷新反复弹出，下次启动或出现另一个新版本可再次提醒。没有新版时不弹提示，检查失败可重试。

保留**每次启动自动检查一次、每 30 分钟检查及「设置 → 更新」手动检查**。多页面读取同一状态，不重复发起启动检查。新版准备好后仍需点击「重启并更新」；课堂或后台任务运行时拒绝重启。版本来源、SHA-256 校验、兼容性判断、隔离安装和回滚保护继续生效。

修正停止旧服务部分成功后抛错却跳过恢复的问题：更新失败时实际尝试恢复旧版本，恢复失败会明确提示。版本比较拒绝前导零和超过安全整数范围的分量。Windows 数据目录迁移也修正目录链接的复制方式：插件指向新快照，外部依赖链接保持原目标，失败时撤销本次复制并保留源目录。

## 升级：备份收好，我们再继续

默认运行数据在 **`~/.notara/vault-runtime`**，与代码目录分开，默认端口 **`57093`**。先停止实例，**完整备份实际数据目录，包括隐藏文件**，再更新代码、依赖与插件快照：

```sh
git pull --ff-only
npm ci --no-audit --no-fund
npm run vault:upgrade
npm run vault
```

已有运行目录使用固定插件快照，单独更新源码不会替换它；快捷安装器也不迁移学习数据或已有快照。升级器保留旧快照、课堂、资料、模型配置与已有像素教室，失败时回滚本次安装改动。自定义实例必须给升级和启动命令传入相同的 `-- --root /你的数据目录`。

兼容的界面更新仍可从「设置 → 更新」执行。DSH、Cordis 或数据格式不同的版本要求手动备份升级。从 **0.21.0 以前**升级会迁移打开过的会话格式，旧版无法读取；回退需恢复旧代码与依赖，并把整份备份放回原数据目录位置。详细方法见[安装和回退](https://github.com/TongZi2003/Notara/blob/v0.23.1/docs/install.md#升级和回退)。

# Notara 0.23.9 · 小书桌有人守着啦 🐾

唔，这次小猫把工具箱搬到了书桌旁。意外熄掉的灯，会试着替你重新点亮；你说要睡觉，就乖乖收好笔记，一起休息。

## 想收工，点这一枚小红灯

页面左下角，设置齿轮上方，多了一枚**红色关闭图标**。

1. 点一下，会问“是否要关闭 Notara「拾页」？”
2. 左边是「取消」，右边是红色「确定」。点空白处、按 Esc，也能取消。
3. 确认后停止服务和自动恢复。正在生成的回复、后台任务也会停止，先保存手头的编辑再收工呀。
4. 已保存的学习集、课堂、讲义和账号配置都留着。关掉浏览器标签页就好，下次回来还能接着学。

## 桌面留一枚小书页就够了

双击 `create-notara-shortcuts.cmd`，桌面会生成 **Notara「拾页」**。

用它启动，也用它回到已经打开的书桌。关闭交给页面里的小红灯。原来的 `start-notara.cmd`、`stop-notara.cmd` 和终端命令仍然可以用，熟悉的路没丢哒。

创建时会整理确认属于这个安装的旧启动、关闭快捷方式。其他安装目录的入口不会被拿走；同名入口指向别处时，会先提醒你确认。

## 服务摔了一跤，小猫会扶一下

- 服务进程意外退出后，先确认原进程与目录锁释放，再用原代码、原地址和原数据目录重新启动。
- 修好 wrapper 硬退出可能留下孤儿 Host 的情况，避免原端口还占着，新服务就急着往里挤。
- 默认十分钟最多自动恢复三次；清理或启动失败就停下，留下简短运行记录。不会无休止地转圈圈。
- 主动关闭立即取消恢复。正在更新时会协调停机，避免两个操作抢着搬书桌。
- 桌面入口跟随应用内更新选定的新代码；更新缓存失效时，仍保留正常停止的入口。

保留的是**已经保存的进度**。正在生成的回复和进行中的任务不保证续跑。电脑关机、重启或整个管理程序也被结束时，需要再次双击入口。这个边界也写进 README 啦，小猫不乱许愿。

## 把小书桌抱回家

- **Windows x64 免安装版**：`notara-portable-0.23.9-win-x64.zip`，完整解压后双击 `start-notara.cmd`。
- **普通安装包**：`notara-0.23.9.zip`，完整解压后双击 `install-notara.cmd`。安装包的小彩蛋还在哦。
- **已经在用**：先结束课堂与后台任务，在「设置 → 更新」检查、重启更新。手动换目录时，先停止旧服务，按 README 升级原数据目录，再创建快捷方式。

这次没有改变课堂数据格式，也不清空学习集。完整步骤收在 [README](https://github.com/TongZi2003/Notara/blob/v0.23.9/README.md)，慢慢看，小猫陪着呢。

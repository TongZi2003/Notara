为什么做它

自己先想一遍，再有人点拨几句

很多知识是在这样的时候接起来的：自己琢磨过的问题，拿去和人讨论，对方一句反问，原来散在各处的东西忽然连成一片。

可愿意陪你讨论的人不总是有空，整理错题又是件忙半天也看不到回报的事。Notara 想把这种讨论留在手边。你的问题有人接住，你的想法被认真对待，讨论过的东西也不会散掉。

三件旧道理，换个做法

重复 · 联系 · 延伸

这些都是学习里的老话。Notara 把它们落在每节课留下的记录上。

重复

把看过的，变成认得出来的

复习只盯一道题最关键的那一步，结果分三种：做出来、没做出来、这次没考。

下一次复习按 1、3、7、16、35 天排。到期做出来才进下一档，没做出来退一档，这次没考不改排期。

联系

让不同地方学到的东西互相解释

题卡一题一张，同类题挂在共性专题下，图谱里能看到资料、卡片和路线怎么连在一起。

讲新题之前，老师会先翻你以前的卡片、画像和锦囊，从你已经站稳的地方讲起。

延伸

把一个答案，变成几个值得想的问题

做完一道题，老师会换个条件、给个反例、问问边界。需要练习时，后台的出题员按你的情况出变式。

白板上可以直接作答，除了选择、填空和排序，还能在函数图上拖点、调参数。

镜子照见的

照出你的好，也照出你的不好

讨论完一道题，老师会把它整理成一张题卡，分成内容、参考理解、学生理解三段。

“学生理解”只记你真正说过、做过的：一开始怎么想，在哪里转了弯，哪一步靠提示才走通，哪些还没检验过。老师讲过的，不算你已经会了。

  • 以前的误解和后来的修正都留着，最后的正确结论不会盖掉过程。
  • 检验过的和没检验过的分开写，下次知道先查哪里。
  • 题卡是普通的 Markdown 文件，你随时可以打开、修改。

因材施教

从一道题、一段笔记，或一个没想明白的问题开始

  1. 写下题目和你的尝试

    不用等到完全想对。卡在哪里就说哪里，想法不成形也可以先写出来。

  2. 老师一次问一步

    它先弄清你卡在哪，再决定给提示还是讲一段。关键的一步尽量留给你自己走。

  3. 需要时切到白板

    公式和关系图写在板上，函数图像能拖动，过程可以逐帧演示，小练习也能直接在板上作答。

  4. 存成题卡，下次接着学

    讨论收束时，题目、参考理解和你的理解变化存进题卡。保存小结以后，这节课还能接着聊。

混合教法，跟着理解换讲法

  • 苏格拉底用问题引导你自己走每一步
  • 费曼法先让你用自己的话讲清楚，再一起找缺口
  • 讲解—变式先讲清例题，再用一串变式检验
  • 结构分析先看清条件、目标与不变关系

老师先判断这一步缺什么、错什么，再选合适的讲法。你也可以直接告诉老师自己的偏好。

替你整理，陪你规划

资料交给它理，路线跟着你改

资料

讲义、PDF 和图片都放进 Vault。PDF 上可以圈出一块区域引用到卡片里，页码和原图一起保留。整本书也能拆，老师先和你确认范围，再把知识单元和题目整理成卡片。

路线

想系统补一块内容，可以请老师规划路线：分阶段，主线、补练、拓展分开，标出先修。学着学着发现不合适，就改后面的课，上过的课原样保留。

锦囊

一节课里值得留下的方法和思路转变写成锦囊：什么时候想起它，要什么条件，怎么做，为什么成立，在哪里会失效。锦囊放在技能页，用不用由你决定。

后台工作员

难题可以交给后台的题目研究员独立解一遍，拿不准的一步再请核验员看。备课、出题和整理资料也各有专门的工作员。

它是什么

一个学习空间，两种打开方式

Notara 从 DeepSeek Harness（DSH）的教学插件开始，现在也有了独立桌面版。插件版在本机运行、用浏览器打开；桌面版拥有自己的应用窗口，目前提供 Windows x64 预览版。

课堂小结、题卡和资料都是普通文件，存在你选的学习目录里，也能用 Obsidian 这类 Markdown 编辑器打开。它本身不是 Obsidian 插件，不从 Obsidian 的插件市场安装。

说在前面

  • 调用模型时，相关内容会发给你选的服务商，所以它不是完全离线的。
  • 费用由模型服务商决定，Notara 本身没有套餐。
  • 模型会出错，老师也会说错。它不保证提分，也不保证你学会；发现错了，直接指出来。
  • 两个版本的安装方式和发布进度不同，详见版本选择与安装说明。

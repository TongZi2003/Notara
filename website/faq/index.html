常见问题

先把话说清楚

桌面版和 DSH 插件版怎么选？

想在独立应用里上课，可以关注 Notara 桌面版；它不需要先安装 DSH，目前处于预览阶段，公开安装包还在准备。

现在就想使用，或习惯 DSH 的模型配置和浏览器课堂，可以安装插件版。两个版本分别维护，插件版会继续保留。入口在版本选择页。

两版的课堂记录不能自动互相迁移。尝试旧资料时先复制学习目录，保留原版数据。

和直接问 AI 有什么不一样？

直接问，AI 可能会给你一份完整解答。Notara 的老师默认先弄清你卡在哪，关键的一步尽量留给你自己走，再把你怎么想明白的记进题卡。

下一次讲课时，老师会翻你以前的卡片、画像和锦囊，从你已经会的地方讲起；复习也按你实际做出来的那一步安排。

要花钱吗？

Notara 本身没有套餐。调用模型的费用由你选的模型服务商决定，按它们的价格计算。

我的数据存在哪？会上传吗？

两个版本都把资料留在自己的电脑上。桌面版的资料放在你选择的学习集文件夹，应用设置与课堂记录由桌面版单独保存；DSH 插件版的默认学习数据目录是用户目录下的 .notara/vault-runtime。

老师回复需要调用模型，这时对话和相关资料会发给你选的服务商。所以 Notara 不是完全离线的，数据是否离开设备取决于你用的模型服务。

能离线用吗？

服务本身在本地运行，可老师的回复靠模型服务，所以需要能连上你配置的服务商。

支持哪些模型？

桌面版在“设置 → 模型来源”按服务商配置，可以填写 API Key，也可以使用服务商支持的订阅登录；模型与推理强度以所选服务商和模型的能力为准。

DSH 插件版沿用 DeepSeek Harness 的模型设置。两个版本都能为老师和后台工作员分别设置模型，工作员也可以跟随老师。

支持 Windows 吗？

桌面版的 Windows 安装包仍在适配与验证中，尚未公开发布。macOS Apple 芯片的桌面安装包也正在准备，请以桌面版发布状态为准。

DSH 插件版已接入 Windows 启动与 Git Bash 支持，但仍待完整实机验收；macOS 的插件版可以按安装说明使用。

它会替我写作业吗？

默认不会先给答案。老师会先问你的想法，在你卡住的地方给提示，关键一步留给你。

能保证提分吗？

不能。模型会出错，老师也会说错，它不保证提分，也不保证你学会。它能做的，是如实记下你哪里做出来了、哪里还没检验过，让你和老师都知道下一步该做什么。

它是 Obsidian 插件吗？

不是。Notara 提供独立桌面版和 DeepSeek Harness 插件版，都不从 Obsidian 的插件市场安装。它的题卡与笔记是 Markdown 文件，可以用 Obsidian 这类编辑器打开。

题卡里的记录我能改吗？

能。题卡和资料都是普通的 Markdown 文件，可以在 Vault 里直接编辑，也可以用别的编辑器打开。

开源吗？

DSH 插件版代码公开在 GitHub 上，但目前没有附开源许可证。公开可见不等于授予了开源许可。

桌面版源码保持私有，安装包与版本说明通过独立的公开下载仓库提供，目前尚未发布安装包。

升级会丢数据吗？

DSH 插件版升级器会保留课堂、资料和模型配置，失败时撤回改动。不过升级前请一定完整备份学习数据目录，从 0.21.0 以前升级尤其要备份。步骤见插件版升级和回退。

桌面版会随公开安装包提供自己的更新说明，不使用插件版的升级命令。

遇到问题去哪反馈？

桌面版请到桌面版 Issues，插件版请到插件版 Issues。附日志或截图前，请去掉凭据和私密的课堂内容。

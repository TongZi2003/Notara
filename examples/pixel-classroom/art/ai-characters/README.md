# 五种角色与精灵图集

通过 Codex 内置 `image_gen` 生成（已修复本机订阅路由的图片接口），不是 CLI/API key 回退。源图在 `source/`；参考出处见 `../../public/assets/ai-characters/ATTRIBUTION.md`。

统一提示规格：一个角色、七列三行、21 个完整全身 Q 版像素帧；三行为正面、背面、朝右侧面；七列为行走左脚、站立、行走右脚、工作姿势两帧、阅读两帧。2.5 头身、透明背景、同尺度、固定脚底、不画文字/网格/场景。大肥鱼首张头像作为后续风格参考，各角色的颜色、发饰、衣着由对应参考图约束。实际生成保留了 Kimi 的茶具工作姿态，仍只由现有任务活动状态驱动。

`prompt-specifications.json` 保留统一提示与逐角色设计要求。生成方向和间距存在模型偏差，因此由 `prepare-sprites.mjs` 做机械分帧、统一缩放、透明边缘阈值、脚底对齐和大肥鱼侧面镜像；不会将高分辨率帧当成更大的世界坐标。

```sh
node examples/pixel-classroom/art/ai-characters/prepare-sprites.mjs
npm run build:pixel-classroom
```

每个原生帧 16×32，用于已有状态机、点击范围、轮廓和出入场效果。细节图集为 4 倍分辨率，通过独立缓存适配器在相同的屏幕矩形中绘制；家具和引擎源码不变。图片解码只在启动时发生，镜像识别和绘图缓存按帧对象缓存，不在动画循环里重新解析图片。

默认绑定只代表外观：老师→大肥鱼；题目研究员→GPT；核验员→Claude；备课员→Kimi；通用工作员→GLM；出题员→GPT。人物详情中的「外观」可单独更换，按岗位保存到浏览器，不改变实际模型、权限、任务或座位。

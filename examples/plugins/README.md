# 当前插件集合

默认保留：`worldbook`（教室背景与世界书）。数学工作台、回合和其他工作台只作为实验插件保留，不进入默认课堂。教室的常用模板在创作者中显式选择，新教室默认空白。

以下旧演示插件于2026-09-15退出日常产品安装集合：function-lab、argument-studio、blackboard、error-clinic、geometry-lab、evidence-detective、time-atlas、seminar-room、scenario-simulator。目录仅作为已有协议与存储回归的测试样本保留，不再批量安装。卸载不删除先前保存的笔记、资料、课堂记录与用户文档。

`study-kit`为安装生命周期测试示例。后续分享的教室沿用普通Notara包和worldbooks声明，不另起一套安装器。

# 数学工作台

JSXGraph 1.13.3离线打包，选择MIT许可；KaTeX与Zod许可随包。二维与三维共用版本化场景、参数和观察，提供27种构造，包括交点、垂线、圆锥曲线、空间点线面、球、函数与参数曲面。AI使用增量编辑接口，并读取绑定场景版本的画布坐标和测量。表达式由受限解释器处理，未开放eval或网络。

Notara Host提供Cortex Compute Engine 0.128.9（MIT），用于化简、求值、单变量求解、求导；每次请求在独立Worker中运行，保留超时、无定义、未判定与并发繁忙状态。公式运算与画布共用参数，结果可加入观察。插件需要包含数学接口的本轮Host版本；旧Host无法调用这些新增接口。首次加载每个插件版本后，当前课堂继续固定原版本，更新后请在新课堂使用新版；旧场景与旧笔记保留。

构建：`node_modules/.bin/tsx scripts/build-math-workbench.ts`，然后在插件页安装本目录或npm pack生成的包。图形操作和观察自动同步，未同步冲突保留本地编辑；“带入对话”携带真实工作文档快照，笔记保存需确认。场景和笔记不会自动推进复习。

画布右下角的虚线矩形开启框选，完整包围当前视图中的对象即可选择；点按中心判断，曲线按屏幕外接框判断。Shift/Ctrl/Command 可追加选择，对象列表也支持多选。删除点会连带删除依赖它的线段及后续构造，删除前显示关联数量；删除线段保留端点。Delete/Backspace 删除所选对象，Esc 清除选择并退出框选，撤销/重做整批恢复。输入公式或坐标时删除键只编辑文字。手帐纸纹保留在画布外，画布内只显示数学网格。

二维画布默认直接拖动空白处平移，无需按Shift；触屏支持单指平移。拖动可移动点仍调整该点；开启框选后，拖拽改为矩形选择，按Esc退出框选即可继续平移。视区随场景自动保存。

计算面板默认计算普通算式（如 `1+1`、`sqrt(4)`）；解方程、求导、小数结果和化简在运算选项中切换。只有解方程和求导显示变量输入。Enter与计算按钮执行同一操作，保存尚在进行时会等待保存结果；空算式有明确提示，修改公式或运算后会清掉旧结果及「加入观察」入口。

# 整理时空线索

提取原文中有根据的事件、年代与地点，读后用read_workbench/update_workbench维护时空地图。year使用整数，公元前填负数；经纬度表示地点近似位置，不能冒充历史疆域。没有确定年份或地点的事件先说明缺口，不猜精确值来填满地图。真实事件fictional=false，并绑定具体来源link；已有笔记和用户关系须保留。

工具不在当前列表时先load_tools加载目录中的真实工具名，按读到的参数合同调用。工作文档的documentJson是完整document序列化，不含revision或schema。出现版本冲突先重读并保留学生修改，不绕道写盘。正式成果保存仍走原有笔记/卡片确认，不能因操作工作台推进复习。

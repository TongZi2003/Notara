# 整理 Markdown 资产

你在 Notara 的资产层中工作。资产事实保存在当前 workspace 的 `vault/` Markdown 文件里。

工作约束：

- 先读取目标文件，再决定是否修改；
- 只修改用户指定的文件和必要字段，保留原有正文、frontmatter、链接和任务；
- 使用 `[[文件名]]` 建立链接，引用已有文件时不要复制出第二份事实；
- 路线、卡片和复习状态写在文件的 frontmatter 或正文中，不写入会话记录；
- 保存遇到版本变化时停止覆盖，重新读取并让用户对照；
- 把整理结果说明给用户，不把绝对路径、内部 session ID 或工具协议带进学生内容。

世界书、子 Agent、会话轨迹和权限属于 Harness 会话层，不写入资产文件，除非用户明确把它们作为普通 Markdown 内容保存。

# 函数实验台

插件页安装本目录或 `npm pack` 生成的 tgz，课堂顶部打开「函数实验台」。

- 支持 `y=a(x−h)²+k` 和 `y=a sin(b(x−h))+k`，角度单位为弧度。
- 写预测，显示图像，逐个调整参数；「固定参照」保留一条虚线作比较。
- 「保存草稿」保存本课参数、参照曲线与文字，刷新恢复；未保存内容会丢失。
- 「整理为笔记」显示完整确认区，确认后进入原有笔记本，不自动记掌握或复习。
- ＋或斜杠选择「探索函数变化」，用对话讨论预测。老师看不到未发送/未保存的滑块和文字。

显示窗口 x∈[−6,6]、y∈[−5,5]，超出窗口的图像被裁切，不代表函数不存在。支持两套宿主主题。无外部网络、依赖、原生代码；只申请 `draft` 与 `save-note` 权限。

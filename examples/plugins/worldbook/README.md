# 世界书 · 城邦议事厅

在插件页选择本目录，或安装 `npm pack` 生成的 `notara-worldbook-1.0.0.tgz`。

课堂顶部打开「世界书」，选择条目编辑并保存，勾选「本课启用」。关键词采用大小写不敏感的字面匹配，不是语义检索；「试查触发内容」显示保存版本的本轮命中。可设始终带入或关闭某条，每轮上限8条/6000字，超出的条目不会截断塞入。

内附可改写的虚构城邦背景，也可以新增自己的术语、人物与实验情境。「进入情境学习」技能在＋或斜杠菜单中选择，发送后使用。

用户编辑内容跨课共用，每课启用独立、默认关闭；改动于下一条用户消息开始生效。运行中的工具循环保留该轮背景。插件停用后不再带入新背景；原生会话中的历史上下文仍可追溯。世界书不代表学生学情，不改变掌握与复习。可导出 JSON；卸载保留用户副本，重装同包可恢复，更新不覆盖副本。

修改包的种子时更新版本号再安装；历史课堂固定旧包，用户副本一经保存即由用户维护。

# 教室

包名保留 `@notara/worldbook`；1.1.0升级为教室工作台。安装本目录或npm pack生成的包。

默认空白，没有成员、背景或自动规则；本课启用默认关闭。创作者选择「教室」作品，可从空白或日常自习、推理讨论、变式训练三份模板开始。模板只在用户选择时复制。创作Skill随插件安装，仅在教室创作者提供。

面板与AI共编同一份worldbook.json。AI使用read_classroom_draft / save_classroom_draft；系统绑定作品和已读版本，冲突不能覆盖。保存只是草稿，安装此版本后才进入课堂。作品发布为普通Notara包的worldbooks声明，外部目录/tgz可沿用现有安装器；在线市场与URL自动安装尚未实现。

点名只进入原生输入框，发送后由教师读材料、供料并通过原生spawn派发；同学无工具、不继承父对话。公开回复署名回原对话；私有备课只回老师，完整子代理导航归调试模式。同任务可以继续同一个原生子会话，换边界则重新派发。

世界书区分参考背景和教学约定，关键词字面命中，寿命可选本轮/阶段/课堂。规则支持手动、每N个真实教学回合、阶段笔记成功保存；只产生教师候选，每教学回合最多一项自动参与。同一时机冲突候选跳过，避免补发过时插话。

停止取消在途与待执行任务，新学生消息可恢复安排；关闭「本课启用」持续停用。跨课只通过教师选择的小结。旧任务保留供料和角色快照，旧课堂保留包版本。

用户编辑内容和学习成果在停用/卸载后保留。九个旧独立演示插件已从日常环境退役，其源码仅保留作回归样本，不属于推荐安装集合。
